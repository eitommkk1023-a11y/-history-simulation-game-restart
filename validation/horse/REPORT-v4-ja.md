# 馬の試作04 — 減速1・減速2・停止

後ろへの入力を、引き始めの歩法を基準にした3段階へ変更しました。

- 減速1：1段下げる（例：襲歩→駈歩）。
- 減速2：さらに1段下げる（同じ入力中なら襲歩→速歩）。
- 停止：止まるまで減速する。

最初の2段階は常歩が下限です。停止は深く引く段で選びます。同じ深さで引き続けても下がり続けず、中央に戻して引き直すと、今の歩法からさらに減速できます。浅い方へ戻しても勝手に加速はしません。

3段階のラベルと選択中の点灯を追加しました。指の揺れによる境界のちらつきを小さな余裕で抑えています。

単体テスト114件、ブラウザ確認30項目が通過。引き続け・引き直し・境界での揺れ・同時タッチ・選択表示・横画面3サイズを確認しました。描画方式、馬のモデル、アニメーションは変更していません。本作やmainには反映していません。

実機iOSの確認ではなく、Chromium上の検証です。試遊では、後ろへ浅く→中ほど→深くと引いたときの使いやすさと、引き直しで1段ずつ下げられるかを確認してください。
