# 馬の試作02 — 左右入力の修正

カメラを基準にした進行方向を計算する際、左右の符号が逆でした。スティックとWASDが共通で使う方向変換を修正しました。カメラ回転の操作は変更していません。

- 修正前：カメラ4方向×徒歩／騎乗×スティック／WASD×前後左右の64ケース中、左右32ケースが逆転。
- 修正後：64ケースすべて期待する画面方向へ移動。
- ブラウザにタッチを送る4ケース（徒歩／騎乗×左／右）も通過。指を離すと入力解除。
- 関連単体テスト7件が通過。ブラウザ・シェーダーエラー0。
- 試作01のHTMLは保持し、修正版を試作02として別出力。本作とmainへの変更はありません。

検証はChromium上です。iPadで軽快とのユーザー報告は受けていますが、機種・FPSを測定したものではありません。iPhone 17の実機速度も未確認です。描画方式・モデル・頭数設定は変更していません。

試遊では左へ倒すと画面の左、右へ倒すと画面の右へ向かうこと、カメラを回しても同じことを確認してください。馬は旋回速度に制限があるため、向きが変わるまで少し時間がかかります。
