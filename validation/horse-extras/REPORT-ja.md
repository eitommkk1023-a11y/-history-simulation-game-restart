# 馬・戦場用追加分 試作06 結果

## 実装

- 既存の馬の造形・3LOD・5歩法・スティック操作と試作05を保持。
- rear（2秒→idle）、fall（1.5秒→dead）、dead、turn_l / turn_rを追加。騎手は鞍へ追従。
- 別モデルの荷馬車（3.84m×1.8m）、車輪回転、1頭／2頭立て、首輪・引き綱、木箱／俵切替を追加。
- 追加依頼の幌（前後開口・表示切替）、御者席1＋荷台2席、人の追従とプレイヤーの馬車乗降・御者操作を実装。
- 1頭ごとのspeed / phase / state / stateT / coat / riderと追加harness / turnを受け取る描画APIを用意。
- 自己完結HTMLは `exports/World-of-History-horse-prototype-v6.html`。モデルとThree r128も内包。

受け渡しAPI・再生成方法・接続点は [README](../../prototypes/horse-extras/README.md) に記載。既存battle.js・main・正式ワールドは変更対象外。

## 技術上の調整

元テクスチャの16空き行へ追加97行は入らないため、高さを512へ拡張。元の240行と馬のLOD配列は維持した。馬具は別インスタンスにして元モデルを変更していない。

turnは足踏みをループし、呼出側が1周期約90度のヨー回転を与える。累積回転をアニメーション内へ焼き込まず、繰返し接続時の巻戻りを防いだ。確認ボタンでは実際に90度回る。

GLBは交換・検査用。大量描画は共通の骨格テクスチャとインスタンシングを使用する。画像用UVのないモデルのuv枠へ内部値を格納し、不要属性によるスロット超過を避けた。

幌・座席の追加により当初の車体目安600／300／60を736／312／66へ改定。人は別に1人312／200／24三角形、同じLODの人は1バッチ。幌は車体と同じバッチで、透明描画を使わない。乗客用では荷物を消して空間を確保する。GLBは18シーン。

## 確認してほしいこと

1. 横画面で従来の前後スティック操作・歩法・後退が使えるか。
2. 「試験設定」で後ろ脚立ち・転倒・倒れたまま・左右旋回を確認。転倒後は「復帰」で戻す。
3. 荷馬車を接続し、1頭／2頭、木箱／俵、走行中の車輪を確認。動作確認時はいったん馬車を切り離す。
4. 「馬車に乗る」で御者席へ移動、スティックで発進・操舵・減速。停止して「下車」。乗客0〜2人と幌の表示を切り替える。
5. iPhone/iPad実機で操作の重なり・描画欠け・発熱やカクつきがないか。

## 範囲と未検証

荷馬車は平地の簡易牽引。悪路の厳密接地、サスペンション、車両衝突・横転、複雑な後退は未実装／未検証。牽引中は試作上の常歩制限がある。戦闘AI・落馬・起き上がりは対象外。乗降アニメーション・乗客の動作・手綱IKは対象外。人型の大量描画と大量馬車の性能も未検証。

GLBは独自読戻しテストとブラウザ描画で検証。外部glTF Validatorやgame-dev CLIによる認証は実施していない。
