# v30 rock-system validation

See [the Japanese report](../../docs/rock-system-report.md) for the numerical scope, units, all A–D comparisons, sources, and limitations.

- `summary.csv`: 28 runs, scalar metrics and differences/rates from A.
- `by-rock.csv`: 28 × 24 rocks, removed mass/volume, mean depth over cells evaluated for that rock, exposed area and A differences.
- `experiments.json.gz`: lossless full metrics, initial input SHA-256, interventions, histograms and boundary budgets. Decompress with `gzip -dk experiments.json.gz`.
- `world-*-new.json`: full native 3000×3000 generator runs (three seeds). Separate processes measured elapsed time and process maxRSS; instrumented input retained for analysis is included in RSS.
- `reproducibility.json`, `rock-state-hashes.json`: same-profile regeneration and baseline/legacy checks.
- `browser.json`: actual WebGL readback of 104 IDs (all 24 kinds), diagnostic modes, landscape viewports, save generation and previous-world history.
- `grass-browser.json`: grass placement/roots/walking/view modes/save regression.
- `images/`: genuine numerical figures and browser captures.

Raw fixture grids and three normal-world grids are generated by the tools and included in the delivered validation ZIP; they are not kept uncompressed in Git. No world-size or generation-resolution reduction was used for the three normal seeds. Node measurements and software WebGL results are not iOS device benchmarks.

Reproduce, from repository root:

```sh
node --test --test-isolation=none tests/*.test.mjs
node tools/build-integrated-world.mjs /path/to/verified-three-r128.min.js --dev
node tools/rock-experiments.mjs
node tools/rock-extra-metrics.mjs
node tools/rock-world-check.mjs 12345 new
node tools/rock-world-check.mjs 67890 new
node tools/rock-world-check.mjs 314159 new
node tools/rock-export-maps.mjs
MPLCONFIGDIR=/tmp/woh-matplotlib python tools/rock-plots.py
node tests/rocks-material.browser.cjs
node tests/rocks.browser.cjs
node tests/grass.browser.cjs
```

Use Chromium and Playwright for browser tests. The input library SHA-256 is checked by the builder. No network assets are required by the resulting standalone HTML. Geological history runs only during generation; runtime lava-to-column reclassification and device performance remain outside verified coverage.
