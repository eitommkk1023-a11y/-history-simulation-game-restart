# 馬の試作08 結果

停止中のスティック左右で、既存の足踏みクリップを使ってその場旋回できるようにしました。移動ボタンとは別に、モーション6ボタンを通常画面へ常時表示し、UIを隠しても残るようにしました。

走行中の転倒では、馬が減速しながら崩れ、騎手は現在の鞍位置から進行方向へ飛び出します。着地後は倒れ姿勢・起き上がりを経て徒歩へ戻ります。落馬中の操作を制限し、復帰ボタンで騎手が鞍へ戻されないことも確認しました。リセット時に馬車のもう1頭が残る不具合も修正しました。

## 検証

- 単体テスト141件。停止旋回、速度を保持した転倒、前後方向、地形・障害物、重力、着地・起き上がり、異なる時間刻みを含みます。
- 新機能のブラウザ確認13項目。実際の2本指操作、走行中の転倒、騎手の別移動、描画境界の接地、徒歩復帰、空中での復帰、リセット、無効操作の制限、横画面3サイズを含みます。
- 既存機能の回帰25項目。旧5歩法、追加動作のGPU/CPU比較、幌・乗客・車輪、5000頭描画など。
- 旧5歩法の固定RGBA差分0、追加5動作の固定シルエット差分0。
- 5000頭は全頭遠LODで、馬具1667頭を含め馬関連2バッチ・890004三角形。実機FPSの測定結果ではありません。

新機能の数値とスクリーンショットは `browser.json` と同じフォルダ、回帰結果は `regressions/browser.json` に保存しています。

## 確認してほしいこと

1. 馬に乗り、停止中にスティック左右。その場で足踏みして回り、離すと止まるか。
2. 常歩・駈歩・襲歩中に「転倒」。スティックを触ったままでも押せ、馬が崩れて騎手が飛ぶか。
3. 着地・起き上がり後に歩けるか。馬を「復帰」させて近づき、再乗馬できるか。
4. UIを隠してもモーションボタンが残り、iPhone/iPad横画面で移動・カメラ操作の邪魔にならないか。
