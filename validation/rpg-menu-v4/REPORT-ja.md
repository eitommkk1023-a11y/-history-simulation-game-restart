# メニュー試作04 — 種類ボタンを左側へ移動

2026-11-06 / `codex/prototype-rpg-menu-v1`

既存のDOM配置とCSS Grid/Flexを調整。新規のライブラリや画像アセットはなし。通常の種類ボタン列80px、狭い画面では68px。ボタン高さ52px、表示が低い場合は44px。収まらない場合は種類の列内を縦スクロールする。装備/使用/保存の処理や地理生成は変更しない。
