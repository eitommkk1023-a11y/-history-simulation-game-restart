# 脚の太さ 比較試作11

前脚の付け根を約18％、後ろ脚の太ももを約20％太くし、膝・飛節を少しふくらませました。膝下の中ほどと蹄は保持しています。近／中／遠の三角形数は2132／1064／174で、従来と同じです。

画面上部の「脚：厚め／脚：元の形」で切替。個体・毛色・能力・カメラ・歩法を維持して見比べられます。新しい正式モデルを上書きしたものではありません。

単体151件、比較ブラウザ12項目、共有回帰25項目が通過。同じ姿勢の実描画で2053画素の違いを確認しました。通常歩法・後退・後ろ脚立ち・旋回・走行転倒・復帰で候補メッシュの接地を確認。横画面3サイズでボタンが重ならず、切替100回でもジオメトリ数が増えませんでした。

5000頭の厚めモデルも実際に送信し、全頭遠LOD・馬具1667頭込みで馬関連2バッチ、890004三角形。Chromium/SwiftShaderでの確認で、実機FPSは未測定です。

確認してほしいこと：

1. 「脚：厚め」と「脚：元の形」を切り替え、正面・横から胴体とのバランスを比較。
2. 歩行・走行中の膝や飛節が太すぎず、体重を支える感じが出たか。
3. 走行転倒で脚が不自然に重なったり、地面に埋まったりしないか。
