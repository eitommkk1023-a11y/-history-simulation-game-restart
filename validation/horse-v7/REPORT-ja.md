# 馬 試作07 結果

復帰後に騎手が横へ残る不具合を修正。旧06でdead→復帰→下馬→再乗馬を再現し、残った腰のX約0.94mを確認しました。通常姿勢へ戻る前に腰の全ローカル位置・回転を初期化し、反復確認で横ずれが残らないことを検証しました。

操作は加速・減速・停止・後退ボタンへ変更し、スティックは左右の方向操作に限定。2本指でスティック保持中に加速する操作も確認しました。馬車は6.6／14km/h、駈歩は27km/h、スタミナ消費は襲歩のみ。高速時と牽引中の旋回半径を大きくしました。停止は急に速度をゼロにする処理ではなく制動です。

## 検証

- 単体テスト135件：速度、スタミナ、ボタン状態、逆走、速度と旋回半径、衝突の小刻み判定、旧資産の不変性を含む。
- 新しいブラウザ確認16項目：復帰／再乗馬、実際の27km/hと14km/h、スティック前後で歩法が変わらないこと、加減速・停止・後退、同時2本指、御者・乗客、旋回、反復復帰、横画面3サイズ。
- 既存機能の回帰確認25項目：rear/fall/dead/turn、幌と人、車輪、GLBに対応するGPU姿勢、5000頭、属性数、従来5歩法の固定画像比較。
- 旧5歩法の固定RGBA差分0、追加5動作のGPU/CPUシルエット差分0。
- 5000頭を実際に送信、全頭遠LOD。馬具1667頭を含め馬関連2バッチ・890004三角形。
- ブラウザ・シェーダーのエラー0。

生データ：`browser.json`、`regressions/browser.json`。操作と数式・再実行方法は [README-v7.md](../../prototypes/horse-extras/README-v7.md)。

## 確認してほしいこと

1. 倒れたまま→復帰、下馬→再乗馬で、騎手が馬の中央へ戻るか。
2. スティックを押さえながら加速・減速でき、前後に倒しても歩法が変わらないか。
3. 駈歩27km/hでスタミナが減らないか。停止後に後退できるか。
4. 馬車を御者席から操縦し、加速2回で14km/hになるか。高速時の大回りと幌・乗客の追従が自然か。
