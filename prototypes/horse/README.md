# World of History — 馬の試作04

本作へ統合する前の独立HTMLです。生成ワールド・本作のセーブDB・mainへの変更は行いません。

## 操作

- 馬の近くで「乗る」。最初は停止しています。
- 「加速」を押すたびに **常歩 → 速歩 → 駈歩 → 襲歩**。1タップ1段階です。
- 前へスティックを倒しても常歩で発進します。倒し続けても勝手に歩法は上がりません。
- スティックを離しても、選んだ歩法で前進を続けます。
- 左右は馬を基準にした手綱操作。右画面のドラッグはカメラだけを回します。徒歩は従来どおりカメラ基準です。
- 後ろへ浅く（18–45%）引くと引き始めの歩法から1段減速、中ほど（45–75%）でさらに1段減速、深く（75%以上）で停止を選びます。減速の下限は常歩です。「減速1・減速2・停止」を表示し、選択中の段を点灯します。同じ深さで引き続けても減速は連発せず、いったん中央へ戻して引き直すと、今の歩法からもう一度減速できます。境界にはわずかな余裕を設け、指のぶれによる段のちらつきを抑えます。減速には時間がかかり、歩法表示は実際の速さに合わせて変わります。
- 引く操作は加速より優先し、入力を戻しても減速先を維持します。すでに低速なら、後ろへの入力で勝手に速くはなりません。
- 「降りる」は減速して停止後、安全な横へ降ります。
- UIを隠してもスティック、加速、乗降、走行状態・手綱表示を残します。
- PC: W発進、A/D手綱、SまたはSpace停止、Shiftを1回押すごとに加速、E乗降、V視点。徒歩ではWASD移動。

## 速度と個体差

常歩110m/分（6.6km/h）、速歩220m/分（13.2km/h）、駈歩340m/分（20.4km/h）を試作の目標値としました。襲歩の最高速は個体ごとに60–70km/hです。品種・年齢ごとの厳密な実馬シミュレーションではありません。

同じ個体ID・Seedは同じ毛色、白斑、体格、加速、持久力、旋回を保ちます。速度のステータスは襲歩の最高速を表すよう再定義し、既存の独立した能力乱数チャネルを使用します。選択個体だけを `woh:prototype:horse:v1` に保存し、本作のDBとは分離しています。

持久力が少ないと襲歩から駈歩へ落とします。常歩・停止で回復します。障害物や急斜面での停止、俯瞰、位置リセット、画面から離れた場合、降車操作では持続走行を解除します。障害物に当たった後、スティックを前へ倒したままでも自動再発進しません。

## 描画とアニメーション

Three r128、オリジナルのメートル単位モデル、20骨格を維持しています。モデルは近2132・中1064・遠174三角形。操作馬はCPUで足位置を求めたポーズを送り、集団は共通の骨格テクスチャをGPUで読み取ります。

停止＋4歩法の5クリップを48フレームずつ格納しました。既存の64×256 RGBAFloatテクスチャの240行に収まるため、テクスチャ寸法・確保容量は増えません。

常歩4拍子、対角肢を同時に出す速歩2拍子、駈歩3拍子に加えて、襲歩は右後肢→左後肢→右前肢→左前肢の4拍子で生成します。襲歩は別の接地時間、歩幅、空中期、胴・首の揺れ、騎手の前傾を持ちます。左右の手前の切替、側対歩、モーションキャプチャ、道沿いの自動操縦は今回の範囲外です。

GLBも同じ頂点・骨格から直接書き出し、3つのLODシーンと5クリップを含みます。Blender評価が不安定だったため初回から直接出力に変更した方法を継続しています。生成元はJSです。外部モデル・テクスチャや課金サービスは使用していません。Three.jsのMIT表示を保持しています。

集団は最大3バッチ＋操作馬1バッチ。5000頭の全体表示では操作馬＋遠景4999頭の2バッチです。画面外除外と距離別LODを使用します。LODの形状補間は未実装です。

集団は**表示試験用の行進**です。野生生成、馬同士の衝突、経路探索、戦闘AI、多数の騎手はありません。試験場は本作の地理生成器に接続していません。操作馬の岩・地面・坂・場外の判定は行い、高速時も移動を0.18m以下に分けます。

## 再生成・検証

Node 24、Playwright、`/usr/bin/chromium` を使用します。ビルドは既存 `exports/World-of-History-development.html` からSHA256固定のThreeを抽出し、実行HTMLは全コード・モデルを内包します。CDN取得はありません。

```sh
node tools/build-horse-assets.mjs
node tools/export-horse-glb.mjs
node tools/build-horse-prototype.mjs
node --test --test-isolation=none --test-reporter=spec tests/*.test.mjs
node tests/horse-riding.browser.cjs
node tests/horse-visual.browser.cjs
```

出力：`exports/World-of-History-horse-prototype-v4.html`。
`horse.browser.cjs` と `horse-input.browser.cjs` は試作02の旧操作の記録用です。新操作の確認は `horse-riding.browser.cjs` を使用してください。

試作04の単体テスト114件とブラウザ検証30項目が通過。加速、入力解除後の前進、3段階のタッチ減速、手綱とカメラの独立、疲労、乗降、衝突、フォーカス、俯瞰、徒歩の左右、667×375・844×390・1180×820の配置を確認しました。5クリップの固定ポーズでGPU変形とCPU基準を比較し、256×256シルエット差分0画素。GLBも骨格位置を読み戻して比較しています。全ポーズ・全機種の一致を保証する試験ではありません。

実際の画像と生データは `validation/horse/riding-v4.json`、`v3-pose-*.png`、`v4-landscape-*.png`。5000頭の襲歩クリップを実際に描画し、配置・描画数が一致することを確認しました。今回の変更でFPS比較を取り直してはいません。

初回のSwiftShaderソフトウェア描画では5000頭で約0.9FPSでした。その後、ユーザーからiPadでは軽快との報告を受けています。iPadの機種・FPS、およびiPhone 17の実機速度は未計測です。ソフトウェア描画の速度をスマホへ換算しません。外部glTF Validatorやgame-dev CLIによる認証も未実施です。
