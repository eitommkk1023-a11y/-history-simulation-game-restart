# World of History — 馬の試作05

本作へ統合する前の独立HTMLです。生成ワールド・本作のセーブDB・mainへの変更は行いません。

## 操作

- 馬の近くで「乗る」。最初は停止しています。
- 前へ倒し直すたび **常歩 → 速歩 → 駈歩 → 襲歩** と1段上げます。加速ボタンは削除しました。
- 倒したままでは歩法は上がり続けません。中央に戻すと次の入力を受け付けます。素早く倒し直しても、物理更新の間に入力を取りこぼさないようイベント時点で記録します。
- 手を離しても、選んだ前進歩法を維持します。
- 後ろも倒し直す**回数**で減速します。引く深さは歩法選択に影響しません。最高速からは **襲歩 → 駈歩 → 速歩 → 停止** と3回です。低い歩法からは先に0段へ達すれば止まります。
- 倒したままでは1回分のみ。後ろへ3回目を入力すると、離しても停止までブレーキを維持します。前へ倒すと減速回数をリセットします。
- 後ろの入力を保持して停止しても、勝手に後退しません。止まってから一度中央へ戻し、改めて後ろへ倒すと低速（0.8m/s）の後退を行います。停止中なら最初の後ろ入力で後退できます。
- 後退は保持中のみ。離すと停止。後退中に前へ倒す場合もまず停止し、止まってから改めて前へ倒すと常歩で進みます。
- 左右は馬を基準にした手綱。右画面は独立した見回しです。徒歩の移動は従来どおりカメラ基準。
- 「降りる」は前進・後退とも停止を待って、安全な横へ降ります。UI非表示でもスティック、乗降、状態・操作ヒントを残します。
- PC: Wを押すたび歩法UP、A/D手綱、Sを押すたび減速、停止後のS押し直しで後退、Sを離すと後退停止。Space停止、E乗降、V視点。Shiftは使いません。

## 速度と個体差

常歩110m/分（6.6km/h）、速歩220m/分（13.2km/h）、駈歩340m/分（20.4km/h）を試作の目標値としました。襲歩の最高速は個体ごとに60–70km/hです。品種・年齢ごとの厳密な実馬シミュレーションではありません。

同じ個体ID・Seedは同じ毛色、白斑、体格、加速、持久力、旋回を保ちます。試作03で速度のステータスを襲歩の最高速を表すよう再定義し、既存の独立した能力乱数チャネルを使用します。選択個体だけを `woh:prototype:horse:v1` に保存し、本作のDBとは分離しています。

持久力が少ないと襲歩から駈歩へ落とします。常歩・停止で回復します。障害物や急斜面での停止、俯瞰、位置リセット、画面から離れた場合、降車操作では持続走行を解除します。障害物に当たった後、スティックを前へ倒したままでも自動再発進しません。

## 描画とアニメーション

Three r128、オリジナルのメートル単位モデル、20骨格を維持しています。モデルは近2132・中1064・遠174三角形。操作馬はCPUで足位置を求めたポーズを送り、集団は共通の骨格テクスチャをGPUで読み取ります。

停止＋4歩法の5クリップを48フレームずつ格納しました。既存の64×256 RGBAFloatテクスチャの240行に収まるため、テクスチャ寸法・確保容量は増えません。

常歩4拍子、対角肢を同時に出す速歩2拍子、駈歩3拍子に加えて、襲歩は右後肢→左後肢→右前肢→左前肢の4拍子で生成します。襲歩は別の接地時間、歩幅、空中期、胴・首の揺れ、騎手の前傾を持ちます。左右の手前の切替、側対歩、モーションキャプチャ、道沿いの自動操縦は今回の範囲外です。

GLBも同じ頂点・骨格から直接書き出し、3つのLODシーンと5クリップを含みます。Blender評価が不安定だったため初回から直接出力に変更した方法を継続しています。生成元はJSです。外部モデル・テクスチャや課金サービスは使用していません。Three.jsのMIT表示を保持しています。

集団は最大3バッチ＋操作馬1バッチ。5000頭の全体表示では操作馬＋遠景4999頭の2バッチです。画面外除外と距離別LODを使用します。LODの形状補間は未実装です。

集団は**表示試験用の行進**です。野生生成、馬同士の衝突、経路探索、戦闘AI、多数の騎手はありません。試験場は本作の地理生成器に接続していません。操作馬の岩・地面・坂・場外の判定は行い、高速時も移動を0.18m以下に分けます。

後退では既存の常歩を逆方向の位相で再生します。専用の実馬の後退モーションを制作したものではなく、操作確認用の試作です。骨格テクスチャやGLBのクリップは増やしていません。速度は符号付き、衝突の移動区間・段差は絶対距離、アニメーション位相は移動方向を反映して更新します。

## 再生成・検証

Node 24、Playwright、`/usr/bin/chromium` を使用します。ビルドは既存 `exports/World-of-History-development.html` からSHA256固定のThreeを抽出し、実行HTMLは全コード・モデルを内包します。CDN取得はありません。

```sh
node tools/build-horse-assets.mjs
node tools/export-horse-glb.mjs
node tools/build-horse-prototype.mjs
node --test --test-isolation=none --test-reporter=spec tests/*.test.mjs
node tests/horse-stick.browser.cjs
node tests/horse-visual.browser.cjs
```

出力：`exports/World-of-History-horse-prototype-v5.html`。
`horse.browser.cjs` と `horse-input.browser.cjs` は試作02、`horse-riding.browser.cjs` は試作04の記録用です。試作05の操作は `horse-stick.browser.cjs` を使用してください。

試作05の単体テスト119件とブラウザ検証32項目が通過。前への倒し直しによる加速、手放し前進、後ろ3回の減速、保持中の後退と解除、後退への切替制限、後ろの衝突・段差、手綱とカメラの独立、乗降、フォーカス、俯瞰、徒歩の左右、667×375・844×390・1180×820の配置を確認しました。試作03/04の描画確認では5クリップの固定ポーズでGPU変形とCPU基準を比較し、256×256シルエット差分0画素。GLBも骨格位置を読み戻して比較しています。全ポーズ・全機種の一致を保証する試験ではありません。

実際の画像と生データは `validation/horse/stick-v5.json`、`v5-reverse.png`、`v5-landscape-*.png`。試作03/04では5000頭の襲歩クリップを実際に描画し、配置・描画数が一致することを確認しました。今回の変更でFPS比較を取り直してはいません。

初回のSwiftShaderソフトウェア描画では5000頭で約0.9FPSでした。その後、ユーザーからiPadでは軽快との報告を受けています。iPadの機種・FPS、およびiPhone 17の実機速度は未計測です。ソフトウェア描画の速度をスマホへ換算しません。外部glTF Validatorやgame-dev CLIによる認証も未実施です。
