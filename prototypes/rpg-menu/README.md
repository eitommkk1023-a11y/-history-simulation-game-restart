# RPGメニュー 試作01

インベントリ・マップ・ミッションを、ひとつのメニュー内のページとして切り替える操作試作。正式版への統合はまだ行わない。v31の単一HTMLを固定の基準とし、コピーへだけ試作用のUIと一時停止制御を追加する。

## 今回試せること

- 画面上の「メニュー」から開閉。最初の起動時はすぐ操作できるようメニューを開く。
- 3つの横タブ、PCのI / M / J / Esc、タブ上の左右キー。
- アイテムの種類別表示・詳細・所持数・重量・試作用の使用/装備切り替え。
- 本作と同じ生成世界の地図。北固定・現在地・拡大縮小・ドラッグ移動。
- 進行中/完了ミッションの一覧・詳細・追跡切り替え。
- メニュー中はゲームのアニメーション/移動/ジャンプ/時間経過の更新を止め、閉じると再開する。
- iPhone/iPadを想定した横667×375、844×390、1180×820のレイアウト。

所持品・ミッション・所持金・性能・報酬は仮のデータ。キャラクターの体力/攻撃力/見た目、採集、実ミッション達成処理、報酬付与は接続していない。メニューの操作を試すための版であり、RPG要素が完成した正式版とは扱わない。

## 本作からの分離

- 試作ブランチ: `codex/prototype-rpg-menu-v1`。基準はv31 commit `89d2ec73c9c96872c10c216501d410121f60f5b8`。
- 本作の `自然地理生成器.html`、地理生成、保存形式、main/地形開発ブランチは変更しない。
- コピーしたゲームのIndexedDBだけを `geo-world-saves-prototype-rpg-menu-v1` へ切り替える。本作の `geo-world-saves` へ自動保存しない。
- 試作用所持品/追跡設定は独立キー `woh:prototype:rpg-menu:v1` に保存。利用できない環境ではその場での操作を続ける。
- 一時停止ゲートはコピー内の5箇所のゲーム用RAF呼び出しにだけ適用し、ブラウザ全体のrequestAnimationFrameは上書きしない。
- 世界生成Workerはメニュー中も準備を続ける。地図は世界の読み込み完了後に表示される。

## ビルド

外部ライブラリは増やさずHTML/CSS/JavaScriptと既存のThree.jsを使用する。生成されたHTMLは依存ファイルを内包する。

```sh
node tools/build-rpg-menu-prototype.mjs /path/to/World-of-History-v31-development.html
```

入力v31 HTMLのSHA-256 `50a6f786eef5b641d0ec235f2111712d7acabd29e87542a75d802b2d993dd348` を確認し、異なる版への無断差し替えは停止する。v31チェックアウトの既存ビルダーから基準HTMLを再生成して渡すこともできる。出力は `exports/World-of-History-menu-prototype-v1.html`。

## 検証

```sh
node tests/rpg-menu-model.test.mjs
node tests/rpg-menu.browser.cjs
```

モデルでは消費数の下限・装備スロット・保存値の検証を確認。Chromiumでは3画面サイズでタブ/詳細/フィルター/試作用使用・装備・追跡・実世界地図のズームと移動・一時停止/復帰・状態保持・本作保存先へ書かないことを確認する。結果は `validation/rpg-menu`。

ソフトウェアWebGL環境では元の3Dゲームの描画が重いため、移動やジャンプの検査は固定の短い待ち時間ではなく実際の状態変化を待つ。実機iPhone/iPadのSafariや本作での正式データ連携は未検証。

次のテストプレイでは「タブ移動のしやすさ」「アイテム詳細と一覧の幅」「地図の操作」「ミッションの読みやすさ」「戻った後に操作できるか」の反応を元に試作を更新する。
