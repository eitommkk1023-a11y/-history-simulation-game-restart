# RPGメニュー 試作03

インベントリ・マップ・ミッションを、ひとつのメニュー内のページとして切り替える操作試作。正式版への統合はまだ行わない。v31の単一HTMLを固定の基準とし、コピーへだけ試作用のUIと一時停止制御を追加する。

## 今回試せること

- 画面上の「メニュー」から開閉。最初の起動時はすぐ操作できるようメニューを開く。
- 3つの横タブ、PCのI / M / J / Esc、タブ上の左右キー。
- アイテムの種類別表示・詳細・所持数・重量・試作用の使用/装備切り替え。
- 所持品の上の武器/胴防具カード。装備中の品物を表示し、押すと対応する所持品の詳細を開く。
- 種類順/名前順/総重量順の選択。並べ替えても選択中の品物と装備を維持する。
- 本作と同じ生成世界の地図。北固定・現在地・拡大縮小・ドラッグ移動。
- 進行中/完了ミッションの一覧・詳細・追跡切り替え。
- メニュー中はゲームのアニメーション/移動/ジャンプ/時間経過の更新を止め、閉じると再開する。
- iPhone/iPadを想定した横667×375、844×390、1180×820のレイアウト。

所持品・ミッション・所持金・性能・報酬は仮のデータ。キャラクターの体力/攻撃力/見た目、採集、実ミッション達成処理、報酬付与は接続していない。メニューの操作を試すための版であり、RPG要素が完成した正式版とは扱わない。

## 本作からの分離

- 試作ブランチ: `codex/prototype-rpg-menu-v1`。基準はv31 commit `89d2ec73c9c96872c10c216501d410121f60f5b8`。
- 本作の `自然地理生成器.html`、地理生成、保存形式、main/地形開発ブランチは変更しない。
- コピーしたゲームのIndexedDBだけを `geo-world-saves-prototype-rpg-menu-v1` へ切り替える。本作の `geo-world-saves` へ自動保存しない。
- 試作用所持品/追跡設定は独立キー `woh:prototype:rpg-menu:v1` に保存。利用できない環境ではその場での操作を続ける。
- 一時停止ゲートはコピー内の5箇所のゲーム用RAF呼び出しにだけ適用し、ブラウザ全体のrequestAnimationFrameは上書きしない。
- 世界生成Workerはメニュー中も準備を続ける。地図は世界の読み込み完了後に表示される。

## ビルド

外部ライブラリは増やさずHTML/CSS/JavaScriptと既存のThree.jsを使用する。生成されたHTMLは依存ファイルを内包する。

```sh
node tools/build-rpg-menu-prototype.mjs /path/to/World-of-History-v31-development.html
```

入力v31 HTMLのSHA-256 `50a6f786eef5b641d0ec235f2111712d7acabd29e87542a75d802b2d993dd348` を確認し、異なる版への無断差し替えは停止する。v31チェックアウトの既存ビルダーから基準HTMLを再生成して渡すこともできる。出力は `exports/World-of-History-menu-prototype-v3.html`。以前の試作HTMLは上書きしない。UIブランチには過去の配布用HTMLが保存されていないため、試作03を新規追加する。

## 検証

```sh
node tests/rpg-menu-model.test.mjs
node tests/rpg-menu-v3.browser.cjs
```

モデルでは消費数の下限・装備スロット・並べ替え・旧保存データの互換性・保存値の検証を確認。Chromiumでは3画面サイズでレイアウトを測定し、装備枠からの選択、装備/解除の同期、並べ替え、使用・追跡・実世界地図のズームと移動・一時停止/復帰・状態保持・本作保存先へ書かないことを確認する。結果は `validation/rpg-menu-v3`。旧 `tests/rpg-menu.browser.cjs` は配布済み試作02用として残す。

ソフトウェアWebGL環境では元の3Dゲームの描画が重いため、移動やジャンプの検査は固定の短い待ち時間ではなく実際の状態変化を待つ。実機iPhone/iPadのSafariや本作での正式データ連携は未検証。

次のテストプレイでは「タブ移動のしやすさ」「アイテム詳細と一覧の幅」「地図の操作」「ミッションの読みやすさ」「戻った後に操作できるか」の反応を元に試作を更新する。

## 試作03での変更

- 既存データで装備できる武器/胴防具の2枠を一覧の上に置く。未実装の頭/脚/装飾品スロットは増やさない。
- 装備枠を押すと装備カテゴリに移り、その品物を選択する。空き枠の場合は所持している対応装備を選ぶ。これだけでは装備/解除しない。
- 詳細で「装備する/外す」を押すと、装備枠・一覧の装備中マーク・詳細の状態を同期する。装備を外しても所持数/総重量は変わらない。
- 並べ替えは表示順だけを変更。総重量順は1個の重さ×所持数が大きい順。名前順は日本語の名前で並べる。種類順は装備→食料→道具→素材で、同じ種類は既存の登録順を保つ。
- 並べ替えの好みを同じ独立保存キーに追加。以前のv1保存にこの項目がなくても所持品/装備/追跡を引き継ぐ。
- 所持品一覧を幅約7割に保ち、装備/使用時には一覧のスクロールを保つ。種類変更では先頭へ戻す。並べ替え後は選択品が見える位置へ移す。
- 新しいライブラリや画像アセットは使わず、既存のHTML/CSS/JavaScriptとSVGアイコンを使用する。地図・ミッション・一時停止の仕組みは維持する。

試作03の実機確認項目: 装備枠を押して詳細を開く→装備/解除する、種類/名前/総重量を切り替える、小さい横画面でボタンを押せるか確認する。Safari実機での開封・タッチ操作・再起動後の保存はユーザーによるテスト待ち。


## 試作02での変更

「画面いっぱいにして、メインを大きく、それ以外は最小限」というフィードバックに対応。

- ダイアログの1120×760上限と周囲の余白・外枠をなくし、ブラウザの表示領域全体を使う。Safari自体のツールバーを隠す機能ではない。
- タイトル/ページタブ/戻るを高さ約48pxの1列にまとめ、下部の固定説明欄をなくす。ノッチやホームインジケーターはsafe-areaで避ける。
- インベントリは一覧を約7割、選択した物の主要情報を約3割に配分。アイテムを大きくし、装備/使用ボタンはスクロール前から押せる配置。長い説明は「説明」を開いて読む。
- 地図の横の説明パネルをなくし、地図を広く表示。拡大/縮小/現在地/全体の4操作を右下へ小さくまとめる。操作ボタンの高さ44pxは維持する。
- ミッションの一覧をコンパクトにし、詳細を主領域にする。
- 所持品や地理生成の内容、正式版のソース/セーブ先は変えない。試作01のテスト所持品を引き続き使えるよう、試作データの保存キーはv1のままにする。

検証は全画面サイズの一致、本文への高さ配分、地図の占有面積、アイテムの大きさ、一覧/詳細の幅比率、主要ボタンが見えることを数値で確認する。既存の切替/使用/装備/追跡/地図移動/一時停止/復帰の検査も継続する。iPhone/iPadのSafari実機は未検証。
