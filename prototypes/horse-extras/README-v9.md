# 試作09 — 控えめな落馬とスティック発進

## 操作

停止中にスティックを前へ倒すと常歩、後ろへ倒すと後退を開始します。離しても選択した歩法を維持します。走行中に前後へ倒しても歩法は上がりません。加速・減速・停止・後退ボタンはそのまま使えます。馬車の御者席も同じ操作です。

停止ボタンを押したあと、スティックを倒したままでも再発進しません。一度中央へ戻して倒し直してください。走行中の後ろ入力で突然逆走することもありません。PCではW/Sで同じ発進、A/Dで操舵、R/Fで歩法、Space停止、B後退です。

停止時のその場旋回、常時表示のモーション、馬車6.6／14km/h、駈歩27km/h・消費なしを保持しています。

## 落馬

前方へ大きく飛ばす動きを抑えました。転倒開始から0.32秒は騎手を現在の鞍へ追従させ、馬が傾いてから、その側へ滑り落ちます。現在のfallクリップは馬ローカル+X側へ倒れるため、落馬も同じ側へ揃えました。キャラクターの上向きの打ち上げ・大きな前転・手足の開きをなくし、抱えるように曲げた姿勢へ変えています。カメラの落馬専用ズームアウトも外しました。

`launchRider` は上向き初速を与えず、vy=-0.2m/s、側方2m/s、前後方向の持ち越しをspeed×0.15・最大±1.1m/sに制限します。`fallSide`（既定+1）と`initialRoll`を受け取ります。元のfallクリップは変更していません。ホストは解放する瞬間の鞍ワールド座標・傾きから開始するため、横へ瞬間移動して落とす方式ではありません。

着地・起き上がり・徒歩への復帰、復帰ボタンやリセットは従来どおり。落下中に復帰しても騎手を馬上へ戻しません。「倒れたまま」の直接確認では鞍への待機を入れず、同じ側へ静かに落とします。馬車の転倒は引き続き切り離してから確認してください。

## コードの変更

- `locomotion.mjs`：`startAxis`の保持と閾値（開始±0.45、中央への解除±0.28）。停止状態・実速度0.08m/s未満の新しい前後入力だけで発進。ボタンの命令と停止命令を優先します。
- `app.mjs`：イベント・フレーム・ボタンの全経路で同じスティックYを渡し、押しっぱなし状態が途中で消えないようにしました。落馬は鞍追従中のattached状態と、解放後を分けています。
- `stunts.mjs`：側方への静かな落下、控えめな体の回転・手足、既存の接地・起き上がり。

新しいライブラリ・モデル・テクスチャはありません。main、battle.js、正式ワールド、旧HTML05〜08、モデル資産は変更していません。全身の物理ラグドールや馬車事故は今回も対象外です。

## 検証と再生成

```sh
node tools/build-horse-extras-prototype.mjs
node --test --test-isolation=none --test-reporter=spec tests/*.test.mjs
node tests/horse-v9.browser.cjs
mkdir -p validation/horse-v9/regressions
HORSE_HTML=exports/World-of-History-horse-prototype-v9.html HORSE_REPORT_DIR=/validation/horse-v9/regressions node tests/horse-battle-extras.browser.cjs
```

出力は `exports/World-of-History-horse-prototype-v9.html`、実行時は外部通信不要です。143単体テスト、新機能14項目と既存回帰25項目のブラウザ確認を使用します。実際の2本指停止、押しっぱなし防止、常歩・後退・馬車、鞍追従と解放、同じ側への落下、打ち上げなし、着地・再乗馬、横画面3サイズを確認します。

既存クリップとモデルの画素・シルエット比較および5000頭描画は共有の回帰テストで確認。環境はChromium/SwiftShaderで、iPhone/iPad実機の速度は未測定です。
