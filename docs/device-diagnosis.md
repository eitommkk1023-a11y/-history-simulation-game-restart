# 実機の性能診断（iPhone/iPad）の手順

目的：実機の基準値（FPS・1か月の計算・保存の圧縮時間・メモリ）を取り、描画・計算・保存の優先順位を決める。ヘッドレス（ソフト描画）の値は実機とは別物なので、実機の値が必要。

## 準備
- 最新の試験版を開く（チャットのArtifact、または `World-of-History-small-world-trial.html`）。
- iPad/iPhone を**横画面**にする。他のアプリを閉じ、充電が十分な状態で、低電力モードはオフにする。

## 手順（約3分）
1. タイトルの左側で、段階を選ぶ（まず **S1**。次に **S3**、余裕があれば **S4**）。
2. 「小規模ワールド（試験）」を押す。世界ができるまで約20〜40秒待つ（この時間も控えておく：端末の起動時間）。
3. 神モードの右側の操作盤を下へ送り、「性能モニター」を開く。
4. 「**実機の性能診断（約25秒）**」を押す。25秒ほど、画面に触れずに待つ（視点が、近い・中・遠いと自動で動く）。
5. 下の枠に文章が出る。「診断おわり」と出たら、枠の文章を**全部コピーして貼り付けて**ください（自動でクリップボードにも入る）。
6. 段階を変えて（S3、S4）、2〜5を繰り返す。

## 一緒に教えてほしいこと
- 端末の名前（例：iPad Pro 11インチ 第3世代、iPhone 14 など）と iOS のバージョン。
- 世界の生成にかかった時間（手順2）。
- 体感：操作がカクつく所（近づいたとき・引いたとき・大きな村へ飛んだとき）、発熱、落ちたかどうか。

## 出力の見方
| 項目 | 目安（合格） | 意味 |
|---|---|---|
| 描画のFPS（近い・中・遠い） | 30以上 | 描画の滑らかさ。低い所が、描画の最適化の対象 |
| 三角形・呼び出し | 近い 20万・遠い 15万 程度 | 描画の重さの目安（実機のFPSと見比べる） |
| 1か月の計算 | 83ms未満（1年/秒） | 世界の計算。S3・S4 で超えると、計算の軽量化（F3）が必要 |
| 保存の圧縮 | 3秒未満 | 長い待ちが出る場合は、圧縮の見直し |
| メモリ | 端末の上限の半分以下 | 超えると落ちる。保存・世界データの見直し |

ヘッドレス（ソフト描画・参考値）：近い 3.5FPS・中 7.2・遠い 3.0、1か月 57ms（S1）、圧縮 5.3秒、メモリ 308MB。実機はこれより速いはず。
