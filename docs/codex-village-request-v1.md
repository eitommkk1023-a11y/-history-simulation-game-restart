# Codex への依頼：村の成長（農耕・牧畜）用の造形とメニュー画面

村が「採集の野営地」から「畑と家畜のある村」へ育つ段階を作り始めます（本編側の仕組みは私が作ります）。Codex には、**見た目の部品**と**メニューの「村」ページ**をお願いします。これまでと同じく、`main` は触らず `codex/*` のブランチで、Three.js r128・外部モデル/テクスチャ/有料サービスなしです。

## 優先順位
1. 畑と作物（最優先。村の成長がいちばん目に見える）
2. 家畜（馬の骨格テクスチャ方式を流用）
3. 村の施設（倉庫・井戸・家畜小屋など）
4. メニュー「村」ページの試作（試作06の続き）

## 1. 畑と作物
- 区画の形：畝のある長方形、棚田状の段、丸い菜園の3種ほど。1区画は 10〜30 m 四方、1つの村に 20〜200 区画。
- 作物は3系統（穀物＝背の高い穂、根菜・豆＝低い葉、実り物＝低木状）。世界によって穀物の種類が違うので、**色と背丈を値で変えられる**形に。
- **生育段階**：`0`耕した土 → `1`芽 → `2`伸びる → `3`実る → `4`刈り跡。段階と季節は1区画ごとに渡します。
- 渡す値（1区画）：`x, y, z, yaw, hw, hd`（半幅・半奥行 m）、`kind`（0畝/1棚田/2菜園）、`crop`（0〜2）、`tint`（色の変化 0〜1）、`stage`（0〜4）、`progress`（0〜1、段階の中の進み）。
- 描画は**インスタンス**で数回の描画命令に。200区画で数十万本の草を1本ずつ出さず、畝のテクスチャ＋少数の穂の群れなどでよい。近距離・遠距離で切り替える。
- 地形の傾きに沿わせる（高さは私が1区画あたり数点で渡します）。

## 2. 家畜
- 馬の仕組み（骨格テクスチャ＋インスタンス）を流用して、**4つの体型**：大型の牛系、中型の山羊／羊系、猪（豚）系、鳥（鶏）系。種の名前は世界ごとに変わるので、体型・色・大きさで見分ければ十分です。
- 動き：`idle` / `graze`（草を食べる）/ `walk`、牛系と山羊系は `lie`（寝そべる）も。
- 1頭ごとの値は馬と同じ形（`x,y,z,yaw,scale,speed,phase,state,stateT,coat`）＋`kind`（体型 0〜3）。
- 数の目安：1つの村に最大 200頭、近くを同時に描くのは 500頭まで。

## 3. 村の施設（形の部品）
次を、サイズ・材料の色・屋根の種類を値で変えられる部品に：
- 高床倉庫、穀物の貯蔵穴（地面の穴＋屋根）、干し棚、井戸、家畜の囲い（柵＋小屋）、共同の炉（広場の竈）、物見櫓（柵のある村用）、土器の窯。
- 既存の家の造形（`npc/arch-gen.js` の9種の共有の形、インスタンス描画）と**見た目が揃う**こと。壁は木・土・石、屋根は草・板・土の色違いで。
- 渡す値：`x,y,z,yaw,w,d,h`（m）、`role`（上の名前）、`wall`/`roof`（材料番号）、`state`（0新築/1通常/2老朽/3廃屋）。

## 4. メニュー「村」ページ（試作07）
試作06（`exports/World-of-History-menu-prototype-v6.html`）に**「村」タブ**を足した試作を。データはダミーでかまいません。
- 上：村の名前、段階（野営地／半定住／村／大きな村）、人口、世帯数。
- 食料：蓄え（日数）、1日の収入（採集／農耕／牧畜の内訳の棒）、季節。
- 建物の一覧（種類ごとの数）と、「建てる」候補（倉庫・井戸・家畜小屋・畑の拡張）。候補には、必要な材料と日数が出る。
- 指導者の操作：**分配**（食べ物を何割分けるか）、**建設**（候補を選ぶ）、**提案**（畑を広げる／家畜を増やす／移る）。押すと、メニュー内で確認する形。
- 小さい画面（横長のiPhone 874×380）で、すべてが1画面で完結すること。
