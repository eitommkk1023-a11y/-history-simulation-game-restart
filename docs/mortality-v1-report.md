# mortality-v1 報告（死と猶予・継承）

前段 vitals-v1（体力・スタミナ・水分）の上に、「死」を入れた。標準は「死ぬ」で、予告・猶予・助かる手段つき。「死なない」も設定で選べる。

## 仕様
- **猶予は3日**（ゲームの時計）：体力が0になると「瀕死」になり、3日のうちに体力を15以上へ戻せなければ亡くなる。体力が1以上になっても15未満の間は猶予の日数は止まるだけで、再び0になると続きから数える。時間を長く飛ばしても1日ずつ計算するので、猶予は正しく効く。
- **助かる手段**：水を飲む（体力が30未満のとき＋6）、食べる（おなかが600kcal未満のとき＋6）、配給をもらう（＋6）、家で眠る（＋25）、焚き火のそばで野宿（＋10）。これらを繰り返して15以上に戻せば猶予はリセット。
- **死因**：その時いちばん効いていた原因（渇き−12／日・飢え−8／日・寒さ最大−10／日・病気−3／日）。
- **予告**：体力30未満で画面の縁が赤くなり、「体力が少ない」の帯。瀕死中は強い赤と「あとN日のうちに…体力を戻さないと死ぬ」の帯。喉の渇きの予告もある。
- **継承**：亡くなると既存の継承の決まり（文化ごとの7種）で後継者が決まる。後継者が居ない場合は別の一族の人物として続く。死亡の画面に、死因と後継者を出す。歴史にも記録される。
  - 後継者へ引き継ぐ物：**家・貯蔵庫・評判の半分**・目標の進み。引き継がない物：持ち物・焚き火・水さらし・体調（体力・スタミナ・水分は満タンで新しく）・教わった記録。
  - 別の一族として続く場合は、家・貯蔵庫・評判も引き継がない（目標の進みだけ残る）。
- **設定**：メニューの「死亡：あり／なし（瀕死で止まる）」で切り替え。「なし」では体力は1で止まり、亡くならない。選択は端末に覚え、新しい世界にも使う。記録にも入る（古い記録は「あり」で読み込む）。
- 修正：ブラウザ向けの書き出しに `peopleSuccession` が無かったので追加。

## 検証（合格）
- Node 単体 275件（猶予の数え方・死因・長い飛ばし・助かる各手段・リセット・「死なない」設定・継承の引き継ぎ範囲・別の一族・保存と壊れた保存）。既存の継承テストも通過。
- Playwright：渇きで体力0 → 予告の帯と赤い画面 → 水を飲んで助かる → 3日放置で亡くなる → 死亡の画面（死因・後継者・引き継ぎの説明）→ 人物が代わる（第2代）→ 家と貯蔵庫が残り、持ち物は空・体力満タン → 歴史に記録 → 「死亡なし」に切替えて10日放置しても体力1で生存 → 保存。エラー0。
- 回帰：deathtest / vitaltest / hudtest / tiestest / foragetest / cooktest / hometest / avatartest / peopletest 通過。

## 未実装・未確認
- 怪我・毒・熱中症・獣に襲われるなど、急な死因は無い。死因は渇き・飢え・寒さ・病気（体調不良）が中心。
- 「死亡なし」の選択はメニューのみ（タイトル画面の設定には出していない）。
- 後継者が未成年のときの扱いは既存の継承の仕組みのまま（成人まで補助）。死亡の画面の文言は簡素。
- 救済（仲間が自動で助ける）は配給をもらう操作に限られ、自動では起きない。係数（猶予の日数・応急の量）は暫定。実機は未確認。
