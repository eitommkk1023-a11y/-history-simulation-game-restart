# 民族の言語と名前（報告）

ブランチ：`claude/npc-names-v1`（`claude/npc-social-v1` から）。

## 入れたもの
- **民族ごとの言語**：仮の言語（語族の祖先）から、民族の位置に近い祖先の言語を選び、近くの同じ語族の民族の言語から分化させる（以前作った `people_lang` を移植）。言語は保存・読み込みに含まれる。
- **民族名・集団名**：民族の言語で付ける（例：「ゲヘレ族」「ネアグの民」）。重なり・似すぎは避ける。分裂でできた集団にも、毎月の処理のあとで名前が付く。
- **地名の付け直し**：民族の住む所（地名の優先度に応じて40〜100ブロック以内）の地名を、その民族の言語で付け直す（新しい世界のときだけ。プレイヤーが改名した地名・遠い所は変えない）。保存・読み込みでは、保存した付け直しを戻す。
- **人物の名前**：民族の言語から、個人IDごとに毎回同じ名前を作る（保存しない。同じ名前の人がいてもよい）。
- **表示**：情報パネルの「あなた」「首長」「自分の民族」、近くの人の情報カード（名前・民族名）、出来事（民族名・集団名・首長・跡継ぎの名前）。

## 確認（ブラウザ）
- Seed 42 を2回作って、民族名・集団名・人物名・地名が同じ。
- 保存→読み込みで、民族名・人物名・地名・付け直しの数（102）が一致。
- 例（Seed 42）：民族「ゲヘレ族」「イケセ族」、集団「ネアグの民」、あなた「ニョンリキャ・男・21歳」、首長「フェエ」、地名「アト大陸」「キャシュア島」。
- 提案・首長・継承・岩石・開発者モード・キャラクターの移動も、エラーなし。

## 修正したこと
- 読み込みのときに、移動した集団の周りの地名をもう一度付け直してしまい、保存前と名前が変わった（102→112）。付け直しは新しい世界のときだけにした。

## 注意・未解決
- 人物の改名・愛称・家名（世帯の名前）はまだない。名前が同じ人は、民族が同じなら出る。
- 言語の分化（時間がたつと言葉が変わる）と、民族の融合による言語の混合は、`languageSplit`/`languageMix` の関数だけ。使うのは民族の形成・分裂・融合のとき。
- 地図に民族名・集団名は出さない（台帳には入っている）。
