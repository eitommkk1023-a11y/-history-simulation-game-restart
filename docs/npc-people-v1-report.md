# NPC を v30 の民族・集団につなぐ（報告）

ブランチ：`claude/npc-people-v1`（`claude/npc-needs-v1` から）。ゲーム本体：`World-of-History-v30-development.html`。

## 方針（決めたこと）
- 人口の本体は NPC（全住民に個人ID）。集団の年齢別の人数は、NPC から数えた「集計」。
- セーブは「人の状態そのもの」を保存する（毎日の出生・死亡の結果は Seed から作り直せないため）。地形などは今までどおり Seed から作る。

## 作ったもの
- `npc/people-core.js`：民族・集団の配置（川沿い）、食料（採集・狩猟・漁）、移住・分裂・接触・全滅、保存と読み込み。以前の「集団ごとの数値」の部品を、NPC の上に載せ替えたもの。
  - 集団の食料の収穫 ＝ 採集者・狩人・漁師の人数と技能（NPC の職業と技能から）。仕事に就いていない10〜13歳と他の仕事の人は、一部が採集を手伝う。
  - 食料の充足・寒さ・病気が、個人の毎日の死亡率・出生率に反映される（`hazardFn`/`fertFn`）。
  - 仕事の必要度は、集団の環境から期待される収穫の最適な割り振りに合わせる（人々は少しずつ、足りない仕事へ移る）。
  - 分裂は家族（夫婦と子ども）ごと。
- `npc/npc-core.js`：集団を増やす `ensureGroups`、集団間の移動 `moveToGroup`、集団の状況を反映する口を追加。職業選びの「空き具合」の効きを強めた。
- ゲーム本体：新しい世界で人々を作る／毎月進める（`monthlyTick`）／出来事を記録（`postEvent`）／セーブ・ロード／情報パネルに「人口」「自分の民族」。

## 測定
- Node（Seed 42、`npc/test-people.js`）：初期 約11,000人・100民族・100集団。50年で約6,900人に緩やかに減って落ち着く（食料の充足 約0.99、食料の内訳 採集 約52%・漁 約48%・狩猟 1%）。1か月の計算は平均 約10ms。
- 生命表（飢え・病気・寒さ無し）：15歳まで生き残る割合 0.506、平均寿命 29.4年。以前の表（理論値）と一致。
- ブラウザ：起動時 約9,500人、5年進めて約8,500人、出来事 約150件。保存→読み込みで人口・集団数が一致、読み込み後も続けて進められる。人々の保存は 約0.5MB。メモリ：描画プロセス 約410MB（人々を足す前 約455MB、測定のばらつきあり）。
- 同じ Seed なら同じ初期配置・初期住民（乱数は固定順）。

## 注意・未解決
- 以前の方式は「年の初めに加齢」する作りで、乳児期の死亡が実質半分だった。NPC は研究値どおりなので、出生の補正（`FERT_ADJ`＝1.3）で人口が落ち着くように合わせた。TFR は約5.9で、研究の範囲（4〜6）の上限。
- 最初の10年は、仕事の割り振りが環境に追いつくまで人口が約2割減る（以前の方式でも約1割減った）。
- 古い記録（人々が無い）を読み込むと、その日から新しい人々が始まる。
- 保存→読み込みは人口・集団が一致するが、「そのまま続けた場合と完全に同じ結果」になるかは未確認（結婚候補の列は保存している）。
- 民族の名前・言語は仮（「第N民族」「集団N」）。言語・名前の付与、集団の地図上の目印、集団の詳細画面（以前の people_lang・people_ui）は未移植。
- 100万人規模・iPhone 実機の速度は未測定。
