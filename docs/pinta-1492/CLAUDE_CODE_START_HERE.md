# Claude Code 最初に読むファイル

ユーザーの目的は **『World of History』で1492年の「ピンタ号（La Pinta）」を史実に可能な範囲で忠実に3D再現して、プレイヤーが甲板に立てる・船長へ航海を委任できるモデルにすること**。

このフォルダのファイルを読む順序：
1. `PINTA_1492_RECONSTRUCTION_SPEC.md` — 史料、設計全体、注意点、実装段階（必読）
2. `pinta_1492_reconstruction.json` — 機械可読プロファイル／曖昧性／根拠ラベル
3. `IMPLEMENTATION_CHECKLIST.md` — 実装時の作業順序と完了条件

## 最初の依頼

既存リポジトリを調査し、自然地理・気象・Three.js・船舶物理・NPCの既存APIを確認した後、`research_compact_1690` 復元案の船体3Dモデルを実装してください。**原船の実測図は現存しないので、数値の確度を誤認しないこと。**

まず船体メッシュ・舵・3本マスト・基礎的な帆装・甲板を表示し、人物と1:1の大きさで並べ、甲板を歩けるようにしてください。史実に根拠のない装飾や後世の武装は追加しないでください。その後に帆走・航海委任・船内・損傷へ進めてください。

- **サブエージェント禁止、単一エージェントで進める。**
- 実装・検証を小単位で進め、段階が終わったらコミットする。不要な再調査、重複検証を避ける。
- レポートでは「実装済み」「暫定値」「史料に異説」「未実装」を必ず分ける。
- 他のシステムの仕様を勝手に変えない。

**注記**：寸法の基準案は船長16.90m・幅5.00m・軽荷時喫水1.58m（学術的な復元案）で、原船の証明された実寸ではありません。歴史的容量約40.10 toneladas de arqueoを排水重量と混同しないでください。帆装の変更対象は史料解釈に争いがあるため、代替プロファイルを保管してください。
