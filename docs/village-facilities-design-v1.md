# 村の施設・保存・土器・開始時代：既存の仕組みの確認と、解放条件・数値の案（v1）

マネージャー方針（Codex 経由）：開始時代は「農耕が始まり、採集・狩猟・牧畜が併存している頃」。施設は仕組みをまとめて作るが、開始時からすべては使えない。保存は食品ごとに向き不向きを分ける。土器は低温焼成から。地域ごとに違う暮らしが併存する。

## 1. 既存の仕組みの確認（事実）
| 項目 | いま | 方針とのずれ |
|---|---|---|
| 開始時の技術 | 栽培・牧畜・銅・首長制は**持たない**（発明・伝わりを待つ）。栽培は自然に約270年後 | **方針と逆**。開始時に、一部の地域が持つ形に変える |
| 栽培に向く民族（野生の穀物が近い） | 100民族中 **29** | 地域差は元からある（残り71は、伝わらないと始められない） |
| 牧畜に向く民族 | 100中100（向き具合は0.6〜1.0） | 向き具合で、開始時に持つ割合を変える |
| 土器 | 技術「土器」は**83民族が開始時から持つ**（粘土が近い所）。暮らしの個人側にも土器（使用25回、煮る・水を運ぶ） | 低温焼成として**そのまま使える**。高温焼成の技術は未実装 |
| 集団の食料の保存 | 食料は**1つの数字**。腐る割合は気温だけ（月8〜22%）。穀物が多いと腐りにくい（平均）だけ | **食品ごとの向き不向きがない** |
| 個人の持ち物の保存 | 食品ごとに腐る速さがある（肉30%／魚25%／貝20%／果実10%／根2%／木の実の加工品1%／干し肉・干し魚0.8%）。干して保存食にできる | 集団の側にも、この表を使える |
| 村の段階 | 野営地→半定住→村→大きな村（村で人口120以上、農産物3割以上） | 解放条件に使える |
| 施設（作ってある） | 倉庫・井戸・家畜の囲い・畑の拡張。倉庫は「蓄えられる量+35%」だけ | 食品ごとの保存に作り直す |
| 「みんなの炉」 | 暮らしの側に**すでにある**（炉で調理、薪をくべる、配給、評判）。村の「共同の炉」はこの発展形にできる | 新規ではなく、既存と統合 |

## 2. 開始時代の作り方（案）
- 民族ごとに、開始時に持つ技術を、**場所の向き×文化の開き**で決める。
  - 栽培：向き（野生の穀物・肥沃さ）が高い民族のうち **約6割**（全体で約15〜20%）が持つ。残りは採集・漁・牧畜中心。
  - 牧畜：向き具合に応じて **約4割** が持つ（栽培との両立も、牧畜だけも、どちらもない民族もある）。
  - 灌漑・輪作などは開始時には持たない。
- 伝わり（近くの民族から）は今のまま。**発展の速さは、民族ごとの向き・文化で変わる**ので、全地域が同時には進まない。
- あなたの民族がどの暮らしから始まるかは、世界ごとにばらつく（農耕あり・牧畜あり・採集漁労中心）。
- この変更で、「栽培が約270年後」という課題も解消する（③の速さ調整は、伝わりの速さだけの話になる）。

## 3. 施設の解放条件（案）
| 施設 | 解放の条件 | 区分 |
|---|---|---|
| 焚き火 | 常に | 開始時から（既存） |
| 簡易な貯蔵穴 | 半定住以上（動かない集団） | 開始時から |
| 干し棚 | 半定住以上 | 開始時から |
| 倉庫（高床） | 村 かつ（栽培を持つ か 農産物が3割以上） | 村の成長で |
| 家畜の囲い・小屋 | 牧畜を持つ かつ 半定住以上 かつ 家畜8頭以上 | 村の成長で |
| 共同の炉 | 村 かつ 人口60以上（既存の「みんなの炉」の発展） | 村の成長で |
| 窯（高温焼成） | 新技術「高温焼成」を持つ かつ 良い粘土が近い | 技術・地域で |
| 物見櫓 | 首長制を持つ（見張り・警報の仕様と合わせて設計。それまで建設候補から外す） | 技術・地域で（後回し） |

野営地（移動して暮らす）の段階では、貯蔵穴・干し棚も建てられない（建てても置いていくため）。

## 4. 保存：食品の分類と、施設の効き（案）
集団の食料を **3つの蓄え**に分ける（いまは1つの数字）。月ごとの傷み（25℃、基準）は、個人の持ち物の表と同じ考え方。

| 蓄え | 中身 | 基準の傷み／月 |
|---|---|---|
| 穀物・根・木の実 | 農耕の穀物、採集の根・木の実・草の実 | 2% |
| 生鮮 | 肉・魚・貝・果実・野菜・乳 | 25% |
| 干物・燻製 | 干した肉・魚・果実 | 0.8% |

気温が高いほど傷みは増える（いまの式と同じ）。
| 施設 | 穀物・根・木の実 | 生鮮 | 干物・燻製 | そのほか |
|---|---|---|---|---|
| 簡易な貯蔵穴 | ×0.5（冷暗）。湿った土地では×0.8 | **×1.3**（湿って傷みやすい） | ×1.0 | 蓄えられる穀物+25% |
| 高床倉庫 | ×0.6（風通し。ネズミ・虫の害で上限あり） | ×1.0 | ×0.8 | 蓄えられる穀物+50% |
| 干し棚 | — | 生鮮の余りを、**干物に変える**（棚1つで月に約20kg相当。雨の多い月は効きが半分） | — | 魚・肉の多い地域ほど価値が高い |
| 共同の炉 | — | 一部を調理して傷みを遅くする（×0.7） | — | 食料が足りないとき飢えが和らぐ／評判 |

→ 貯蔵穴は穀物・根の施設で、生鮮には**逆効果**。生鮮の対策は干し棚と炉。

## 5. 土器（案）
- **低温焼成（野焼き）が出発点**＝いまの技術「土器」。
- **高温焼成は、後の新技術「高温焼成（窯）」**（前提：土器。銅より前に置く）。
- 土器の品質は、焼成温度だけでなく、次の3つの合成で決める。
  品質 = 0.3×粘土の質（その土地の粘土）＋0.3×成形の技能（職人の知識）＋0.4×焼成（野焼き0.3／穴窯0.5／窯0.8）
- 品質の効き：割れにくさ（使用回数 25回→最大60回）、水を運べる量、貯蔵壺として使うと穀物の傷みがさらに×0.85。
- 高温焼成は、窯（施設）を建てた集団だけが作れる。

## 7. 決めてほしいこと（マネージャーへ）
1. 開始時の栽培・牧畜を持つ割合（案：栽培＝向きの高い民族の約6割、牧畜＝約4割）。多め／少なめの希望。
2. 野営地（移動して暮らす）では、貯蔵穴・干し棚も建てられない案でよいか。
3. 干し棚の効き（棚1つで月約20kg相当）と、貯蔵穴の生鮮への逆効果（×1.3）は、強さの感覚として妥当か。
4. 高温焼成を新しい技術として足す（技術が22→23になる）でよいか。

# 実装（claude/food-stock-v1）：マネージャーの回答を反映

回答：①開始時の技術は始まった場所による、②干し棚は野営地でも建てられる、③効きの強さは妥当、④高温焼成は高度で、この時代には現れないこともある。

## 実装したこと
- **開始時代**（A）：栽培・牧畜は、**場所（必要な資源の近さ）×文化の開き**で、一部の民族だけが開始時に持つ。固定の割合は決めていない。測定（同じ世界・5つの乱数）：栽培 9〜13民族、牧畜 38〜41民族、どちらも持たない 47〜56民族（100民族中）。残りは、伝わりを待つ。
- **高温焼成**（新技術・窯）：前提は「土器」と「首長制」、人口300以上、良い粘土。高度なので自然には現れにくい（この時代に現れないこともある）。技術は22→23。
- **保存の3分類**（B）：食料を「長持ち（穀物・根・木の実）／生鮮／干物」に分けた。傷みは 2%／15〜30%／0.6〜1.2%（月、気温で変わる）。食べるのは生鮮→長持ち→干物の順。採集した食料の55%は長持ち扱い。
- **施設の効き**：貯蔵穴＝長持ちが×0.7（生鮮は×1.3の逆効果）、倉庫＝長持ち×0.6・干物×0.8、干し棚＝生鮮の余りを月200kgぶん干物に（寒い月は半分）、共同の炉＝生鮮×0.7＋飢える人が15%減る。蓄えられる量は、貯蔵穴+25%・倉庫+50%。
- **解放条件**（C）：開始時から＝貯蔵穴（半定住以上）・干し棚（野営地でも可）・井戸（半定住以上）。村の成長で＝倉庫（村で、栽培か農産物3割）・家畜の囲い（牧畜・半定住・家畜8頭）・共同の炉（村で人口60）。技術・地域で＝窯（高温焼成）。**物見櫓は、候補にない**。
- 村ページ：全施設を表示し、未解放のものは条件を表示。蓄えの内訳（穀物・根／生鮮／干物）も表示。3Dには貯蔵穴・干し棚・炉・窯も出る（Codexの部品）。
