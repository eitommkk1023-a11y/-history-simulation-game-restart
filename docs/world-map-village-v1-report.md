# 世界マップ：村の表示と集落詳細（報告）

## 1. 実装内容
**世界マップ（既存の「マップ」タブに追加。新しい仕組みは作っていない）**
- 開発者モード：全集団（未探索を含む）を表示。通常プレイ：自分の集団（★）だけ。既存の「探索・情報伝達」の仕組みはゲーム内にまだ無いため、通常プレイでは他の集団を出さない（今後その仕組みができたら `mapVilList()` の1か所で絞り込む）。
- 発展段階の区別：丸＝野営、三角＝半定住、四角＝村。輪の色＝立地（川・海岸・湖畔・湧水）。大きさ＝人口。
- 表示モード：通常（発展段階）／人口・居住（色の濃淡）／民族・文化（民族の色）／生産・経済（いちばん多い生業の色）／建築物・道路（集落詳細）。
- 数字の意味：「数字＝その集団の人口（人）」「＋N＝近くて重なった集団の数（タップで拡大）」「★＝あなたの集団」を、パネルの凡例に明記。
- 密集対策：近い印は大きい集団を優先して「＋N」にまとめる。数字は重なる場合は出さない（選択中・自分の集団は必ず出す）。縮尺で印の大きさも変える。
- 操作：ドラッグ移動、ピンチ拡大縮小（指の中心を基準）、ホイール、タップで選択、選択中の印をもう一度タップで集落の内部へ、空き地のタップで選択解除、「現在地」「全体を表示」「情報を閉じる／開く」、距離スケール（m・km）。
- 外部連携：`window.__wohMap.focusVillage(集団ID, {detail:true})` で、村を選んで世界マップへ移動／集落詳細を開く（世界統計・ランキングからの呼び出し用）。

**集落詳細（既存の `g.layout` の座標とIDをそのまま描く）**
- 建物の位置・輪郭（回転した長方形／円形）・用途（色）・状態（使用中／空き家＝破線／廃屋＝灰）・入口。
- 道（太さ＝通る家の数）、広場／焚き火、水場、柵（境界。定義があるときだけ）、畑、集団が建てた施設（位置が決まっているもの）、建設中の予定地。
- 地形：配置の原点の周り200mを既存の地形から測って描く（水・陰影）。
- 建物をタップ：用途・状態・利用者（世帯ID・人数・親族）・築年・壁と屋根の材料・基礎・大きさ・中心からの距離・ID。
- 層の切替（地形／道／建物／施設）、距離スケール。
- 未生成の集落：通常は「まだ見ていない集落です」と表示。開発者モードだけ「配置を作る」でき、これはゲームが近づいたときに作るのと同じ関数（`dwEnsure`）を呼ぶので、後で3Dで見る集落と一致する（別の生成はしない）。

## 2. 検証（ヘッドレス・ソフト描画）
- 世界マップ→モード3種→村を選択→集落詳細（150棟）→建物タップで詳細→拡大→パネル開閉→世界へ戻る→未生成の村を作って表示：全て成功、エラーなし。通常モードでは一覧・開発者ボタンが出ない。
- 全17本の回帰テスト：エラーなし。
