# 古い造山帯の見直しと生成時間の短縮（rock-24-v3）

対象：`World-of-History-v30-development.html`（ブランチ `claude/orogen-and-speed-v30`、`claude/rock-geology-v30` の続き）

## 1. 古い造山帯が陸の約3割になる原因（Seed 42、初期の大陸の区画）
初期の大陸で、安定地塊（CRATON）でない区画を古い造山帯（OROGEN）にしていた（`simulateTectonics`）。条件は次の3つの和。

| 条件 | 効いた割合 | その条件だけで造山帯になった割合 |
|---|---|---|
| 安定地塊のノイズ（`fbm(cratonN) > -0.25`）が低い | 23.7% | 17.2% |
| 海岸から7区画（約190km）以内 | 17.8% | 11.7% |
| 縫合帯のノイズ（`ridged(beltN) ≥ 0.72`、線状の過去の衝突の跡） | 7.2% | 4.6% |

合計で初期の大陸の41%（最終的に陸の31〜37%）。**本来の造山帯の姿である線状の縫合帯は、7%しかなく、残りは塊状のノイズと、縁の一律の帯だった。**
参考：地球の大陸で、古生代以降の造山帯は、おおよそ1〜2割（調査・定義によって異なる）。

## 2. 変更内容（v3）
- 古い造山帯を、**線状の縫合帯（ノイズ0.70以上）と、大陸の縁の狭い帯（2区画＝約53km）だけ**にした。塊状のノイズの条件と、縁7区画の一律の帯はやめた。
  - `TEC_BELT_T = 0.70`、`TEC_MARGIN_CELLS = 2`［仮］。候補の割合（縫合帯の閾値×縁の幅）は、Seed 42・7・1で同じ傾向（0.72/2区画：約11〜13%、0.66/2区画：約17〜19%）。
  - 乱数の消費は変えていない（どちらの条件でも各区画で1回）。初期の地殻の種類以外の乱数の列は同じ。
- **世代 `rock-24-v3` を追加**（既定）。v3 は、岩石の地質（v2）＋造山帯の見直し＋気候の計算を1回にする。`rock-24-v1`・`rock-24-v2`・岩石なし（世代11）は従来のまま。
- 旧世代の結果が変わっていないことを、Seed 42 の標高・植生・陸海・岩石のSHA-256で確認した（v1・v2・岩石なしのいずれも一致）。

## 4. 生成時間の短縮
生成の内訳（Node、Seed 42、28.4秒）：岩石の侵食 5.2秒、気温 4.0秒、海岸線 3.1秒、地質年代 2.2秒、海流 2.1秒、気候区分 1.6秒、水系の特徴 1.5秒、日射量 1.5秒、火山島弧の補完 1.4秒、海域の判定 1.3秒、植生 1.0秒。気候（日射量・風・海流・気温・降水・気候区分・植生）は、岩石の侵食の前後で2回計算しており、2回目が約5〜5.5秒。

2回目が必要かを確かめた：侵食による標高の変化は、平均5.6m（中央値2.4m、95%の区画で22.5m以下、最大271m）。陸海の境目は変わらない。気候を作り直しても、気候区分が変わる区画は0.55%、年平均気温の差は平均0.03℃、年降水量の差は平均2.2mm、植生が変わる画素は0.49%だけ。

→ **v3 では、2回目の気候の計算をやめた**（侵食の前の気候を、そのまま使う）。

| | v2 | v3 |
|---|---|---|
| Node（Seed 42／7／1／12345、秒） | 27.1／25.9／26.9／27.3 | 21.3／21.1／22.9／22.1 |
| ブラウザ（swiftshader、Seed 42、秒） | 27.8 | 23.2 |

約5〜6秒（約2割）の短縮。岩石の生成時間（約3〜3.5秒）は変わらない。

## 6. 未解決・注意
1. 堆積岩は53〜60%で、参考の60〜75%の下限に届かない。割合に合わせる補正はしていない。残りの原因は、被覆の場（なめらかな乱数）の扱いと、盾状地の広さ（`ROCK_SHIELD_T`）で、堆積の履歴をプレートの計算側に持たせるのが筋。
2. `TEC_BELT_T`・`TEC_MARGIN_CELLS` は［仮］。造山帯を何割にするかは、地球の大陸の調査・定義で幅がある。
3. 山脈の数は、Seed 1 で14→10に減った（ほかの3つはほぼ同じ）。標高の分布は大きく変わらない。
4. 気候を1回にしたため、v3 の気候は侵食の前の標高に基づく（平均0.03℃の差）。v2 の世界とは、同じ Seed でも造山帯・岩石・植生が変わる。
5. 残りの生成時間：岩石の侵食 3〜5秒、気温・海流（1回あたり約2秒・約1秒）、海岸線 3秒。これらを短くするには、結果が変わる変更（侵食の段数や気候の反復回数）が必要で、今回は見送った。
6. 実機（iPhone）での生成時間は未計測。
7. 元のソース（`src/rocks/world-rocks.mjs` など）には、同じ変更を入れていない。
