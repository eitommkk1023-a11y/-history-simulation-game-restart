# ベローナ号(1760)の実装

Codex が作った「Bellona 1760 study(船内試作05)」のモデルを、船システムに載せた(ゲームの開発者メニュー「船(開発者)」→「ベローナ1760 74門艦」)。

## 実装済み
- **見た目**: 外観GLBを3段階(近・中・遠)で切り替え。船内GLB(部屋・家具・砲列甲板の砲)は、船内の断面表示のときに出す。帆桁・帆(`yard_*`、`sail_*`)は帆の角度に、舵(`rudder_pivot`)は舵角に追従。
- **物理の入力**(すべてモデルから測った値。`tools/bellona-extract-design.mjs` → `src/ship/bellona-data.mjs`):
  - 船体:全長56.0m、最大半幅8.1m、喫水5.4m(モデルのY=0を喫水線とみなす)。29断面。排水量は船体の体積から約2,100t。
  - 3本マストの横帆(各3枚):前檣269㎡、主檣348㎡、後檣182㎡。舵:位置と面積。
- **安定**:横傾斜10°で復原力0.2m、最大0.9m前後(`tests/bellona.test.mjs`)。
- **船内の歩行**:モデルの床・階段(連続した傾斜)・障害物(440)・天井をそのまま使う(ビューアーの `createShipNavigation` を移植)。梯子ボタンは無く、階段を歩いて上下する。8つの床(船倉・最下甲板・下砲列甲板・上砲列甲板・後甲板・前甲板・船尾楼・船首楼)。
- **乗員**:同民族の村人12人(レベルD)。舵輪・見張り・各マストの根元に配置(経路探索はまだ無く、持ち場に立つ)。
- **断面表示**:屋根(上の甲板)のある所では、すぐ上の甲板の下で切って中を見せる。甲板の反りを考えて、周囲の最も低い甲板の下に切断面を置く。
- 風・波・視界・計器・帆の手動操作など、これまでの船システムはそのまま使える。

## レベルD(ゲーム上の仮説)
- 質量の内訳(船体47%・バラスト16%・索具6%・砲と物資31%)、各重心の高さ、船体の抵抗係数、風圧面積、乗員数。
- 船内の配置は、モデル側の「暫定。区画の割り当ては未検証」のまま。砲の形は見た目だけ。

## 未実装
- 大砲の発射・戦闘、被弾による浸水、砲の数や口径(モデルに年代の砲身寸法が無い)。
- 乗員の経路探索(今は持ち場に立つだけ。船員が階段で移動する動作)、実際の乗員数(約600人)。
- 帆の膨らみ・はためき(ピンタ号の帆だけ)、帆の展開(絞る)の見た目。
- 浸水モデルへの接続(モデルの`waterExclusion`、区画の浸水箱は未使用)。
- 負荷:近距離・開けた甲板で、描画約450回・三角形約11.5万、船内で約16.6万。実機での測定が必要。
