# タイトル画面・ロード画面のイラスト組み込み（報告）

ブランチ：`claude/title-art-v1`（`claude/title-screen-v1` から）。画像：`docs/images/title-art-dev.png`、`docs/images/loading-art.png`。

## 組み込み
- **タイトル画面**：ユーザーが作ったイラスト（`1.jpg`）を背景にして、描かれたボタンの位置に透明なボタンを重ねた（続きから始める／新しい世界を創る／セーブデータ／開発者モード）。画面の縦横比が違うときは、イラストを中央に置き、左右は同じ絵をぼかして埋める。
  - 「続きから」：記録がないときは暗くして、「保存された記録がありません」を小さく表示。あれば日付・Seed を表示。
  - 「開発者モード」：イラストのスイッチを、オン／オフが分かるスイッチで上書き。オンのときは Seed 指定の欄が出る。
- **ロード画面**：ユーザーが作った10枚のイラスト（`2.jpg`）を1枚ずつ切り出して使う。1回のロードで、10枚から**ランダムに3枚**を選び、進み具合に合わせて切り替える（0〜33%、34〜66%、67〜100%）。イラストに描かれていた進捗バーは見本として扱い、**本物の進捗バーとパーセント表示**を重ねた。
- **進み具合**：世界の生成の段階（プレート・地形・気候・岩石・河川・資源など）から、測った所要時間の割合で計算した。最後の仕上げで 98% → 100%。
- 画像はHTMLに埋め込み（タイトル約300KB、ロード10枚で約320KB。ファイルは約1.4MB → 約2.1MB）。

## 確認（ブラウザ、横画面 874×402）
- タイトルの表示、開発者モードのオン・オフ、続きから・読み込み・タイトルへ戻る、通常モードで開発者向けが隠れること。
- ロード中の進み具合が 2% → 97% と進み、3種類の画像が切り替わる。完了まで約28秒（ソフトウェア描画）。
- 既存の確認（住民・岩石・開発者モード）もエラーなし。

## 注意
- イラストの文字（ボタンの文言）は画像の一部。文言を変えるときは、画像の差し替えが必要。
- 「続きから」の日付の小さな文字は、イラストの上に重ねている。
