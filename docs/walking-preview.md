# 歩行プレビュー v3

Safariで単体HTMLを開いて利用する。左スティックで移動、右側をドラッグして見回す。ダッシュは押している間有効。
PCではWASD/矢印、Shift、画面ドラッグ。設定内の「周辺を俯瞰」で同じ地形を見下ろせる。
設定は見出しをタップして折りたたむ。ChatGPT側の入力バーはこのHTMLから消せない。

現在の対象は9チャンクの地形上の歩行。端・急斜面・崖で停止する。全世界ストリーミング、LOD、ジャンプ、建物の衝突、歩行アニメーションは未実装。
半径0.25mの周辺点で足元を検査する簡易接地方式で、完全な人体カプセル衝突ではない。カメラは地形への線分交差で短縮し終点の高さを補正する。狭い隙間に対する球体スイープは後段。

既存世界生成を選ぶと元の3000×3000世界を生成するため、そのメモリ負荷は従来通り。初期表示は軽い固定地形。

## v4 操作変更
UIを隠す／表示で設定・説明を切替。スティック・ダッシュ・再表示ボタンは残す（俯瞰中のダッシュ非表示は維持）。
ダッシュはタップまたはShiftで切替。移動停止・障害物で停止・視点切替・フォーカス喪失で解除。待機中に押すと次の移動をダッシュにできる。
三人称の距離は12m固定。俯瞰だけ20〜300mのバーを利用し、左スティック／WASDはカメラを平行移動、右ドラッグは俯瞰カメラを回転する。人物は停止し、三人称の向きも保持。
検証: view-controls.browser.cjsで844×390 / 1180×820のUI切替、ダッシュ再押し・停止解除、俯瞰中の人物不動とカメラ移動を確認。既存歩行・同時タッチ検証とNode40件もPASS。Safari実機は未確認。

## v6 ダッシュ同時タッチ・ジャンプ
歩行スティック保持中の第2ポインターでダッシュが始まらないことをブラウザで再現。pointerdownで切替え、後続clickで二重切替しないよう分離。Enter/Spaceのボタン操作も対応。
ジャンプボタンとSpaceを追加。約1.27mの高さ、重力9.81m/s²、空中連打不可。地形基準の簡易ジャンプであり、横移動の既存斜面・境界制限は維持（崖越え物理ではない）。俯瞰切替時は着地させる。UI非表示中もジャンプを残す。

## v7 操作配置と移動アニメーション
右下の単一グリッドにジャンプ・ダッシュ・しゃがみを64px、間隔12pxで配置し、セーフエリアはパネル全体に一度だけ適用する。UI非表示でも操作ボタンは残る。
腕・股関節・膝を持つ簡易人型に、歩き・走り・移動中のジャンプ・しゃがみ・しゃがみ歩きの姿勢を追加。
しゃがみはボタン／Cの切替。しゃがみ速度0.65m/s、通常1.5m/s、走り4m/s。しゃがむとダッシュ解除、ダッシュを選ぶと立ち上がる。しゃがみ中はジャンプ不可、空中ではしゃがみを切り替えない。
地形専用の簡易ジャンプと足元判定を継続。建物や天井との衝突、崖越え物理は含まない。
検証: Chromium横画面667×375、844×390、1180×820で全操作ボタンの境界矩形が非交差、6動作の状態遷移、歩行時の脚の角度変化、UI非表示後の操作表示を確認。小型横画面の画像を目視確認。Safari実機は未確認。

## v8 円柱と関節を持つ人型
胴体・上腕・前腕・手・太もも・すね・足を円柱、首・肩・肘・手首・股関節・膝・足首を球と回転軸で構成。頭は球、身長は約1.7m。肘の姿勢と足首の逆回転を追加し、角度の切替を指数補間で滑らかにした。
同一フレーム内の重複描画を削減。既存の簡易地形接地・ジャンプを継続し、足固定IKや人体コライダーは未導入。
テストは固定秒数だけ待って着地とみなす方式から、実際の着地状態を待つ方式へ変更（低速なソフトウェア描画で早過ぎる判定が発生したため）。

## v9 近距離カメラと足先からの膝計算
三人称距離12m→4m。歩行時は足を14cm、走行時は26cm持ち上げる遊脚期間を導入。legPoseで足先の前後・上下目標から2本の35cm脚の関節角を解析計算。接地期間は足先の相対後退を実移動距離に同期。
これはキャラ足元の水平な接地面を基準にした簡易方式。足ごとの斜面追従や完全な足固定・走行中の両足離地は今後の調整対象。
検証: Node43件PASS。側面から歩行と走行を約100フレームずつ計測。遊脚高さ約14cm/26cm、最大膝角約92度/130度。両モードを3枚ずつ撮影し歩行1枚・走行2枚を目視確認。接地期間の高さ・近距離カメラと既存操作をブラウザで確認。Safari実機未確認。

## v10 歩行・走行サイクルの再構成
脚を片節42cmへ調整し、胴体と頭の比率を合わせて約1.7mを維持。v9の走行中の低過ぎる腰を解消。
human-gaitは歩行60%・走行38%の接地期間を使用。歩行は常に支持脚があり、走行には両足が離れる期間を持つ。蹴り出し・足の戻し・腕振り・上体の前傾と微小なひねりを別々に定義。
接地中の足の相対後退を実移動距離に同期。左右の足位置で地形を問い合わせて高さ差を反映（±12cm以内）。旋回は補間し、ジャンプ着地に腰の沈み込みを付与。
検証: 全Node45件、3横画面の6動作・配置、同時タッチのダッシュとジャンプがPASS。歩行/走行を約90フレーム計測し、各10枚の時系列画像を目視確認。まだ簡易円柱リグによる手続き的モーションで、実写モーションキャプチャや完全な足固定ではない。Safari実機での検証は未実施。
