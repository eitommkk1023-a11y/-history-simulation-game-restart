# NPC 段階3（最初の一歩）：欲求と、欲求に基づく職業選び

`npc/npc-core.js`、`npc/bench-needs.js`（測定）。ゲーム本体には未接続。

## 入れたもの
- **欲求7種**（生存・安全／家族／財産／権力・地位／信仰・思想／知識／自由）。強さは性格と年齢・家族の状況から計算（保存しない）。
- **職業の魅力**：各職業が欲求をどれだけ満たすか（`JOB_APPEAL`、仮の値）と、本人の欲求の「全体の平均との差」から決まる。職業を選ぶとき、向き・空き・親の職業に、この魅力が掛かる。
- **いま一番強い欲求**（`topNeed`）：欲求の重みを全体の平均で割り、まだ満たされていない度合いを掛ける。満たされ具合は呼び出し側が与える（まだ接続先がないので中間値）。
- **重要人物**（`promote`/`demote`）：第3層に上げる人を印付けして、理由・開始日・目標を持たせる。個人ID・経験・家族は維持する。

## 測定（10万人）
- 一番強い欲求（全体の平均と比べた違い）：生存・安全 4%、家族 22%、財産 3%、権力・地位 19%、信仰・思想 20%、知識 16%、自由 15%。
- 職業の違い：野心が高い人は交易者・警備者に 12.2%（低い人 7.0%）、好奇心が高い人は治療者・交易者・道具製作者に 20.3%（低い人 15.4%）、共感性が高い人は治療者に 11.0%（低い人 4.3%）。
- 環境の反映と職業の割合は、段階2のまま（漁の民族は漁師 26% など）。
- 転職は年約2.3%（予定どおり）。1年あたり約390ms。欲求の計算は10万人で約50ms。
- 同じ Seed で結果が一致。

## まだ作っていないもの（決める必要がある）
- 欲求の「満たされ具合」を決める状況（食料・安全・家族・財産）。経済・人口・政治の接続が必要。
- 意思決定の6段階の流れ（情報の認識 → 欲求の評価 → 行動の抽出 → 選択 → 実行 → 学習）のうち、今は「職業」だけ。結婚・移住・政治行動などの選択肢は未実装。
- 記憶・感情・人間関係。重要人物の詳細な思考。
- `JOB_APPEAL` と欲求の式の係数は、すべて仮の値。
