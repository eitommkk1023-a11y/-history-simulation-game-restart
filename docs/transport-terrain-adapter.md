# 交通・ナビゲーション: 自然地理データ接続（試作）

## 位置づけ
- 対象: `自然地理生成器.html` 内の `window.__geo.world`
- 実装: `src/transport/geography-adapter.mjs`
- 検証: `tests/geography-adapter.test.mjs`
- **自然地理生成器の本体HTMLは変更していない。** 本モジュールはHTML画面にまだ読み込まれておらず、ブラウザ上の統合動作は未検証。
- 人口・経済エンジンの実ソースはこのリポジトリには存在しないため、家計・交易・移住との直接統合はまだできていない。

## 調査した既存の地理データ
| キー | 内容 |
|---|---|
| `world.elev` | 3,000×3,000 の標高（m） |
| `world.type` | 陸域・海域 |
| `world.biome` | 植生・土地特性を表す分類 |
| `world.water` | 0=なし / 1=河川 / 2=湖 |
| `window.__geo.world` | 現在の生成済み世界を参照するための既存の公開口 |

地表のセル数が多いため、本試作は局所的な探索を想定し、展開件数に上限を設けている。既存の表示用 `heightAt()` は標高を平滑化するため、**経路の傾斜計算には `world.elev` の元データを用いる。**

## 利用例（別モジュール内）
```js
import { createGeographyAdapter } from './src/transport/geography-adapter.mjs';
const adapter = createGeographyAdapter(window.__geo.world);
const knowledge = new Set(['100,100', '101,100', '102,100']);
const result = adapter.route({x:100,y:100},{x:102,y:100},{
  knows:(x,y)=>knowledge.has(`${x},${y}`),
});
```

## 制約・未実装
1. **3,000×3,000は大域ナビの完成を意味しない。** 将来、階層型の広域・地域・詳細探索が必要。
2. 渡河地点・橋・渡し場データの接続は未実装。現段階では河川セルを保守的に通行不可にしている。現実の浅瀬を全面的に禁止する確定仕様ではない。
3. 人物ID別の地理知識の保存、斥候・商人からの情報取得は未接続。`knows` コールバックはそのための境界。
4. 道路階層、人工道路、所有・通行権、通行料、運搬設備、物流、人口・家計とは未接続。
5. 生物群系と勾配による減速係数、および約3.33km/セルは試験設定。世界の地理的スケールを変更した場合は再調整が必要。
6. この試作は実世界の地形配列を読み取れるが、実地形での全大陸経路探索、スマホ上の負荷、既存セーブデータとの統合は検証していない。
7. 渋滞・海上交通はユーザーの方針に従い保留。
