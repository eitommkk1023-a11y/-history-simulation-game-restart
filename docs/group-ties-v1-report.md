# group-ties-v1 報告（集団とのつながり）

個人の暮らし（採取・調理・道具・住まい）と、すでにある集団・住民の仕組みを結びつけた。ロジックは `npc/forage.js`、画面は持ち物パネルの「集団」欄と「話す」パネル。

## 仕様
- **みんなの炉**：自分の集団の野営地の中心（まわり1ブロック＝約33m）では、自分の火が無くても炉が使える。焼く・煮る・土器を焼くことができ、薪をくべると集団への貢献になる（評判＋1.5）。自分の火が無い場所では「みんなの炉」扱い。
- **評判**（0〜100。よそ者／顔見知り／仲間／頼られる人。1日に0.04ずつ薄れる）：
  - 食べ物を集団の蓄えに「分ける」：1kg（≒1,800kcal）あたり＋3。生の物は価値が6割。蓄えは本当に増える（集団の食料に加算）。
  - 薪をみんなの炉にくべる：＋1.5。住民に食べ物を分ける：＋0.8。技を教わる：＋0.5。
  - **配給**：おなかが空いていて（1,200kcal以下）、評判が8以上なら、集団の蓄えから1,400kcalをもらえる（2日に1度、評判−2、蓄えが足りないときは不可）。助け合いの流れ（余裕があれば分け、飢えたら頼る）。
- **近くの人と話す**：4.5m以内に住民がいると、右下の「調べる」が「話す」になり、パネルが開く。
  - 話す：その人の仕事・集団の食料の具合・あなたの評判に応じた言葉（同じ人・同じ時期は同じ言葉）。
  - 食べ物を分ける：その人の信頼＋6・好意＋8（相手から見たあなた。関係の枠がいっぱいでも、いちばん薄い関係を押しのけて必ず覚えてもらう）。あなたからの好意も少し上がる。
  - 技を教わる：その人の信頼が140以上で、その人がその道に30以上詳しく、あなたより10以上上のとき。5日に1度。技能が上がる（住民の成長の仕組みを使う）。
- **目標**を5つ追加（全16）：集団の人と話す／近くの人に食べ物を分ける／みんなの炉で調理する／食べ物や薪を集団に分ける／技を教わる。
- 保存：評判・分けた量・配給の日・教わった記録・話した日も記録に入る（古い記録も読める）。炉の位置は保存せず、そのときの野営地から毎回決める。

## 検証（合格）
- Node 単体 210件（炉の範囲・調理・薪・評判の段階と減衰・分ける/配給の各条件・信頼と教わる・枠が埋まった相手・話す・保存と壊れた保存）。
- Playwright（実際の集落・住民60人）：野営地でみんなの炉で焼く／薪をくべる／煮物を分ける（集団の蓄えが増える）／配給をもらう（+1,400kcal・すぐ2回目は不可）→ 住民のそばで「話す」ボタンに変わる → 話す／分ける×5／教わる（相手が詳しくないため断られた）→ 保存。エラー0。
- 回帰：hudtest / foragetest / cooktest / hometest / fptest / avatartest / peopletest / proptest / titletest / devtest 通過。
- 発見して直した不具合：みんなの炉に薪をくべたときの表示エラー（日数が無い）、関係の枠が埋まった相手に分けられない問題。

## 未実装・未確認
- 「近くに家を建てる利点」は、距離の表示とみんなの炉（野営地の中心）までに留まる（家そのものの恩恵は無い）。
- 住民の反応は言葉と数値のみ（笑顔などの見た目や、住民が自分から話しかけてくる動きは無い）。教わる成功の画面確認は、詳しい住民が近くにいなかったため Node のみ。
- 評判は集団の首長・提案（既存の仕組み）にはまだ影響しない。結婚・仲間入り・集団の乗り換えも未対応。
- 係数（評判の増減・配給量・信頼のしきい値）はすべて暫定。iPhone/iPad の実機は未確認。
