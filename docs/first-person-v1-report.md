# first-person-v1 報告（1人称視点の切り替え・試作）

## 背景
ユーザーの指摘：別で作っているキャラベル船は小さく、3人称では内装が見にくい。将来、家の中に入る場面でも3人称だとカメラが壁にめり込んで見えない。→ 3人称を標準のまま、1人称へ切り替えられるようにする。

## 仕様
- 右下のボタン「視点：3人称／1人称」、またはキーボードの V で切り替え。標準は3人称。選択は端末に覚える（localStorage。読めない環境でも動く）。
- 1人称：カメラを目の高さ（立ち1.58m、しゃがみ1.0m、ジャンプ中は体に追従）に置き、自分の体は隠す（体の描画だけを消し、位置や当たり判定は同じ）。視野角を 55° → 72° に広げる。
- 視線：画面の右半分のドラッグで見回す（右へドラッグ＝右を向く、下へドラッグ＝下を向く）。上下は ±77°まで（3人称は元の範囲のまま）。歩く向きは視線の向き（W＝前）。
- 地面にめり込まないよう、カメラは地面より常に0.5m以上上に保つ。3人称へ戻すと元の見え方に戻る。
- 俯瞰（地図）モードには影響しない。

## 検証（合格）
- Playwright（iPhone横画面）：切り替え（ラベル・視野角・体の表示 30/30 ↔ 0/30）、ドラッグで見回し、Wで前進（4秒で約3〜6m・ソフトウェア描画のため遅い）、Vキーでの切り替え、1人称で家・焚き火を作って見る、3人称へ戻す。エラー0。スクリーンショットで足元の草・地平線・家の屋根が目の高さで見えることを確認。
- 回帰：gotest / avatartest / proptest / titletest / devtest / hometest 通過。

## 未実装・未確認
- 家の中に入る・内装は未実装（今の家は外から見るだけの仮の形）。1人称はその準備。
- 実機（iPhone/iPad）での操作感は未確認。特に右半分のドラッグがボタン配置と干渉しないか、酔いやすさ、視野角72°の適否。
- 1人称では自分の手や持ち物を表示しない（道具を持つ見た目は未対応）。
- 視線の感度（0.006 / 0.005 rad/px）は3人称と同じ暫定値。1人称では高め/低めの調整が必要かもしれない。
