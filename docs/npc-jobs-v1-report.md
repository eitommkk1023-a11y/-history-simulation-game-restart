# NPC 段階2：職業・技能・成長（測定報告）

`npc/npc-core.js`（独立モジュール、ゲーム本体には未接続）、`npc/bench.js`（測定）。

## 先に変えたもの：項目の絞り込み
- 性格 10軸 → 9軸（協調性・積極性を削除、信頼傾向を新設）。認知 8 → 7項目（理解力を学習力に統合）。身体は5項目のまま。潜在能力は能力（認知7＋身体5）ごとに12個。
- 項目の順番は変えない（末尾にだけ足す）ので、後から足してもセーブはずれない。

## 仕組み
- **職業**：11職業＋無職。14歳で見習いとして選ぶ。選ぶ重みは、「空き（その民族で必要なのに足りていない仕事ほど高い）× 向き³ × 親（父）の職業（×1.6）× ばらつき」。今の職業には慣性（×1.5）。
- 農民・牧畜従事者・交易者は、その民族が栽培・飼育・取引の条件を満たすときだけ選べる（`setGroup`）。
- **向き**：職業ごとの能力・性格の重み付き平均（例：治療者＝器用さ・共感性・注意力・学習力）。
- **成長**：1か月あたりの成長量 ＝ 訓練量 × (0.5＋潜在能力) × (1 − 現在値÷255) × 年齢係数。小さな成長は確率的な丸めで整数の配列に積む。潜在能力は上限ではなく、伸びやすさだけを決める。
- **技能**：職業ごとに1つ（採集・狩猟・漁労・材料加工・建築・輸送・治療・警戒・農業・家畜管理・商業）。伸びは学習力に比例し、技能が高いほど伸びにくい。`practice()` で本業以外の活動でも伸ばせる。
- **年齢**：成長期（認知は18歳、身体は20歳まで）と衰え（身体は30歳〜、瞬発力・敏捷性は速く）を、能力の現在値に掛ける。
- **引退**：60歳から月3%で引退（無職）。まれに転職（月0.2%）。

## 測定（10万人、30年進めたとき、Node）
- 職業の割合：採集17・狩人18・漁師13・道具製作9・建築10・運搬8・治療7・警備8・農民6・牧畜1.5・交易1.6・無職2.4（%）。
- 環境が出る：漁の民族は漁師26%（全体13%）、狩の民族は狩人28%、農の民族は農民21%。農民・牧畜・交易は条件のない民族に0%。
- 技能の成長（本業、年齢帯の平均）：16–20歳 26、20–30歳 79、30–40歳 131、40–55歳 154、55歳〜 161。
- 学習力の差（30〜40歳）：高い人 150、低い人 109。
- 向きの反映（生まれつきの値の平均、その職業 / 全体）：農民の筋力 133/128、狩人の敏捷性 135/128、治療者の共感性 139/127、交易者の社交性 140/127。
- 成長の例（筋力30、同じ訓練を5年）：潜在能力が高い 37.1、平均 35.2、低い 33.5。
- 時間：1年あたり 約480ms（10万人）。配列メモリ 約40MB（10万人、容量は人数の2倍で確保）。
- 30万人で約1.7秒、100万人で約6.5秒（最初の年は全員が職業を選ぶので重い）、配列 約137MB（100万人）。
- 保存（変化分）：訓練 1.8MB、技能 1.3MB（10万人、約23万ID）。
- 同じ Seed で2回走らせて結果が一致。

## 未決・注意

- 女性・子育て中の人の就労の扱いは未設計（今は全員が働く）。
- 家族による職業の継承は父親のみ。教育・見習いの師匠は未実装。
- 兼任（本業以外の活動）は `practice()` を用意しただけで、自動では使っていない。
- 1日分の処理は10万人で約1.3ms。iPhone 実機は未測定。
