# 馬と荷馬車を野戦の画面へ（Codex 試作11の取り込み）

- Codex の馬・荷馬車（`codex/prototype-horse-v1`、試作11）のモジュールを `tools/build-horse-view.py` で1本にまとめ（`npc/horse-view.js`、ブラウザでは `WohHorseView`）、データ（`assets/horse/`）とともにゲームへ埋め込み。ゲームの Three は Codex が使った固定版と同一（SHA一致）。ファイルは約2.4MB→約3.8MB。
- 野戦の画面（`BV`）：戦闘計算の `viewHorses` を1体ごとの値（速さ・位相・状態・経過秒・毛色・騎手）にして毎フレーム渡す。騎手は馬の背に乗る。倒れた馬は倒れたまま残る。荷馬車は2頭立て（馬具つき）で、車輪が進んだ距離に合わせて回る。敵の馬・荷馬車は、見えているものだけ描く。
- 開発者メニューに「野戦：騎兵と荷馬車」を追加（両軍に騎兵12騎と荷馬車3台。味方の射手は矢30本で、荷馬車から補給）。
- 歩様の境目は Codex の描画と同じ（0.04／2.5／4.6／8.3 m/s）。

## 検証
戦闘 35件、画面の全回帰17本＋戦場表示＋新規 cavtest（騎兵の前進・交戦・馬の倒れ）はエラーなし。馬の描画は描画命令2〜4回。
## 未検証
iPhone/iPad 実機の速度、近距離に数百頭が集まったときの負荷（今回の画面は馬30頭）、馬の恐慌・兵站の消費。馬に乗る操作（プレイヤーの乗馬）は本編に未接続。
