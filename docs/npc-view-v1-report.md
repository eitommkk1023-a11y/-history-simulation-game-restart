# 周辺の住民（NPC）の3D表示（報告）

ブランチ：`claude/npc-view-v1`（`claude/npc-activity-v1` から）。方針（決めた案）の3番目。画像：`docs/images/npc-view.png`。

## 入れたもの
- **描く人**：3Dのキャラクターから半径160m以内の住民を、近い順に最大60人。近くの集団（野営地が約520m以内）の、生きている人。
- **見た目**：頭・胴・腕・脚の簡単な人型。部品ごとにまとめて描くので、描画は6回（60人でも）。服の色は民族の色、高さは年齢（0歳で45%、15歳で100%）。肌の色は個人ごとに4種から。
- **位置と動き（保存しない）**：個人ID・世帯・職業・時刻から計算（`npc/npc-view.js`）。視覚上の1日は現実の10分。
  - 夜：世帯ごとに野営地の周り（6〜40m）に集まる（同じ世帯は約12m以内）。
  - 昼：採集者・農民・牧畜は野営地の周りを歩き回る（70〜180m）。狩人・漁師は遠く（230〜300m）へ歩いて出ていく（出ていく途中は見える）。警備者は野営地の周りを巡回。その他の仕事の人は野営地の近く。子どもと引退した人は家の周り。
  - 歩く脚・腕の振りは、実際に歩いているときだけ。
- **タップ**：人をタップするとリングが付き、情報カードが出る（年齢・性別・職業・あなたとの関係・主な技能3つ・民族）。カードの×で閉じる。
- 俯瞰の表示のときは描かない。描く人がいないときは再描画しない。

## 測定・確認
- Node（`npc/test-view.js`）：プレイヤーの集団（169人）で、夜は全員が120m以内、朝夕は約3分の1が出入り。移動の速さは平均0.7m/s、最大8.2m/s（狩人・漁師が出ていくとき）。同じ位置が毎回再現される。
- ブラウザ：60人を描画、画面内の人のタップで情報カードが出る。保存→読み込み、岩石、開発者モード、継承時のキャラクター移動も、エラーなし。

## 注意・未解決
- iPhone 実機の速度は未測定。ここの環境はソフトウェア描画で、フレーム数は参考にならない（15回/秒で位置を更新する）。
- 名前が無いので、情報カードに名前は出ない。会話・提案は次の段階。
- 描く人数の上限（60）・範囲（160m）・日の長さ（10分）は仮の値。
- 昼間の狩人・漁師は遠くへ出ていくと見えなくなる（案どおり）。
