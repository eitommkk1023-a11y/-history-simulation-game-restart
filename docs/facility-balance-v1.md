# 施設の分かりやすさと強さ：3つの観点への対応と測定（facil-ux-v1）

マネージャー（Codex の意見）の3つの観点：①建てる前に判断できるか、②強すぎ・弱すぎないか、③不利な使い方が事前に分かるか。

## 1. 建てる前に判断できるか（村ページの表示）
各施設のカードに、次を出す。
- **必要**：材料（足りないときは「足りない：薪があと3」）と日数。
- **未解放のとき「足りないもの」**を具体的に：例「村になる必要（いまは半定住）」「人口があと11人必要（いま49人）」「家畜があと5頭必要（いま3頭）」「栽培の技術がない」「『高温焼成』の技術がない」。
- **建てた後の効果**（折りたたみ。注意があるときは開いたまま）：保存日数の前後、いまの蓄えでの傷みの量（kg）、蓄えの上限の前後、受け持つ人数（人口に対して）。
- **おすすめ**：村の食料の入りの内訳から。生鮮が4割以上なら干し棚・共同の炉、穀物・根が主なら貯蔵穴・倉庫。

### 表示文の実例（人口209人、生鮮の入りが48%の村）
- 貯蔵穴：受け持つ人数 0人→25人（村の人口209人）／穀物・根・木の実が半分に減るまで（保存日数）639日→663日／生鮮が半分に減るまで 64日→61日（短くなる）／穀物・根の傷み（いまの蓄えで月）449kg→433kg／蓄えの上限 44,806kg→46,146kg。**⚠ 食料の入りの48%が生鮮です。貯蔵穴は穀物・根向きで、生鮮は傷みやすくなります。干し棚か共同の炉のほうが合っています**
- 干し棚：保存日数 生鮮64日→干物1,861日／1つで、生鮮の余りを月に最大200kg（干物になるのは80%）。★生鮮が多い村向き
- 倉庫：受け持つ人数 0→40人／穀物・根が半分に減るまで 639日→692日（干物も 1,861→1,935日）／蓄えの上限 +4,288kg。★穀物・根が主な村向き
- 共同の炉：受け持つ人数 80人／生鮮が半分に減るまで 64日→74日／食料が足りないとき、飢えて亡くなる人が約15%減る（受け持つ分）。

## 2. 強さ：測定で見つけた問題と、直したこと
**問題（測定1）**：貯蔵穴・倉庫は「1つ目だけ」が効き、2つ目以降はほぼ効果がなかった（貯蔵穴3つ≒1つ）。「増設する意味が残る強さ」になっていなかった。
**直し**：効果を「受け持つ人数」で決める形にした。貯蔵穴1つ＝25人、倉庫1つ＝40人、共同の炉＝80人。効果は「受け持つ人数÷村の人口」の割合だけ出る。**大きな村は、増設しないと全部は賄えない**（人口100の村なら、貯蔵穴は4つで全部、倉庫は3つで全部）。上限は貯蔵穴・倉庫とも4つに増やした。

**測定（同じ世界・2つの乱数・24か月、施設は36か月の助走のあとで付与）**

穀物・根が主な村（6村）：
| 施設 | 蓄え（日分） | 傷みで失う（1村・月kg） | 
|---|---|---|
| なし | 154 | 575 |
| 貯蔵穴1／2／4 | 160／166／171 | 547／514／471 |
| 倉庫1／2／4 | 168／177／180 | 513／450／406 |
生鮮が主な村（46村）：
| 施設 | 蓄え（日分） | 傷みで失う（1村・月kg） |
|---|---|---|
| なし | 165 | 970 |
| 貯蔵穴1／2／4 | 172／178／183 | 960／943／914 |
| 倉庫1／2／4 | 185／194／199 | 943／900／854 |
| 干し棚1／3 | 169／175 | 888／761 |
| 共同の炉 | 168 | 945 |

→ 増設するほど、少しずつ傷みが減る（倉庫4つで約29%減）。1つで劇的には変わらない。生鮮の村では干し棚の増設が効く（3つで約22%減）。

**不作（収入が8か月、8割減る）の測定**：食料が足りない月の割合は、穀物の村で 16.0%→（倉庫4つで）15.3%、生鮮の村で 9.7%→（倉庫4つで）8.3%。→ **施設1つはもちろん、4つ揃えても、不作を防ぎきれない**（飢饉の備えとしては弱め）。

## 3. 不利な使い方が事前に分かるか
- 貯蔵穴は「穀物・根向きで、生鮮は傷みやすくなる」を、カードの効果欄に常に出す。**生鮮が主な村では、カードに注意（⚠）を出し、干し棚・共同の炉を勧める**。穀物が主な村では注意は出さず、「穀物・根が主な村向き」と勧める。
- 貯蔵の使い分け（穀物を優先して穴に入れ、生鮮は入れない）：いまのモデルは食料の種類ごとに自動で分かれ、施設を選んで入れる仕組みはない。**生鮮を穴から外す選択は、まだ作っていない**（判断：下記）。

## マネージャーに判断してほしいこと
1. **強さ**：不作のとき施設の効果は小さい（食料が足りない月の割合が1〜1.5ポイント減るだけ）。「施設で飢饉をある程度防げる」強さにしたいなら、次の案がある。
   - A. 倉庫の効きを、傷み防止に加えて「不作の年の蓄えの放出（飢える人の減り）」にも広げる。
   - B. このまま（保存を良くするだけで、飢饉は防げない。飢饉対策は別の仕組みに任せる）。
2. **貯蔵の使い分け**：「貯蔵穴は穀物だけ入れる／生鮮も入れる」の切り替えを作るか。切り替えを作る場合、「生鮮も入れる」側に、蓄えられる量+25%などの利点を持たせないと選ぶ意味がない。作らず、注意の表示だけでよいか。

# 判断の結果と、効果の数字（全施設）

## マネージャーの判断
1. 強さ：**A（倉庫が不作の年の飢えにも効く）**に決定 → 実装した。
2. 貯蔵の使い分け：説明が分かりにくかったので、言い直して再確認する（この間は「注意の表示だけ」のまま）。

## Aの実装と測定
倉庫が受け持つ分は、食料が足りないとき、**飢えて亡くなる人が最大35%減る**（受け持ちの割合ぶん）。
不作（収入が8か月、8割減る）での、飢えで亡くなる人（人口1000人あたり・年）：
| 施設 | 穀物の村 | 生鮮の村 |
|---|---|---|
| なし | 254 | 123 |
| 倉庫1 | 229（-10%） | 106（-13%） |
| 倉庫2 | 199（-22%） | 89（-27%） |
| 倉庫4 | 164（-35%） | 80（-35%） |
| 共同の炉 | 231（-9%） | 107（-13%） |
→ 1つでは飢饉は防げず、増やすほど効く。4つで約3分の1減る。数値は不作の厳しさに依存する（この試験は、8か月収入が8割減る重い不作）。

## 全施設の効果の数字（実装どおり）
ふだんの食料の傷み（1か月、気温15〜25℃で）：穀物・根・木の実 約2〜3.5%、生鮮 15〜30%、干物 0.6〜1.2%。
