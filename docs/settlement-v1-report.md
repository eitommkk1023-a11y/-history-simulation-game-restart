# 定住と村：野営地・村を世界の中に見えるようにする（報告）

ブランチ：`claude/settlement-v1`（`claude/title-art-v1` から）。きっかけ：「民族が生きている感じがしない。野営地や定住したら村を作った方が絶対良い」。画像：`docs/images/settlement-3d.png`、`docs/images/settlement-overview.png`。

## 定住の仕組み（人口の計算）
- 集団の段階：**0 野営地（移動して暮らす）→ 1 半定住 → 2 村**。
- 同じ場所に安定してとどまった月数（食料の充足が0.9以上、移住中でない）で進む。
  - 半定住：5年以上（人口30人以上、暮らしやすさが上位60%の場所）。
  - 村：10年以上（人口50人以上、食料の充足0.97以上、暮らしやすさが上位35%の場所）で、確率（月3%）で村になる。
  - 暮らしやすさが低い場所の集団は、野営地のまま（移動して暮らす）。
- 定住すると：蓄えられる食料が増える（半定住 ×1.25、村 ×1.5）。野営地を移す頻度が下がる（半定住は4割、村は移さない）。村は、食料不足が長く続いても（+3か月）簡単には捨てない。村を捨てる移住をしたときは、野営地に戻る。
- **初期の状態は「縄文」のように、すでに暮らしのある社会**：暮らしやすさが上位35%の集団は村、次の25%は半定住、残りは野営地。
- 出来事：村になったとき、村を捨てたとき（自分の集団・接触した民族は重要度が上がる）。
- 速さの設定（民族の変化）で、定住に必要な年数も短くなる。

## 見える形
- **3Dの世界**：近くの集団の、**世帯ごとの家**を、住民が夜に集まる位置（世帯の家）に建てる。野営地はテント、半定住・村は小屋（村は広場の大きな家も1軒）。野営地の中心に焚き火（石の輪と揺れる炎）。民族の色が、家の色にわずかに混ざる。
- **俯瞰の地図**：村の名前（「⌂ ○○村」、民族の色）。近づいたときに表示。集団の目印（民族の色の点、村は大きめ）。野営地・半定住の名前は出さない（以前は民族名・集団名が地図に出てしまっていたのを直した）。
- **ミニマップ**：集団の点（民族の色、村は四角）。自分の集団は白縁。
- **情報パネル**：「あなたの集団」の行（集団名・段階・世帯数・人口）。

## 測定（Seed 42）
- 開始時：野営地 40集団（4,358人）／半定住 30（2,909人）／村 30（3,731人）。
- 100年後：野営地 17（709人）／半定住 29（1,150人）／村 57（5,931人）。村になった出来事 27回、村を捨てた 0回。
