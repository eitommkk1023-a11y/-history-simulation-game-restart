# jomon-cook-v1 報告（縄文の暮らし：食べる・火・調理・あく抜き）

前段 jomon-life-v1（採取と持ち物）の上に、集めた物の使い道を作った。ロジックは `npc/forage.js`（純粋・UMD）、画面は持ち物パネル。

## 仕様
- **おなか**：蓄え 0〜3000kcal、1日に2000kcal減る（ゲームの時計に連動。時計が動かなければ減らない）。満腹／普通／空腹／飢え。空腹で採取の見つかりやすさ×0.85、飢えで×0.6。体調不良は×0.75。（飢えで死ぬことは今はない）
- **食べる**：1個ずつ。調理済み・果実・新芽・草の実はそのまま。生の根・貝・魚は熱量が半分程度で、30〜40%の確率で2日間おなかをこわす。**生の木の実（ドングリ）は渋くて食べられない。**
- **火**：薪2本と繊維1（火口）で起こす。成功率は 0.6＋0.3×技能（水辺は−0.25）、失敗すると繊維だけ失う。薪1本で約0.75日。火の周り2ブロック以内が有効。薪をくべて延長できる。
- **焼く**：火のそばで、魚・貝・根・草の実・水さらしした木の実をまとめて焼く（1回30個まで）。焼き魚280kcal、焼き木の実80kcalなど。
- **水さらし**：川や湖（真水）のそばで木の実を最大60個、2日間水にさらす。同じ場所に戻って受け取る。→「水さらしした木の実」→焼くと「焼いた木の実」。ドングリのあく抜きの流れ。
- 保存：おなか・時刻・体調・焚き火・水さらしも記録に入る。暮らし項目の無い古い記録は、読み込んだ日から数え始める（急に飢えない）。

## 検証（合格）
- Node 単体 71件（食べる・空腹・火・焼く・水さらし・保存・壊れた保存・古い保存）。
- Playwright（iPhone横画面）：水辺で 木の実を食べようとして拒否 → 水さらし → 2日後に受け取り → 火起こし → くべる → 焼く → 焼き魚を食べる(+280kcal)。保存に反映。エラー0。
- 回帰：foragetest / gotest / avatartest / titletest / devtest / rocksmoke / peopletest 通過。
