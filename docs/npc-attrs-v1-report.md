# NPC 属性の拡張（民族ID・世帯・死因・成人年齢）報告

ブランチ：`claude/npc-attrs-v1`（`claude/npc-people-v1` から）。民族思想の引継仕様書（2026-11-04）の確認結果にもとづく、実装の順番の1つ目。

## 入れたもの
- **主たる民族（個人）**：1人 約2バイト。生まれたときは「育ち中（未確定）」で、**12歳で、育った集団の民族**になる（両親の民族を出生時に自動コピーしない）。両親の民族が違えば、副次的な帰属として別の表に残す（まだ使われる場面はない）。
- **世帯**：1人 約4バイト。結婚で新しい世帯ができる（夫のIDが世帯ID）。子どもは母親の世帯。初期の子どもには、同じ集団の年上の女性を母親として割り当てた。
- **死因（10分類）**：1人 1バイト。老衰・非感染性疾患・感染症・戦死・殺害・事故・飢餓・出産関連・災害・環境。いま起こるのは、老衰・非感染性疾患・感染症・事故・飢餓・環境・災害。
- **文化ごとの成人年齢**：民族ごとに15〜21歳（基本18歳）［仮］。職業を選ぶのは成人の4年前、結婚は成人から。
- **寿命の上限** 120歳。
- 保存：新しい配列も保存する。古い保存（これらが無い）は読み込める（集団の民族から補う）。

## 測定（Seed 42、30年）
- 12歳以上で民族が未確定：開始時 0／8,367人、30年後 7／5,370人（直近に12歳になった人）。
- 世帯：開始時 平均1.4人（初期は夫婦がいない）→ 30年後 平均2.4人（最大10人）。
- 成人年齢未満で結婚している人：0／3,624人。
- 死因：感染症 40%、飢餓 28%、事故 12%、非感染性疾患 11%、老衰 9%。
- 民族の成人年齢の分布：15〜21歳でほぼ均等（各12〜15民族）。
- 初期の再現性：同じSeedで一致。
- 出生の補正（FERT_ADJ）：成人年齢を上げたぶん結婚が遅くなったので、1.3→1.5に再調整。人口は約6,000人で落ち着く。実際の合計特殊出生率は約6.0。
- ブラウザ：保存→読み込みで人口が一致、岩石・開発者モードもエラーなし。

## 注意
- 初期の人々には夫婦がいないので、最初の数年は結婚が集中する。
- 民族がまだ集団の属性とほぼ一致するので、副次的な民族は実際には発生していない（集団間の移動・婚姻が起きるようになってから）。
- 戦死・殺害・出産関連の死因は、仕組み（戦争・暴力・出産リスク）が入るまで起こらない。
- プレイヤー像（人物か民族か）は未決定。この段階には影響しない。
