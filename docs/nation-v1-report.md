# nation-v1 報告（国の層の骨組み・技術の拡散の試作）

**ゲーム本体（HTML）は変更していない**（試作は Node のみ）。個人ごとの計算とは別に、民族を「集計の数字」で表し、1年ずつ進める層の実現性を確かめた。ファイル：`npc/nation.js`、`npc/test-nation.js`（`npc/tech.js` に拡張）。

## 作ったもの
- **民族の集計状態**：人口・上限・技術（22節の持ち物・取り入れた年・どの民族から伝わったか・やり方・名前を借りたか）・近くの民族（接触）・文化の値。
- **1年の進み方**：①人口が増える（ロジスティック。農耕などで上限が上がる）→ ②自分で**発明**（資源が近いほど・人口が多いほど・文化が開いているほど・前提が深いほど難しい）→ ③近くの民族から**伝わる**（近いほど・文化が開いている（外婚性が高い）ほど・その土地で使えるほど）。伝わると、やり方（バリアント）を受け継ぎ、名前を借りることがある（借用語）。
- 作物・家畜は、伝われば野生の群生地から遠くても、その土地の肥沃さしだいで育てられる。鉱床は、鉱山まで出かける・鉱石を交易で入手する前提で、手が届く範囲を広めにとる（近い／中距離／遠いの3段階）。
- 乱数はすべて整数ハッシュ（同じSeedなら同じ結果）。

## 測定（4つの世界×100民族・3000年）
### 計算の速さ（Q2「毎年」の目標：1年50〜100ms以下）
| 民族の数 | 1年あたり |
|---|---|
| 100 | 0.02〜0.06 ms |
| 300 | 0.21 ms |
| 1,000 | 0.67 ms |
| 3,000 | 2.2 ms |

→ **目標の数十分の一**。個人ごとの計算（1年≒0.65〜1.1秒）の約1,000倍軽い。民族3,000でも1年を2msで進められるので、「毎年」は十分に現実的。作る時間は民族1,000で約0.6秒（世界生成の後に1回）。

### 技術の広がり方（世界ごとに違う）
- 農耕は100〜200年台に、世界のどこかの1か所で生まれ、1,000〜2,000年かけて広がる。広がりは、最も近い発明者から離れるほど遅れる**波**になる（相関：世界7で0.7前後、ほかは0.2〜0.8）。
- 牧畜は各地で独立に生まれ（発明17〜26か所）、すぐに全域へ。鉄は2〜26か所で発明されて広がる。
- **青銅は、世界によって到達率が大きく違う**（24〜71%）。銅と錫が近くに揃わない地方には届かない。
- 3000年後の世界間の違い（最も近い民族との違い）：平均4.15／最小3.90（静的な試作の約2倍）。世界ごとに、最初の農耕・鉄の場所と年が違う。
- 1,000年あたりで「栽培・文字・国家」が7〜9割に達する（人口が増えて条件を満たすため）。**時代の速さ**は、`K.INVENT`（発明）・`K.DIFFUSE`（伝わり）の2つで調整できる。

## わかったこと・課題
1. **集計の層は、性能の面では全く問題がない**（設計の最大の不安が解消）。
2. 拡散の仕組みで、世界ごとの違いが自然に出る。ただし、**時間の速さ・民族どうしのつながり（接触）の疎密**は、ゲームの感覚に合わせた調整が要る（係数はすべて暫定）。
3. 節が22個で、3000年後に多くの民族が同じ状態に収束する（栽培・文字・国家が7〜9割）。**節を100以上に増やし、各節に作風の連続値を持たせる**ことが、「毎回違う文化」には必要（前回の結論どおり）。
4. 民族の人口は、ここでは固定の初期値から増える単純なモデル。**既存の個人ごとの層とのつなぎ方**（個人の層の集計を国の層に渡す・国の層の変化を個人の層に反映する）は、次の設計項目。
5. 戦争・交易・婚姻による移動と融合（技術と人口の移動）は未実装。
