# jomon-life-v1 報告（縄文の暮らし：個人の採取と持ち物）

方針：まず個人の暮らし（拾う・加工する・食べる・備える）を作り、のちに集団の運営へ広げる。時代は進めず、縄文相当の暮らしを遊べるようにする。本単位はその第1段「持ち物と採取」。

## 実装
- `npc/forage.js`（純粋ロジック・UMD、画面に依存しない）／`npc/test-forage.js`（29件）
  - 持ち物10種：木の実、果実、山菜・新芽、根・球根、草の実、貝、魚（以上、食料）／薪、石、繊維（素材）。重さ・熱量・「生で食べられない」印を持つ（調理・あく抜きは次の単位）。
  - 豊かさ＝その場所のその月の植物資源（既存の `faunaPlantFood`）・森/草原の割合・海辺/水辺・岩の露出から決める。→ 冬は新芽、秋は木の実、海辺は貝と魚、岩場は石。
  - 採り尽くし：1ブロック（約33m四方）につき、豊かさ1で月に約6回まで。月が変わると回復。歩いて別の場所へ行く動機になる。
  - 腕前：プレイヤーの人物の「採集」「漁労」の技能（0〜255）で、見つかる確率と量が変わる。
  - 運べる重さの上限 25kg（暫定）。乱数は Seed・採取回数・日付で決まり、保存・読み込みしても同じ並び。
- 画面：右下に「食料を探す」「素材を探す」「持ち物」。持ち物パネルは一覧・合計の重さ・捨てる。
- 保存：`forage` として記録に含む（古い記録には無くても読み込める）。

## 検証（合格）
- Node 単体 29件。
- Playwright（iPhone横画面・ソフトウェア描画）：
  - 内陸の森：1月は新芽、4月は新芽、10月は木の実・果実。草原は草の実。砂漠は「何も見つからない」。
  - 海辺で貝・魚。持ち物パネルの表示・捨てる、保存内容（持ち物・回数）、月が変わると回復。
  - 回帰：gotest / peopletest / avatartest / titletest / devtest / rocksmoke すべて通過。エラー0。
