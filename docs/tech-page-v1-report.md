# 技術ページ v1：村の技術・技能を把握するメニュー（表示・集計・検索まで）

ブランチ：`claude/tech-page-v1`。依頼（マネージャー→Codex→Claude）：村にどんな技術があり、誰が持ち、どの水準かを首長として把握する。研究・伝授・仕事の割り当て・解放条件・成長速度の変更は含まない。

## 先に確認したこと（いま何を管理しているか）
| 項目 | 管理の単位 | 中身 |
|---|---|---|
| 技術（栽培・牧畜・土器・鉄…23個） | **民族** | 民族が持つ。「持つ／持たない」だけで、水準はない。その民族の人は、誰もがその技術を「知っている」扱い（個人ごとの記録はない） |
| 技能（採集・狩猟・漁労・材料加工・建築・輸送・治療・警戒・農業・家畜管理・商業） | **個人** | 0〜255の数値。仕事で使うほど伸びる。人ごとに11種の値がある |

→ 「知っていること」と「作業への熟練」は、**もともと別々に管理されている**。画面のために新しいレベル制度は作らず、両方を区別して表示した。

## 表示のルール
- **知っている人**：その村に所属する生存者（10歳以上）のうち、その人の民族がその技術を持つ人。
- **熟練者**：その技術に結びつく仕事の技能が **30以上** の人。結びつきは、表示用の対応表（`TECH_SKILL`。栽培・灌漑・輪作→農業、牧畜・牽引→家畜管理、土器・銅・青銅・鉄・鋼・金銀細工・窯・金属の武具→材料加工、水車・城塞→建築、丸木舟・外洋航海・荷車→輸送、刻み・文字→商業、弓→狩猟）。技能と結びつかない技術（首長制・国家）は、「熟練は管理していない（知っているだけ）」と表示。
- **分類**：既存の技術定義（食料／素材・加工／動力／輸送／記録／組織／軍事）をそのまま使用。
- 技能の値は0〜255のまま表示（段階名などは付けていない）。

## 画面（メニュー「技術」タブ）
- **技術から**：一覧（技術名・分類・知っている人数・熟練者数・最高の熟練）。選ぶと、熟練者の名前・年齢・仕事・技能（棒と数値）が並ぶ。熟練者が1人だけの技術は「熟練者1人」と表示し、詳細に警告を出す。
- **人物から**：村人の一覧。選ぶと、知っている技術（その人の熟練値つき）と、11種の技能の値を一覧で見られる。技術名から人物へ、人物から技術へ、タップで行き来できる。
- 検索（技術名・人物名）、分類の絞り込み、並べ替え（熟練者の数／知っている人数／最高の熟練／名前。人物は熟練の高い順／名前／年齢）、「熟練者が1人だけ」の絞り込み。
- 全画面方式で、一覧が主領域。横画面のiPhoneでも、検索・分類・並べ替えが1〜2行に収まり、一覧は指でスクロールできる。

## 更新と検証
- 画面を開く・操作するたびに、元データから集計し直す（メニューを開いている間は時間が止まるので、習得・死亡・所属の変化は、開き直し・操作のたびに反映）。
- Node（`test-techview` 14件）：保有者に重複がない／熟練者は知っている人の部分集合／人物の技能値が元データ（`P.skills`）と一致／基準30以上で高い順／分類が既存の定義と一致／技能と結びつかない技術は熟練を数えない／**死亡した人が外れる**／**所属を変えた人が元の村から外れ、新しい村に入る**／**村を切り替えても混ざらない**／技術の習得が反映／「熟練者1人」の判定／読み取りだけで状態を変えない。1回の集計は約0.7ms（164人）。
- ブラウザ（`techpagetest.js`）：行数が集計と一致／分類・検索・並べ替え／保有者の人数が一致／人物の技能値が元データと一致／死亡した人が一覧から消える／タッチでスクロール。エラーなし。

## 課題
- 人物名は、ゲームの既存の表示（名前を持たない人は「#番号」）のまま。名前がつく人が増えれば、そのまま反映される。
- 「知っている人」は、民族単位の技術なので、同じ民族の人は全員が知っている。個人ごとに技術を習得する仕組みはない（今回の範囲外）。
- 自分の村だけを表示する（他の村の人は、首長として把握する対象ではないため）。別の村に切り替える画面は、必要になったときに足す。
