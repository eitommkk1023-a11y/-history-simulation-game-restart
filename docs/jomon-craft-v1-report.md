# jomon-craft-v1 報告（縄文の暮らし：道具づくり・土器・煮る）

前段 jomon-cook-v1 の上に、道具と土器を足した。ロジックは `npc/forage.js`、画面は持ち物パネルの「作る」。

## 仕様
- **新しい素材**：粘土（川や湖のそばで採れる。海辺はごく少ない）、縄（繊維3）。
- **道具と効き目**（使うほど傷み、壊れる。使える回数は暫定）：
  - 石のナイフ（石1・40回）：根・繊維・貝・新芽が3割増。
  - 石斧（石2・薪1・縄1・40回）：薪が2倍。
  - 魚網（縄3・30回）：魚が見つかりやすくなり（×1.6）、数も2倍。
  - 土器（粘土4・薪2・**火のそばで焼く**・25回）：煮る。
- **作る**：成功率＝基本値＋0.3×「材料加工」技能（上限95%）。失敗すると一部の材料を失う（縄は繊維1、石器は石1、土器は粘土2など）。重さの上限を超えるなら作らない。
- **煮る**：土器・火・真水のそばで、素朴な食材（木の実・水さらし木の実・貝・根・新芽・草の実・果実）4つ→煮物1つ（260kcal、安全）。1回に最大4つ。生の木の実も煮れば使える（縄文の煮炊きの再現）。魚は焼く方が良いので使わない。
- 保存：道具の摩耗も記録に入る（古い記録は摩耗なしで読み込める）。

## 検証（合格）
- Node 単体 100件（作る・失敗・火の条件・重さ・煮る・最大4つ・土器が25回で壊れる・斧/網の効果・保存と壊れた保存）。
- Playwright（iPhone横画面）：水辺で素材を採って粘土が出る → 縄・ナイフ・石斧 → 火なしで土器は拒否 → 火を起こして土器を作る → 煮る → 煮物を食べる(+260kcal) → 保存に摩耗が入る。エラー0。
- 回帰：cooktest / foragetest / gotest / avatartest / titletest / devtest / peopletest 通過。

## 追記：持ち物の上限を「重さ」から「枠」へ（jomon-slots-v1）
ユーザーの指示「持ち物の上限は良いけど重さは要らない」に従い、重さ（kg）を廃止して枠の数で制限する形に変えた。
- 持ち物は **20枠**。1つの枠に積める数は品物のかさで決まる：薪・石は10個、魚・粘土などは20個、木の実・繊維などの軽い物は40個、道具は3個。（暫定。これは判断して決めた値で、変えたければ `npc/forage.js` の `SLOTS` と `stackOf`）
- パネルの表示は「N / 20 枠」。採取・水さらしの受け取り・作る、いずれも枠が埋まると「持ち物がいっぱいで持てない（20/20枠）」。
- 保存形式は変わらない（重さは保存していなかった）。古い記録もそのまま読める。
- 検証：Node 112件（枠の数え方・同じ物の積み上げ・満杯・保存）、画面テスト（crafttest / cooktest / foragetest）と回帰（gotest / avatartest / peopletest / titletest / devtest）通過。
