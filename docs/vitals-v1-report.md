# vitals-v1 報告（体力・スタミナ・水分）

HUDの「準備中」だった3本（体力・スタミナ・水分）を実際に動かした。ロジックは `npc/forage.js`、操作の制限はネイティブ側（ダッシュ・ジャンプ）。

## 仕様
- **水分**（0〜100）：1日（ゲームの時計）で30減る。ダッシュ中は少し余計に減る。「水を飲む」で+45（川や湖のそばだけ。海の水は飲めない）。果実（+8）・煮物（+18）などの食べ物からも少しとれる。右下の「調べる」の上のモードに「水」を追加、持ち物パネルにも「水を飲む」。
- **体力**（1〜100）：飢え（満腹度0）で−8／日、渇き（水分0）で−12／日、病気で−3／日、寒さ（気温0℃未満で屋根・火・みんなの炉のそばでない）で最大−8／日。何も不足がなければ＋5／日。**1未満にはならない（いまは死なない）**。眠ると回復（家＋25、焚き火のそばの野宿＋10）。体力が30未満で採取が見つかりにくく（×0.7）、10以下で×0.5、ダッシュ不可。
- **スタミナ**（0〜100）：**実時間**で動く。ダッシュ中は毎秒6減り、止まって休むと毎秒7、歩くと毎秒2戻る。0になると「疲れ切り」でダッシュできず、25まで戻ると再びダッシュできる。ジャンプは8を使い、スタミナが8未満ではジャンプできない。上限は体力が低い・喉が渇いている（水分15未満）・飢えている（250kcal未満）と下がる。
- HUDの4本はすべて実際の値（体力・スタミナ・満腹・水分）。弱ると色が変わる（体力30未満＝明るい赤、疲れ切り＝橙、喉が渇いた＝橙）。持ち物パネルに数値も出る。目標に「川や湖の水を飲む」を追加（全17）。
- 保存：体力・スタミナ・水分・疲れ切りも記録に入る（古い記録は満タンで読み込む）。気温などの環境は保存しない。

## 検証（合格）
- Node 単体 250件（水分の減り・体力の増減・寒さと屋根・飲む・食べ物の水分・スタミナの減りと尽きる/回復・ジャンプ・休む・眠る・採取への影響・保存と壊れた保存）。
- Playwright（iPhone横画面）：ダッシュ中にスタミナが減る（97.8→74.2、水分もわずかに減る）→ 尽きると疲れ切り・ダッシュが自動で解除され、押しても入らない → 休んで回復して再びダッシュ可 → ジャンプでスタミナ減・不足で不可 → 水辺で「水」モードで飲む（20→65）→ 2日渇くと体力が減る（100→55）→ HUDのバー・保存。エラー0。
- 回帰：hudtest / tiestest / foragetest / cooktest / crafttest / hometest / fptest / avatartest / peopletest / proptest / titletest / devtest 通過。

## 未実装・未確認
- **死なない**：体力が1まで下がっても死亡・継承にはならない（飢え・渇き・寒さの影響は大きいが、救済として）。死を入れるかは仕様の判断が要る。
- 怪我・毒・病気の発生、暑さ（熱中症）、雨や雪での濡れ、水の汚れは未実装。
- 水を持ち運ぶ（容器）、雨水、泉・井戸は未実装。土器に水を汲む案は次の候補。
- 係数（水の減り・体力の増減・スタミナの秒あたり）はすべて暫定。実機（iPhone/iPad）での操作感・バランスは未確認。
