# 見下ろしの建設 v1：施設の置き場所を、村を上から見て選ぶ

ブランチ：`claude/topdown-place-v1`。方針（マネージャー）：探索などのアクションは一人称・三人称、街のインフラ整備（施設・道・城壁など）は見下ろし。その最初の一歩として「施設の置き場所を選ぶ」。

## 遊び方
1. メニューの「村」ページで、施設の「建てる」を押す。
2. メニューが閉じ、**カメラが上がって、村を真上から見る画面**になる（時間は止まる）。
3. 建てたい場所を**タップ**する。置ける場所は**緑**、置けない場所は**赤**で、下の欄に理由が出る（例：建物と重なる／水辺・水の上には置けない／斜面が急すぎる／広場の中心には置けない／ほかの施設と重なる／村から遠すぎる）。
4. ドラッグで動かす、2本指（PCはホイール）で拡大・縮小、「向きを変える」で45度ずつ回す。
5. 「ここに建てる」で確定。材料が減り、建設が始まる（日数は今までどおり）。完成すると、**選んだ場所**に施設が出る。工事中は、地面の印と杭が立つ。「やめる」で、何も変えずにメニューへ戻る。

## 対象
貯蔵穴・干し棚・倉庫・井戸・家畜の囲い・共同の炉・窯。畑の拡張は、場所を選ぶものではないので、これまでどおり即時に建て始める。

## しくみ
- 見下ろしの画面は、地面を読み込んだままカメラを上げるだけ（別の世界に切り替えない）。置き場所の判定は、集落の配置の判定（建物・畑・既存の施設との重なり、水、傾斜）をそのまま使う。
- 選んだ場所は、集団の記録（`facilSpots`、建設中は `build.spot`）に保存され、保存・読み込みで残る。場所を選ばなかった（既存の）施設は、これまでどおり自動で決まる。
- 時間は、場所選びの間だけ止まり、終われば元の進み方に戻る。

## 確認したこと（ブラウザ）
- 「建てる」で見下ろしになり、HUDが隠れ、時間が止まる。
- タップで判定が出る／建物の上は赤（理由つき）／置ける場所は緑で、「ここに建てる」が押せる。
- 向きを変えられる／拡大・縮小できる。
- 確定で、選んだ場所に建設が始まり、材料が減る。完成後、**選んだ場所と同じ場所**に施設が出る。
- 「やめる」で、何も建たず、材料も減らない。エラーなし。
