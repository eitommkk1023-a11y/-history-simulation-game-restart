# プレイヤーの人物：3Dとの紐づけと、活動の選択（報告）

ブランチ：`claude/npc-activity-v1`（`claude/npc-player-v1` から）。決めた方針（A 存在・B 行動）の1・2番目。

## 入れたもの
### 1. 紐づけ（存在）
- 世界ができたとき、3D のキャラクターは**プレイヤーの人物の集団の野営地**に現れる（以前は乾いた陸の適当な場所）。保存した記録を読み込んだときは、保存した位置のまま。
- プレイヤーの人物が亡くなって跡継ぎが決まると、キャラクターは**跡継ぎの集団の野営地**に移る。
- 世界の時間は、これまでの時間の操作どおり流れる。

### 2. 活動の選択（行動）
- 情報パネルの「活動」で、8つから選ぶ。いつでも切り替えられる。他の人の自動の判断と同じ仕組みで動く。
  - **自動**：他の人と同じ判断（既定）／**本業**
  - **採集・狩り・漁**：その仕事として食料に貢献し、その技能と関連する能力が伸びる。
  - **学ぶ**：学習力・洞察力・記憶力・計画力が伸びる（仕事の合間の6倍。仮）。食料の仕事には数えない。
  - **体を鍛える**：筋力・持久力・敏捷性・瞬発力が伸びる（6倍。仮）。
  - **家族**：独身なら、毎月 30% の確率で同じ集団の親族でない独身の成人と結婚する。既婚なら、配偶者の出産が増え（×1.4）、同じ世帯の5歳未満の子が死ににくくなる（×0.7）。
- 亡くなって跡継ぎに移ったときは「自動」に戻る。保存・読み込みに含まれる。

## テスト（Seed 42、12人の候補で10年、「自動」との差の平均）
- 採集：採集技能 +55／狩り：狩猟技能 +50／漁：漁労技能 +13（自動の人は採集 25・漁 21・狩猟 0）。
- 学ぶ：学習力 +5.8／体を鍛える：筋力 +5.3、持久力 +1.6、敏捷性 +2.3。
- 家族：結婚 +25pt、子 +1.0人（候補が少なく、差はばらつく）。
- ブラウザ：起動時のキャラクターの位置が野営地と一致。亡くなって継承すると跡継ぎの野営地へ移動し、活動が自動に戻る。保存→読み込み、岩石・開発者モードもエラーなし。

## 注意
- 野営地は季節で動くが、キャラクターは置かれた場所から自由に動く（自動では追従しない）。
- 3Dのキャラクターと NPC の位置の対応（遠く離れたら「旅」の状態になる等）は未実装。「旅」の活動もまだ無い。
- 効果の大きさ（訓練の6倍・家族の結婚30%・出産×1.4・幼児×0.7）はすべて仮の値。
- 周辺の NPC の3D表示（次の段階）はまだ。
