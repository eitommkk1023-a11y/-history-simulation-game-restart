## 既存システムとの衝突・重複（注意点）
1. **川の判定が3か所**：人口の層（川の線）、描画（川の距離の場＝新）、地形の水（海・湖のみ）。高優先度の立地・水辺の建築で統一が必要。
2. **技術が2層**：民族の技術（23個）と、個人の技能（11種）。表示（技術ページ）では区別済み。配置・建築への接続は未実装。
3. **食料が2系統**：個人の持ち物（`forage`）と、集団の蓄え（`g.food`・3分類）。互いに独立。
4. **施設の配置が2系統**：自動配置と、見下ろしで選ぶ配置。
5. **集落の配置は保存しない**：歴史の保存（高8）と衝突する。
