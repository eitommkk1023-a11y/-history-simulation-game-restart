# 神モード（空から見守る）と、時間加速・統計・人口の調整（報告）

## 神モード（新しいモード）
- 入口：メニュー（システム）の「神モード（空から見守る）」。出口：画面の「出る」／Esc。
- 空から自由に動く視点（どの共同体にも属さない）。ドラッグで移動、2本指で拡大・回転、ホイール、キー（WASD・QE・RF、Shift で速く）。高さ 14〜1500m。
- 村人の動きが見える：高く上がるほど、村人を大きく（倍率は高さに応じて最大14倍。小・標準・大で調整）、描く範囲を広げ（最大約1100m）、人数の上限を60→500人に。村の名前・段階・人口のラベル（重なる場合は人口の多い村を優先）。ラベル・ランキングから村へ飛べる。
- 地形・集落・村人の読み込みの中心を、カメラの注目点に合わせて動かす（歩かずに遠くへ行ける）。
- プレイヤーは元の場所に戻り、持ち物・体の状態も入る前の状態に戻る（神モードの間は、あなたの世界の時間は止まっているものとして扱う）。

## 時間加速（追加要望 2〜4・7・8）
- 速さ：止める／標準／日×10／月/秒／**1年/秒／5年/秒／10年/秒／30年/秒**（新しい「高速」モード）。
- **毎月の計算を省かない**：人口（出生・死亡・移住）・民族・技術・建築技法・経済・集落の劣化・手入れ・修理・住居の需要・工事（材料と人手を消費）を、月ごとに実際に計算する。日付や人口の数値だけを動かすことはしない。作ってある**全ての集落**を、毎月進める（描画の範囲外の遠い村も）。
- **端末の速さに合わせて実効の速さが決まる**：1コマの時間の予算の中で、できるだけ多くの月を計算する。目標の速さに届かないときは、目標と実際（年/秒）を画面に表示する。
- 高速（1年/秒以上）の間は、**3Dの描画を省略**してシミュレーションを優先する。止める・遅くする・出ると、3Dが戻る。
- 止めたらすぐ止まる（まだ計算していない月は計算しない。常に月の区切りで止まる）。

## 統計（追加要望 1・5・6）
- 90日ごとに、世界の総人口・集団数・村の数・出生・死亡（病気・飢え）と、**全集団の人口と集落の段階**を記録（`people.statLog`）。多くなったら古いほうを間引く（新しいほど細かい。最大520件）。保存・読み込みに含まれる。約180KB（約480件・100集団）。乱数・シミュレーションの結果に影響しない。
- 神モードの操作盤：**人口の推移グラフ**（世界全体／地域／選んだ集落、全期間・50年・10年、人口／出生・死亡／村の数）。地域は、世界の地域ID（`world.regionId`）で集計。
- **ランキング**：人口の多い順／50年で増えた順／減った順／発展した集落（段階が上がった）。タップで、その村へ飛び、情報を表示（そこから「詳細マップで見る」で集落詳細マップへ）。

## 人口の増え方（調整）
- 調査：出生は年4.3%、死亡は年3.9〜4.9%で、ほぼ釣り合っていた。農耕の村は年+0.6%、非農耕の村は+0.45%、半定住は減少、野営は横ばい。全体では年0.1%（先史時代の世界人口の増え方に近い）。
- 監督の選択（「農耕の効果を強める」）に従い、農耕・牧畜が食料に占める割合（0.6で最大）に応じて、出生を最大+30%、基本の病気の死亡を最大-30%、飢えの死亡を最大-50%とした（仮の値）。
- 結果（100年、同じSeed）：総人口 10,468 → 16,069（+54%）。農耕の集団 0→59。前：11,649（+11%）。
- **注意**：最初の約30年は、10,468→9,329へ一度下がる（開始時の人口が、食料で支えられる水準よりやや多いための立ち上がりの揺れ）。グラフで目立つ。未対応。

### 端末の限界（ソフト描画のヘッドレス）
- 目標が 1年/秒でも 30年/秒でも、実効は約 0.6〜0.8年/秒（1か月あたり約100ms）。**これが、この環境で毎月の計算を省かずに進められる限界**。実機（iPhone/iPad）では未測定で、より遅い可能性がある。速さの選択肢は、実機で測ってから整理する（遅い端末で意味のない選択肢を出さない）。
