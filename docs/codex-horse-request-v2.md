# Codex への依頼：馬 試作05 の追加分（戦場用）

試作05（`prototypes/horse/`、`assets/horse-source/`）を確認しました。造形・5歩法・5,000頭の集団描画はそのまま使います。**既存の5クリップ・LOD・操作は変更しないでください**。戦場で使うために、以下を追加してください。

## 1. 追加する動き（馬）
| 名前 | 内容 | 再生 |
|---|---|---|
| `rear` | 後ろ脚立ち：後ろ脚だけで立ち上がり前脚を上げ、降りる。Tポーズではない | 1回きり（約2秒）。終わったら `idle` に戻る |
| `fall` | 倒れる：前のめり、または横倒しに崩れる | 1回きり（約1.5秒）。最後は `dead` の姿勢で止まる |
| `dead` | 倒れたまま | 静止（1フレームでよい） |
| `turn_l` / `turn_r` | その場で向きを変える（足踏み。約90度分で、速度に応じて繰り返せる形） | ループ |

- 騎手が乗っているときは、騎手が振り落とされない前提で構いません。騎手側の「落馬」は戦闘側で別に扱います。
- 既存の `idle` / `walk` / `trot` / `canter` / `gallop` の見た目は変えない。

## 2. 荷馬車（新規）
- 荷馬車の車体（荷台と車輪）を別モデルで。長さ約4m、幅約1.8m。三角形は近600／中300／遠60を目安に。
- **車輪は速さに比例して回る**（シェーダーまたは頂点の動きで。骨は使わなくてよい）。
- 馬と連結する**くびきの点**を決める。馬は2頭立てを基本とし、1頭立ても可能な形に。
- 引く馬用に、馬具（首輪と引き綱）を付けた見た目を `rider` と同様のインスタンス属性で切り替えられる形に。
- 荷物の見た目は、俵と木箱の2種類から選べる程度でよい。

## 3. 1体ごとに渡す値（既存の仕様に合わせる）
`speed`（m/s）、`phase`（0〜1）、`state`（0=通常、1=rear、2=fall、3=dead）、`stateT`（その状態に入ってからの秒）、`coat`、`rider`（0/1）。
`state` と `stateT` から、1回きりの動きの再生位置を決められるようにしてください。

## 4. 守ってほしい制約
- Three.js r128。大量描画のまま、5,000頭で描画命令が数回に収まること。
- 骨格テクスチャ（64×256）の空きは16行しかありません。追加クリップが入らない場合は、テクスチャを大きくするか、追加クリップだけフレーム数を減らしてください（24フレームなど）。**その場合、サイズの増え方を報告してください。**
- 外部モデル・外部テクスチャ・有料サービスは使わない（今回までと同じ）。
- 再生成の手順（`tools/`）、単体テスト、ブラウザの確認も、追加分に合わせて更新する。
