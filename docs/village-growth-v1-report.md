# 村の成長 v1：技術の層を本編につなぎ、農耕・牧畜が村を育てる

ブランチ：`claude/village-growth-v1`。設計書 M1「指導者と村の成長」の1段目（技術と生業）。指導者の操作（分配・建設・提案）と、畑・家畜・施設の本番の見た目は、次の段階（Codex への依頼は `docs/codex-village-request-v1.md`）。

## 何をつないだか
1. **技術の層（`tech.js`・`nation.js`）を本編に入れた**。これまでは計算だけの試作だった。民族ごとに22の技術（栽培・牧畜・灌漑・輪作・土器・銅・鉄・首長制…）があり、自分で発明するか、近くの民族から伝わる。世界ごとに、いつ・どこで最初に生まれるかが違う。
   - 分裂・融合で生まれた民族は、親の技術とやり方を受け継ぐ（`spawn`）。
   - 保存・読み込みに含まれる（`meta.nation`）。読み込み後、最初の月に復元する。
   - 年に1度（民族の年次処理と同じ時期）進める。民族の人口は、実際の集団の人口に合わせる。「民族の変化の速さ」の設定で、年に進む回数が変わる。
2. **栽培・牧畜を持つ民族の集団に、農民・牧人の職が開く**。働き手の割り振りに、農耕・牧畜が選択肢として加わった（採集・漁・狩りと、いちばん得なものに回す）。
   - 農耕：成長期（月の平均気温が4℃を超える月）に収穫が出る。土地の肥沃さ、始めてからの年数（技能。80年で最大）、灌漑・輪作・牽引・鉄で収穫が増える。成長期でない月は、農民も採集に回る。
   - 牧畜：群れは牧草地で支えられる頭数に向かって増える。牧人1人が20頭を世話し、1頭あたり1か月5kg分の乳・肉になる。
   - 穀物の割合が高いほど、蓄えられる量が増え、腐りにくくなる。
3. **村の成長の段階**：野営地→半定住→村→**大きな村**（村で人口120人以上、食料の3割以上が農産物）。
4. **見える形**：農民が増えると、畑の区画が村の外側に増える（畑の広がりは4段階で、段階が変わると集落の配置を作り直す）。いまの畑は平らな緑の板（Codex の造形ができたら差し替える）。情報パネルの「あなたの集団」に、段階・農民・家畜が出る。歴史に「○○が、世界で初めて『栽培』を身につけた」。
5. 開発者向け：メニューに「あなたの民族に栽培・牧畜を与える」。

## 測定（Seed 42、40年）
| | 対照（技術なし） | 栽培・牧畜を半数の民族に与える |
|---|---|---|
| 人口（40年後） | 7,087 | 9,397 |
| 村（大きな村） | 49（0） | 50（13） |
| 農民 | 0 | 2,659 |
| 農産物の割合 | 0 | 66% |
| 1か月の計算 | 20.6 ms | 19.9 ms |

- 計算量はほぼ変わらない（技術の層は年に1度、1回0.5ms 以下）。
- 自然に任せた場合、牧畜は数十年で広がり始め、栽培は約270年（年に3回進める設定）から現れた。**この速さは調整が必要**（`WohNation.K.INVENT`・`K.DIFFUSE`）。
- 対照でも人口が減っていく（11,335→7,087）のは、もとの狩猟採集の集団が飢えで減るため。農耕はこれを緩める。

## 未実装・課題
- **畑・家畜・施設の見た目**：Codex 待ち。いまは平らな板のみで、家畜は数だけ（描画なし）。
- **土地の限り**：農地の面積による上限はまだない（農民を増やせば収穫が比例して増える）。肥沃さの違いだけが効く。
- **季節の収穫の山**：月ごとの均等な収穫。実際の収穫期の集中と、凶作はまだない。
- **技術の速さ**：栽培の自然発生が遅い（上記）。ゲームの時間の進め方に合わせて調整する。
- **指導者の操作**：分配・建設・提案は次の段階。
- 数値はすべて仮。
