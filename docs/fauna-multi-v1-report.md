# 野生動物の追加（牛・ヒツジとヤギ・イノシシ）と、複数の獲物の狩猟（報告）

ブランチ：`claude/fauna-multi-v1`（`claude/settlement-arch-v1` から）。牧畜（家畜化）の前の準備。方針（ユーザーと決定）：種は3種に絞る→野生動物を追加→狩猟で獲物が複数→（次の段階）家畜化・牧畜。

## 入れたもの
1. **野生動物の3種**（`ANIMAL_SPECIES` に追加。鹿と同じ仕組みで、気候・植生・水・食べ物・繁殖・死亡・移動・分裂・狩猟を持つ）
   - **オーロックス（野生の牛）**：草原・温帯の大型の草食動物（体重約700kg、妊娠283日、幼獣24か月）。狩りは危険で成功しにくい。1頭の肉 280kg。
   - **野生のヒツジ・ヤギ**：山地・乾燥した草原・高地（険しい地形に強い）。双子が多い。1頭の肉 22kg。
   - **イノシシ（野生のブタ）**：森・湿地の雑食（木の実・果実を食べる）。繁殖が速い。1頭の肉 55kg。
   - 世界の生成：種の一覧に加えるだけ（種ごとに独立した乱数なので、鹿・地形など他の部分は変わらない。Seed 42 で標高・鹿の初期個体数が一致することを確認）。
   - 古い記録は読み込める（新しい3種は、生成時の状態から始まる）。
2. **複数の獲物の狩猟**（`npc/people-core.js`）：集団の生活圏にいる種ごとに「1か月に期待される捕獲数 × 1頭の肉」を比べ、一番得な種を狩る。獲物ごとの狩りやすさ・肉の量・時間帯が効く。集団が狩った肉は、種ごとに記録（`meatBy`）。集団の配置の「暮らしやすさ」にも、獲物の生息しやすさが入る。
3. **画面**：情報パネルの「野生動物」に4種の群数・頭数。出来事（分裂・全滅）に種の名前。
4. **個体群数の上限**（`range.maxLive`）：新しい3種だけ。イノシシで個体群が際限なく分裂して増えた（30年で372→18,606群）ため。鹿には無い（挙動を変えない）。

## 測定（Seed 42）
- 生息適地の気候区分：牛＝温帯・草原・地中海性・サバナ、ヒツジ・ヤギ＝草原・高地・乾燥地、イノシシ＝温帯・熱帯の森。鹿は以前と同じ。
- 60年の野生動物（群数/頭数）：鹿 892群/6,760万（以前と同じ傾向）、牛 465群/640万、ヒツジ・ヤギ 700群/3,890万、イノシシ 700群/3,140万。**4種とも、60年で落ち着く**（イノシシは暴走していたのを、繁殖・病気・食べ物の好みで調整）。
- 人口と合わせて50年：鹿 4%増、牛 +56%（収容力に近づく途中）、ヒツジ・ヤギ +48%、イノシシ +88%（収容力へ）。狩猟で減る分は小さい（鹿 2.8万頭、イノシシ 8千頭、牛 2千頭）。
- 狩猟で得た肉（50年、累計）：鹿 42%、牛 33%、イノシシ 23%、ヒツジ・ヤギ 1%。**集団が狩る獲物は地域で分かれる**（鹿24・イノシシ19・牛16・ヒツジ・ヤギ2集団）。
- 人口の挙動は以前とほぼ同じ（50年で約6,900人、食料の充足0.99）。
- 世界の生成：約22.9秒 → 約24.8秒（+約2秒）。
- **1か月の野生動物の計算：約7ms（鹿のみ）→ 約25ms（4種）**。ブラウザで5年進める時間は約1.2秒 → 約3.0秒（ソフトウェア描画）。
- ブラウザ：4種の表示・出来事・保存→読み込み（古い記録も含む）・既存の確認（住民・提案・3D・タイトル・岩石・開発者モード）にエラーなし。

## 注意・未解決
- **毎月の計算が増えた**。「年ごと」モードで進めるときの1コマが重くなる（iPhone 実機は未測定。デスクトップの2〜3倍かかる可能性）。個体群数の上限を下げる、遠くの個体群の計算を間引くなどの軽量化の余地がある。
- 数値（密度・繁殖・死亡・狩りやすさ・肉の量）はすべて仮。特に、牛の狩りの危険（狩人の怪我・死亡）は、まだ入れていない。
- 狩猟は、1つの集団が1か月に1種だけ狩る簡易な形。複数種を同時に狩る・獲物を追って移動する、は未実装。
- 開発者用の「鹿」の表示・狩猟パネルは、鹿のままで、他の種には使えない。
- 家畜化・牧畜・栽培は、まだ。次の段階で、この3種を元に入れる（人が飼いならす過程、飼育数、牧畜の職業、畑・家畜小屋）。
