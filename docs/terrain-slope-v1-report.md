# terrain-slope-v1 報告

## 変更
1. **標高圧縮の式**: `1000*tanh(e/3000)` → 同式 + `0.15*d²/(d+1000)`（d = max(0, e−3000)）。3,000m超の山が頭打ちにならず、緩やかに高くなり続ける。
2. **傾斜制限（最大約35°）**: 粗いグリッド（4ブロック＝750×750）上で、海・低地・湖面を起点にした chamfer 距離変換（`PLAYABLE_MAX_SLOPE_DEG=35`）で「許容高さの上限面」を作り、各ノードの標高を `min(元の標高, 上限面)` とした。高地側を斜面に削る方式で、海岸から十分遠い山頂の高さは変わらない。結果が海岸の崖（以前: 913m→0mが500m以内）を緩やかな斜面にする。
   - 上限面は World ごとに WeakMap でキャッシュ（世界生成後の初回のみ計算）。

## 実測（シード同一のテスト世界・マクロ地形、標高帯ごと）
| 標高帯(実) | 歩ける割合(45°以下) | 傾斜の90%点 |
|---|---|---|
| 0〜100 | 98% | 6° |
| 100〜500 | 100% | 15° |
| 500〜1500 | 100% | 25° |
| 1500〜3000 | 100% | 35° |
| 3000〜 | 100% | 36° |

最高峰（実6266m）はプレイ上 1064m。山頂から東へ 0m:1064m/34° → 500m:730m → 1000m:471m → 2000m:216m → 2500m:79m。海岸の崖は消え、一様な約35°の登り斜面になった。

## 未確認・注意
- 海岸に近い山は上限面で削られるため、山頂高さが以前より下がる場合がある（最高峰でも海岸まで約2.5kmのため1064m）。内陸の山は圧縮式の変更により以前より高くなる。
- 係数（35°、0.15、1000）は暫定値。
- climb.js による実歩行テストは、ソフトウェア描画のため14秒で約20mしか進まず比較に使えなかった。実機（iPhone/iPad）での歩き心地は未確認。
- 地形の見た目が変わるため、iPhoneでの確認が必要。
- 回帰: gotest / avatartest / proptest 通過。
