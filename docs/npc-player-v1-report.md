# プレイヤーの人物と、文化ごとの継承（報告）

ブランチ：`claude/npc-player-v1`（`claude/npc-attrs-v1` から）。

## 決まったこと（ユーザー）
- プレイヤーは民族ではなく「1人の人物」。死んだら血縁の子孫・養子・指名された人へ移る。
- **継承は文化（民族）による。**

## 入れたもの
- **プレイヤーの人物**：世界ができたとき、プレイヤーの民族の20〜35歳の1人を Seed で決める。個人ID（特権なし）。
- **継承の決まり（民族ごと、7種）**［割合は仮］
  - 長子相続（最年長の子）、男系長子（最年長の息子→兄弟→兄弟の子）、末子相続（末子。未成年なら後見つき）、
    母系相続（女性なら長女、男性なら姉妹の子）、兄弟相続（年長のきょうだい→子）、
    能力による選出（血縁の成人→集団の成人を、判断力・洞察力・計画力・誠実性・社交性で選ぶ）、指名（指名された人→血縁の成人）。
  - 決まりで見つからなければ、子→孫→きょうだい→きょうだいの子の順にたどる。亡くなった子・きょうだいを通した孫・甥姪も入る。
- **一族の断絶**：開始時の選択に従う。「続ける」（既定）は、同じ集団→同じ民族→世界の成人の順に、一番若い成人が新しい一族の人物になる。「ゲームオーバー」は出来事（重要度3：時間が止まる）を出す。選択の画面はまだ無い（`people.player.onExtinct`）。
- **初期の家族**：成人の約75%が夫婦。35歳未満の人には年の合う夫婦を親として割り当てる（きょうだいができる）。これが無いと、最初の人物に跡継ぎがいなかった。
- 情報パネルに「あなた」（性別・年齢・第○代・継承の決まり・配偶者・子の数）。出来事の記録。保存・読み込み。

## テスト
- `npc/test-succession.js`：手で作った家族で、7種の決まりと、孫・甥姪・未成年・血縁なしの12項目が全て合格。
- `npc/test-player.js`（Seed 42、200年）：代替わり5回、一族断絶後に別の一族として続けたのが3回、ゲームオーバー0回。使われた決まりは長子相続・選出。
- 初期の夫婦を足したあとの人口：50年で約7,400人で落ち着く。1か月の計算は平均約12ms。
- ブラウザ：保存→読み込みで一致、「あなた」の表示、岩石・開発者モードもエラーなし。

## 未実装・注意
- 養子、後見の実際の動作（未成年の跡継ぎは記録だけ）、プレイヤーが指名する操作、開始時の選択画面。
- プレイヤーが人物として何ができるか（立場に応じた働きかけ、3D の操作キャラクターとの結びつき）は次の段階。
- 継承の決まりの割合（長子相続30%・男系長子20%・選出15%・母系15%・末子10%・兄弟5%・指名5%）は仮。
- 人物の名前がまだ無いので、「あなた」は性別・年齢などで表示している。
