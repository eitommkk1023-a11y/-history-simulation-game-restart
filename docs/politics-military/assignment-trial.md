# 配属接続の開発試験 P0b

対象ブランチ：codex/politics-military-p0。これは人員配属台帳の接続試験で、自律政治・戦争のプレイ版ではありません。

## 起動
`tools/politics-military/assignment-sandbox.html` は1ファイルで動く試験画面です。必要なら `python tools/politics-military/build-sandbox.py` で生成し直してください。ESMの接続部品と実人口コードをそのまま埋め込み、外部ライブラリ要求はありません。

画面は本作のセーブから独立したテスト世界を使用します。6人はテスト世界の開始時にPopulation.addFounderで生成し、軍事モジュールはその同じIDだけを参照します。本作の人物を複製しません。権限条件の人物0→部隊A／人物1→部隊Bは検査用データで、ゲームの軍制・任命規則ではありません。

## 確認すること
1. 操作者0、部隊A、人物2を選んで配属する。生存人口は6のまま、実位置は未取得のまま。
2. 同じ内容で再送する。配属・成功操作・未確認履歴候補の数が増えない。
3. 操作者1・部隊Bに変え、同じ人物2を配属する。二重配属を拒否する。
4. 人物2と未配属の人物4を同時に選ぶ。失敗時に人物4だけ配属されないこと。
5. 操作者0・部隊Aで人物2の配属を解除。その後、操作者1・部隊Bへ配属できる。
6. 操作者2で配属する。権限不足となり、台帳を変えない。
7. 保存テキストを作り、同じ内容で復元。配属と未確認の履歴候補を保持する。
8. 保存テキストのworldKeyを別の値に変え、復元する。失敗しても現台帳を保持する。

履歴の受取確認ボタンは模擬です。本作の履歴・思想へ送信していません。保存するのは配属台帳だけで、本作の人口・経済セーブではありません。
