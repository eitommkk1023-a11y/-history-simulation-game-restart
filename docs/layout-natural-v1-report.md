# 第2工程 2B：集落配置の自然化（報告）

## 1. 実装・修正内容（`npc/settle-layout.js`）
- **円形広場を必須から外した。** 野営地・半定住は焚き火だけ（半径2〜4m）。村でも円形の広場を持つのは約45%（Seedで決まる）。広場のある村だけ、集会所が広場の縁に立つ。`layout.plaza.kind`＝`open`／`hearth`。
- **家の置き方を「輪」から「育ち方」に変更。** 既存の建物（と中心の火）の近くから外へ増える。評価は、平らさ・水との距離（水辺の村は水から約35m、湧水は約14m）・近すぎず遠すぎない間隔・集落の広がりの上限・その集落ごとの伸びる向き（`layout.axis`）。
- **中心の選び方**：水から20〜40mの乾いた平地を好む。
- **入口の向き**：伝統（水・太陽・東・中心）を基本に、水辺の向きと下り坂を混ぜる。広場のない村では中心を向く力を弱める。ばらつきも大きくした。
- **道**：中心から近い順に、すでにある道へつなぐのは同じ。太さは「その先につながる家の数」で決める（幹線は太く枝は細い）。水場への道は、中心からではなく、水に一番近い道の端から水辺へ。
- **干し場**は集落の家の重心から見て最寄りの水辺に。作業場・廃屋は集落の広がりの外れに。
- 増築（世帯の増加・NPCの建設要求）も、同じ育ち方で既存の建物のそばに建つ。
- 村の生成時に、立地の種類（`g.site.kind`）を配置へ渡す（`spec.siteKind`）。
- 形を測る道具を追加：`npc/shape-metrics.js`（形の指標・合成地形）、`npc/bench-shape.js`（版どうしの比較）、`npc/test-layout-natural.js`（検証）。

## 2. 実際に変化した動作
- 村ごとに形が違う。輪っか状の家並みや、全員が広場を向く配置はなくなった。
- 水辺の村は水に沿って細長くなる。内陸は丸い。
- 道は幹線が太く、枝が細い。

## 3. 検証結果
- `test-layout-natural.js`（5地形×3段階×12シード＝180集落）全て合格：重なり0・水中0・急斜面0・入口が道で中心につながる。
- 比較（同じSeed・地形、前→後）：
  - 入口が中心を向く割合：0.40〜0.76 → 0.10〜0.35（平均0.26）
  - 村の広場：全村が円形 → 25/60が広場あり
  - 水辺の村の細長さ：内陸 1.50 に対し水辺 1.82（以前は水辺も内陸もほぼ同じ円形）
  - 道の太さ：一律 → 幅 1.0〜2.2m
- 既存の `test-layout.js` 全て合格。ブラウザで海岸・湖畔・川・湧水の8村を確認、エラーなし。性能：90世帯 62ms／回（目標150ms）。
- 全17本の回帰テスト：エラーなし（マップ追加後も確認）。

## 4. 既存仕様との整合性
- 建物の重なり禁止・水中禁止・急斜面禁止・世帯と住居の対応・既存の建物が動かない仕様は維持。`plaza.r` と `center` は残したので、施設・家畜・畑の位置計算はそのまま動く（広場が小さい村では施設が中心の近くに寄る）。
- 建築様式・民族システムは変更なし。

## 5. 未解決の問題
- 配置（`g.layout`）はセーブされない（読み込むと同じSeedから再生成。2Cで対応）。
- 「道が先にあり、家が道に面して建つ」形（街道沿いの村）にはまだなっていない。
- 地形が狭いなど極端な場合、1世帯が置けない例が合成地形で1件（以前は2件）。
- 川の判定が3か所に分かれたまま。
- 比率（広場45%、伸びる向きの強さ）は仮の値。
