# 第2段階: 小範囲チャンクと接地面

既存生成器を変更せず、第1段階のworld-terrainから64m・32分割の地形を生成する。
全世界LODを直ちに統合する方法ではなく、同一解像度の小範囲から始める。
単一エージェント。既存HTML、main、保存形式、配信中サイトは変更しない。

- 格子に整列したタイル座標を使い、全頂点を絶対世界座標で問い合わせる。
- 頂点はチャンク原点からのFloat32局所座標。原点の標高も差し引く。
- 三角形は(a,c,b)、(b,c,d)。接地判定は実際のFloat32頂点を補間する。
- sampleGroundは高さと面法線・勾配を返す。体全体の衝突や崖での移動制限は次段階。
- 元データが変わっても表示と接地は同じスナップショットを保つ。更新時はチャンクを再構築して両者を置き換える。
- 法線の表示用データは共通の基礎地形から取得し、同解像度の境界をそろえる。
- 最端チャンクは世界境界で切り詰める。世界の外のチャンクはnull。
- LOD、スカート、詳細ノイズ、先読み、人物操作は今回含めない。

別の検証ページで既存HTML内のWorker生成器を読み取り、Seed 12345の世界から内陸の乾いた地点を選び、3×3チャンクを表示する。
基準HTMLは実行・改変せず、生成器のテキストだけをWorkerとして使う。人の縮尺を確認する1.7mの目印を置くが、操作キャラクターではない。
Three.jsは既存と同じr128。ページは開発用HTTP環境での確認を想定し、file://対応や配信は行わない。
既存世界生成の処理負荷は残る。軽量な固定テスト地形モードも用意する。

合格条件: 共有辺の位置・法線一致、非平面地形での三角形補間、世界端、再構築、Three.jsのRaycasterとの高さ一致、元HTML不変。
