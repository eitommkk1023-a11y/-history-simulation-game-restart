# 第3段階: 小範囲の歩行プレビュー

既に依頼された三人称操作と、Safari確認後の「次に進めます」に基づく小単位の実装。
既存Three.js・単体HTMLを継続。全世界ストリーミングとの同時導入は避け、現在の9チャンクで操作と接地を先に検証する。これは実装側の段階分け判断。

- 左スティックと右ドラッグをpointerIdで分離。PCはWASD/矢印・Shift。blur/非表示/再生成で入力解除。
- 身長1.7m、歩行1.5m/s・ダッシュ4m/sは仮設定。カメラ基準で移動、斜め入力を正規化。
- 描画三角形の高さを足元に使用。半径0.25mの周辺点で45度超斜面・未描画領域・段差を拒否し、0.1m以下の刻みで移動。これは地形専用の接地制御で、建物対応のカプセル物理ではない。
- 背後カメラ、右ドラッグ見回し、地形遮蔽時は距離短縮。周辺俯瞰切替は同じ地形・人物位置を保つ。世界全体の広域表示統合は後段。
- 底部は移動とダッシュだけ。情報は折りたたみ設定。iPhone/iPad横画面用、外部通信不要のHTML v3。
- 固定範囲端で停止し、その理由を表示。チャンク追従・LOD・ジャンプ・戦闘・建物は対象外。
- 元HTML、Seed、保存形式、main、配信中サイトは維持。単一エージェント。作業ブランチへコミット。
