# World of History — 岩石・地層・山肌表現システム 統合実装指示書

## 1. 開発目的

『World of History』の自然地理生成器に、**岩石24種類の物理・化学的特性を実際の地形生成へ反映するシステム**を導入してください。

岩石の種類によって、山脈・尾根・谷・崖・斜面などの形状が自然に変化し、山肌には露出した岩石の色・質感・地層構造が表現されることを目指します。

**岩石の色だけを変更する実装は禁止します。岩石特性が地形生成計算に直接影響することを必須条件とします。**

関連機能はまとめて実装・統合・検証してください。

## 2. 岩石24種類

以下の岩石を基本セットとして採用します。

**火成岩8種類**
花崗岩、閃緑岩、斑れい岩、玄武岩、安山岩、流紋岩、凝灰岩、黒曜岩

**堆積岩9種類**
礫岩、砂岩、泥岩、頁岩、石灰岩、ドロマイト岩、チャート、石膏岩、岩塩

**変成岩など7種類**
片麻岩、結晶片岩、粘板岩、千枚岩、大理石、珪岩、蛇紋岩

各岩石に、密度・硬度・圧縮強度・引張強度・侵食耐性・風化特性・空隙率・透水性・溶解性・鉱物組成・熱的性質・割れ目特性・形成条件を設定してください。

岩石の基本特性と、地域ごとの割れ目・風化状態・地層傾斜・地下水条件は分離して管理してください。数値は科学的な根拠を考慮し、実測値の幅が大きい場合は条件依存モデルを使用してください。

## 3. 地形生成への反映手順

以下の処理を連動させてください。

1. **地殻変動**：プレート運動・造山運動・断層・火山活動から初期地形を生成する。
2. **岩石形成**：マグマの冷却・堆積・変成作用など、地質学的な形成条件に基づいて24種類の岩石を分布させる。無関係なランダム配置は禁止。
3. **地層形成**：地層の厚さ・上下関係・年代・傾斜・褶曲・断層構造を設定する。
4. **実効特性計算**：岩石の基本特性に、割れ目・風化状態・地層構造・気温・降水・地下水などの地域条件を反映する。
5. **侵食・風化計算**：岩石の侵食耐性・強度・溶解性・透水性と、水流・斜面勾配・気候条件から侵食・風化量を求める。
6. **土砂運搬・堆積**：削られた物質を可能な範囲で移動・堆積させる。溶解した物質は固体土砂と区別する。
7. **地形変形**：侵食・堆積結果を実際の標高データと地層厚に反映し、谷・斜面・崖・尾根などの形状を変化させる。
8. **地層露出**：上位地層や表土が除去された場合は、下位の岩石を正しく露出させる。
9. **山肌描画**：露出岩石の種類・鉱物組成・風化・湿潤状態・層理・節理に応じて、色・模様・質感を描画する。
10. **地質表示**：岩石種類・侵食耐性・透水性・斜面安定性を確認できる表示モードを追加する。

地質史の侵食・堆積は世界生成時に計算し、ゲーム開始後の継続的な地形変化は今回の新規実装対象から除外してください。

## 4. 山肌の表現

今回の岩石表示は、主に**山肌・崖・露岩など、岩盤が地表に露出した場所**を対象とします。

平地や緩斜面では土壌・砂・植生などを優先し、岩盤が露出した場所では岩石の種類に応じた色や質感を表示してください。

- 花崗岩：白灰色・淡桃色、結晶粒や節理、風化による巨岩
- 玄武岩：暗灰色・黒色、溶岩面や冷却節理
- 砂岩：黄褐色・赤褐色など、粒状感や層理
- 石灰岩：白色・灰色、溶食による凹凸
- 頁岩：暗灰色、薄く剥離する層状構造
- 片麻岩：明暗の縞模様や褶曲構造

その他の岩石にも、それぞれ適切な色・質感・構造模様を設定してください。

岩石ごとに色を完全固定するのではなく、風化・酸化・湿潤・鉱物組成などで変化させてください。

通常の自然景観表示と、岩石の種類や特性を識別する地質表示は分離してください。

地質表示用の色は必ずしも岩石の自然色と一致する必要はありません。

## 5. 比較実験の共通条件

岩石特性が地形形成へ実際に影響していることを確認するため、**A〜Dの比較実験**を実施してください。

すべての実験で、変更対象以外の条件を統一します。

共通で固定する条件：

- Seed
- 初期標高
- プレート運動・隆起・沈降
- 初期の岩石分布
- 初期の地層構造
- 降水量・気温などの外部気候条件
- 初期の水量・地下水条件
- 計算領域・格子解像度
- 侵食計算の期間・ステップ数
- 数値計算方法と境界条件

乱数消費順の変化が比較結果に混入しないよう、必要に応じて処理別・位置別の独立した乱数系列を用いてください。

ただし、実験によって生じる流路・浸透量・地下水位・侵食量などの変化は固定せず、モデル内部の結果として計算してください。

### A：通常生成（基準実験）

24種類の岩石それぞれに固有の特性を適用して、通常の地形生成を実施します。

侵食耐性・強度・風化・透水性・溶解性・地層構造などを有効化し、標高・斜面・谷・崖・露出岩石・水流・堆積結果を記録してください。

**Aを他の実験と比較する基準とします。**

### B：岩石特性を均一化した対照実験

Aと同じ初期地形・岩石分布・地層構造を使用します。

ただし、岩石間で異なる侵食耐性・風化・強度など、地形形成に作用する物性値を共通の基準値に統一してください。

岩石名と地層の位置は維持し、岩石の違いによる物性効果だけを除去します。

共通値は極端な値ではなく、モデルの代表的な範囲から合理的に設定してください。

**目的：岩石固有の特性を使用した場合と、使用しなかった場合の地形差を確認する。**

### C：侵食耐性のみを変更した実験

Aと同一条件を使用し、特定の岩石または検証領域の**侵食耐性だけ**を変更します。

- C1：侵食耐性を高くした場合
- C2：侵食耐性を低くした場合

変更倍率はモデルの感度分析に適した範囲を選び、極端に非現実的な値は使用しないでください。

他の岩石特性、初期標高、気候、地層構造は変更しません。

侵食耐性を高くした場合に、該当領域の侵食が減少するか確認してください。

**目的：侵食耐性と地形変化の因果関係を分離して検証する。**

### D：透水性・溶解性・地層傾斜の個別実験

Aを基準として、次の3項目をそれぞれ独立して検証します。

**D1：透水性**

透水性のみを変更し、浸透量・表面流出量・水流による侵食量・谷の形成への影響を比較します。

**D2：溶解性**

石灰岩・石膏岩などを対象に溶解性のみを変更し、適切な水理条件下で溶食量や地形変化が生じるか確認します。

**D3：地層傾斜**

地層の傾斜角・方向のみを変更し、露出する岩石分布・差別侵食・斜面形状への影響を確認します。

地層傾斜の変更で地表の岩石分布まで変化する場合は、その変化を明示し、岩石種の違いによる影響と区別してください。

**目的：各要素が意図した物理過程に作用していることを個別に検証する。**

## 6. 数値検証指標

A〜Dの実験結果について、以下を比較してください。

| 指標 | 検証内容 |
|---|---|
| 岩石別侵食量 | 岩石ごとの平均侵食深、侵食量の分布 |
| 標高変化 | 平均・最大標高差、標高差分マップ |
| 斜面形状 | 平均傾斜、傾斜角90パーセンタイル、急斜面の面積割合 |
| 谷の形状 | 谷の深さ・幅・密度・流路の違い |
| 土砂移動 | 侵食・運搬・堆積量、物質収支 |
| 地層露出 | 岩石別の露出面積、地層境界の変化 |
| 浸透・流出 | 地下への浸透量、表面流出量 |
| 溶食 | 溶解量、溶食地形の発達 |
| 描画整合性 | 表示岩石と実際の露出岩石IDの一致率 |
| 性能 | 生成時間、ピークメモリ、描画への影響 |

各指標について、Aとの差分と変化率を示してください。変化率が不適切な指標では絶対差を使ってください。

値が変化したという事実だけでなく、**なぜ変化したのかを計算過程と照合して説明**してください。

## 7. テスト地形とSeed

まず、以下の4種類の小規模な検証用地形を用意してください。

1. **硬い岩石と軟らかい岩石が接する斜面**：差別侵食と崖の形成を検証する。
2. **砂岩と泥岩の互層を持つ地域**：層理・傾斜・侵食耐性が地形へ与える影響を検証する。
3. **湿潤・乾燥条件の石灰岩地域**：降水・透水性・溶解性による地形形成の違いを検証する。
4. **割れ目の多い岩盤と少ない岩盤**：透水性・風化・侵食・斜面安定性の変化を検証する。

その後、異なるSeedを最低3種類使用して、通常の世界生成でも検証してください。

特定のSeedだけで成立する仕組みにならないようにしてください。

## 8. 合格基準

以下を満たすことを必須とします。

1. **再現性**：同一Seed・設定・生成バージョンで同じ地形と地質データが生成される。
2. **侵食への影響**：岩石特性を変更すると、対応する侵食量と実際の標高データが変化する。
3. **因果関係**：他条件が等しければ、侵食耐性を高くした岩盤は侵食されにくくなる。ただし相互作用がある場合は、その理由を分析する。
4. **透水性**：透水性の変更が浸透・表面流出の計算に反映される。
5. **溶解性**：適切な条件下で溶解性の違いが溶食量に反映される。
6. **地層露出**：上部地層が侵食された場合、正しい下位地層が露出する。
7. **描画整合性**：山肌に表示される岩石が、実際の露出地層と一致する。
8. **数値安定性**：NaN・無限大・負の地層厚・異常な標高値が発生しない。
9. **空間的連続性**：チャンク境界や地質格子の境界で、不自然な段差や断絶が発生しない。
10. **互換性**：既存の自然地理生成・河川・湖・火山・Seed・セーブ機能を破壊しない。

**侵食量や標高変化に一律の5%・10%などの数値目標を強制しないでください。**

自然な計算結果を優先します。差が小さくても、合理的な理由があり、制御された実験で特性の影響が確認できれば問題ありません。

逆に、差を大きく見せるためだけの補正係数や恣意的な地形変形は禁止します。

物質収支の検証では、固体土砂・溶解物質・計算領域外への流出を区別し、数値誤差を評価してください。

## 9. 実装・性能上の条件

- 地質データを世界全体の地理生成システムに統合する。
- 岩石特性の参照元を共通化し、地形生成・地下水・描画で利用できるようにする。
- 世界全体に高解像度の3Dボクセルを常駐させない。
- 広域地質と局所的な詳細地層を整合させる。
- 山肌・崖・露岩と、土壌・植生に覆われた地面を区別する。
- 岩石24種類を将来追加・拡張できる設計にする。
- スマホ・タブレットのメモリと計算性能を考慮する。
- 既存Seedの世界が変わる場合は生成バージョンを分離し、旧セーブとの互換性を保つ。
- 既存の広域表示と、今後のチャンク・LOD・三人称視点でも同じ地質情報を利用できるようにする。

## 10. 作業方針

今回は、関連する地質・岩石・地層・地形・描画・検証機能を**まとめて実装し、統合された成果物として完成させる**方針です。

- サブエージェントは禁止。
- 複数エージェントによる並列処理は禁止。
- 単一エージェントで実装・検証を行う。
- 小さな作業ごとに私へ確認を求めない。
- 必要な内部テストは省略しない。
- 不要な調査や重複した検証は避ける。
- 作業途中の変更は適切な単位でコミットする。
- mainブランチへの直接変更・無断マージは禁止。
- 既存の完成済みシステムを勝手に削除・簡略化しない。
- 技術的に不合理な部分は、合理的な方式へ修正し、その理由を報告する。
