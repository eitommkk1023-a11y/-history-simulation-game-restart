# foundation-v1 報告（決定事項の反映・技術の生成の試作・時間の測定）

設計書 v1 の決定（Q1 軍事＝指揮／Q2 国の段階＝毎年／Q3 主役＝あなたの人物・基本は頂点）を反映し、軍事に依存しない土台を先に進めた。**ゲーム本体（HTML）は変更していない**（試作は Node のみ。次の段階で本体へ接続する）。

## 1. 時間の測定（Q2「毎年」への影響）
- 実測（Node、世界生成後の最初の数年、住民約9,000人・動物4種）：**1年あたり約0.65〜1.1秒**（1か月の平均は約7〜74ms、年によって幅がある）。
- 国の層を「毎年」進めて快適に遊ぶには、1年あたり**50〜100ms以下**（1秒に10〜20年）が目標。今の個人ごとの計算の**10〜20倍の軽さ**が要る。
- 方針：国の層は、個人ではなく集団・民族の集計で計算する。個人の計算は、プレイヤーの近くだけ細かく（LOD）。

## 2. 技術の生成の試作（`npc/tech.js`、`npc/test-tech.js`）
世界ごと・民族ごとに技術が違うことの実現性を確かめる試作。

### 作り
- 技術を「名前つきの木」ではなく**節（ノード）**で表す。22節：食料（栽培・灌漑・輪作・牧畜）、素材（土器・銅・青銅・鉄・鋼・金銀細工）、エネルギー/輸送（水車・牽引・舟・外洋船・車）、記録/組織（刻み・文字・首長制・国家）、軍事（弓・金属武器・城塞）。
- ある民族がある節に届くかは、①**世界の資源**（鉱床・野生の穀物・動物・川・海・粘土・石・木。すべて既存の世界生成のデータ）がどの距離にあるか（近い＝そのまま、中距離＝交易で入手、遠い＝技術が伝わる、の3段階。遠いほど取り入れにくい）、②前提の節、③人口、④**文化の値**（年長者の尊重が高いと新しい技術に慎重、外婚性が高いと取り入れやすい、など）と運、で決まる。
- **やり方（バリアント）**と**名前**は、Seed・民族・節から生成（同じ「青銅」でも、鋳型・蝋型・鍛造の別、名前も世界ごと・民族ごとに違う。名前は仮の音の並び）。
- 決定性：同じ世界・同じ入力なら同じ結果。

### 測定（4つの世界：Seed 42・7・1・2026、各100民族）
| 取り入れの段階 | 民族あたりの技術 | 世界内の違い（民族の組・全22項目） | 世界間の距離（最も近い民族との違い） |
|---|---|---|---|
| はじめ（×1） | 約5.2個 | 5.0 | 平均0.89（最小0.84） |
| 進んだ（×3） | 約10.0個 | 6.3 | 平均1.71（最小1.53） |
| さらに進んだ（×8） | 約11.9個 | 7.1 | 平均2.14（最小1.87） |

- 「はじめ」の段階の到達率（4世界の範囲）：栽培 7〜8%・牧畜 46〜54%・灌漑 3〜5%・銅 10〜18%・青銅 約2%・鉄 14〜20%・鋼 0〜3%・舟 71%・外洋船 10〜22%。作物は世界ごとに違う（例：Seed 7 は麦・稲・トウモロコシ・アワ、Seed 1 は稲が中心）。
- 1世界100民族の計算は約0.1〜0.3秒（1民族あたり1〜3ms）。

### 読み取れること
1. **世界の資源が、技術の差になる**：青銅は銅と錫が近くに揃う民族だけ（約2%）。農耕も少数の中心地から広がる。これは設計の意図どおり。
2. **世界内でも民族ごとに違う**（段階を問わず、民族の組の違いは約5〜7項目）。
3. **世界間の違いは、技術が進むほど大きくなるが、頭打ち**：節が22個しかないため。「毎回違う文化」を強く保証するには、**節を100以上に増やし、各節にやり方の選択肢と連続の「作風」の値を持たせる**必要がある（本試作の結論）。
4. はじめの段階では、粗末な技術（土器・舟・弓）の民族が世界をまたいで重なる。これは自然（初期の文化は似る）。

## 4. 未実装・次に必要なこと
- 試作は**静的**（ある時点の取り入れ）。時間とともに、接触・交易・戦争・婚姻で技術が伝わる**動的な拡散**は未実装（国の層の核）。
- 節は22個のみ。ゲームの本体にはまだ接続していない（人口は民族の合計のため、「文字」「国家」は現状の小さな人口では届かない）。
- 縄文の暮らしの物・作り方・目標は、まだコードの中（データ表への切り出しが次の最初の作業）。
- **軍事の設計の受け取り**（Q1 確定の次の作業）：部隊の単位・隊形・命令・士気・兵站・指揮官・海戦。ユーザーの設計を受け取ってから、技術的な制約と突き合わせる。
