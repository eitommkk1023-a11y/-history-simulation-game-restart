# タイトル画面と開発者モード（報告）

ブランチ：`claude/title-screen-v1`（`claude/npc-ethnogenesis-v1` から）。画像：`docs/images/title-dev.png`、`docs/images/title-normal-ui.png`。

## 入れたもの
- **タイトル画面**（起動時に表示。世界はまだ作らない）
  - **続きから**：自動セーブがあれば有効（日付・Seed を表示）。無ければ無効。
  - **新しい世界で始める**：ランダムな Seed で開始。
  - **記録を読み込む**：記録1〜3・ファイルの読み込みの画面を開く（閉じるとタイトルに戻る）。
  - **開発者モード：オフ／オン**：切り替えると保存され（端末に記憶）、オンのときは「Seed を指定して始める」の欄も出る。
- **メニュー（≡）に「タイトルへ戻る」**：自動セーブしてからタイトルへ。
- **開発者専用の部品（開発者モードがオフのときは隠す）**
  - ツールバー：大陸を再生成／前の世界／Seed／Seed指定／表示切替／実験／開発者。
  - 実験パネル、開発者パネル（速度×10〜×1000 など）、左のメニュー、FPS 表示、表示の選択（植生・岩石など）、情報パネルの「民族の変化」。
  - 通常モードのツールバーは、視点リセット・世界を俯瞰・情報・メニュー（時間のバーはそのまま）。
- 動作確認用：URL に `?autostart` を付けるとタイトルを飛ばして新しい世界を始める（自動テスト用）。

## 確認（ブラウザ）
- タイトルの表示、世界が未生成であること、続きからの有効/無効、開発者モードのオン・オフと記憶。
- 通常モードで開発者向けのボタンが隠れ、視点リセット・俯瞰・情報・メニューは見えること。開発者モードで全部見えること。
- 2年進めて自動セーブ→再読み込み→「続きから」で日付が一致、人口も復元。メニューから「タイトルへ戻る」。
- 既存のテスト（住民・提案・名前・3D表示・継承・岩石・開発者モード）：エラーなし（岩石・開発者モードのテストは開発者モードをオンにして実行）。

## 注意
- 開発者モードは「隠すだけ」で、認証ではない（端末の設定で誰でもオンにできる）。
- タイトルは毎回出る（起動時の「前回の続きから？」の確認は、タイトルの「続きから」に置き換わった）。
