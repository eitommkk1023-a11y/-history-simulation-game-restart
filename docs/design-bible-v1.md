作成：Claude／対象：プロジェクトの全体像。ChatGPT で作っている設計資料（民族・思想など）と並べて、食い違いを見つけるための土台にする。

## 0. 決定事項（2026-11）

- **時間：1日＝現実の24分を基準**（連続して流れる。早送りで世代を進める）。「日の出〜日没＝1か月」案は、戦闘（伝令・偽装撤退・伏兵）と両立しないため取り下げ。
- **軍事の仕様**：ユーザー提供の統合仕様書（Ver.2〜20-6）を正とする（`docs/military-review-v1.md` に突き合わせ表）。人物ごとのHP・伝令・情報の不完全さ・戦争モードなし。

- **Q1 軍事＝指揮**（地図上で部隊を動かす。ユーザーの設計を受け取る）
- **Q2 国の段階＝毎年**
- **Q3 主役＝あなたの人物（基本は頂点）**

## 0.1 この文書の使い方

1. 第1章（ビジョン）が、あなたの構想の整理。違っていたら、まずここを直す。
2. 第2〜3章は、現状の実測と設計の原則。

5. 第7章が、**決めてほしい項目の一覧**。ここが埋まると、次の実装に入れる。

## 1. ビジョン【確定】

> 縄文時代と同等の時代から始まり、民族をまとめ上げ、指導者になり、村を発展させ、国を作る。民族の分裂や、他民族との融合を繰り返しながら、独自の技術・文化を発展させる。他国と貿易・交流を深め、時には戦争もしながら発展を続ける。

**この世界は、地球ではない。完全に別の世界。**（実在の国・民族・歴史を前提にしない。「中世ヨーロッパ」は、発展の到達点の目安にすぎない。）

## 3. 設計の原則【提案】

1. **「内容」ではなく「原理」を生成する。** 技術・制度・軍隊の「名前つきの一覧」を手で書かず、「何ができるか（能力）」の組み合わせと、その選び方のルールを作る。名前・見た目・順序は、Seedと文化から生成する。
2. **同じSeedなら同じ結果（決定性）。** 整数ハッシュのみ。保存は「Seed＋その後の変化」。
3. **データ駆動。** 物・作り方・建物・職業・技術・政策は、コードの中ではなく「表」にする。時代を足す作業を、表を増やす作業にする。（縄文の暮らしは、いまコードに直接書いてあるので、**表への切り出しが最初の作業**になる。）
4. **視点の梯子。** 個人・集団・国は、同じ状態を粒度を変えて見たもの。上の層ほど粗く、早く計算する。プレイヤーの操作は、層ごとに別の形になる（個人＝歩く・作る／集団＝提案・命令／国＝政策・外交・軍）。
5. **粗い時間。** 個人の層は日・月、集団は年、国は10年単位。早送りは粗い層だけを進める。
6. **つながり。** 貿易で技術が移り、戦争で民族が混ざり、婚姻で文化が溶ける、のように、柱同士は1つの仕組みでつなげる（別々の機能にしない）。
7. **検証できる設計。** 「毎回違う文化」は、別Seed間の違いを数値で測る（第4.1節の指標）。

## 4. 柱ごとの設計案

### 4.1 P1・P4：文化と技術の生成（核）【提案】

**課題：** 「何度作っても同じ文化にならない」ことと、「遊べる（意味のある選択がある）」ことの両立。

**案：能力（ケイパビリティ）グラフ**

- 技術を「名前つきの木」ではなく、**能力の軸**で表す。例：

| 軸 | 低 → 高（例） | 世界から決まるもの |
|---|---|---|
| 食料生産 | 採集狩猟 → 栽培 → 灌漑 → 輪作 | 育つ植物・気候・水 |
| 素材 | 石・骨 → 土器 → 銅 → 青銅 → 鉄 → … | **その世界で採れる鉱物**（岩石24種・資源の生成が既にある） |
| エネルギー | 人力 → 火 → 家畜 → 水 → 風 → … | 河川・風・森・家畜化できる動物 |
| 輸送 | 徒歩 → 家畜 → 車 → 船 | 動物・地形・海 |
| 記録 | 口承 → 刻み → 文字 → 紙 | 文化の言葉・素材 |
| 組織 | 血縁 → 首長制 → 官僚 → 国 | 人口・密度・文化（合議性など） |
| 軍事 | 素手 → 投擲 → 弓 → 金属武器 → 隊形 → … | 素材・組織・文化 |

- **技術＝軸の上の「到達点」と「前提」**。ある民族がどこに到達するかは、①その世界の資源（例：銅が無ければ青銅へは進めない）、②人口・密度（必要な人手）、③必要（圧力：飢え・寒さ・戦争）、④接触（貿易・戦争・婚姻での伝わり）で決まる。
- **名前・見た目・順序**は、民族の言語・文化値・素材から生成する（同じ「鉄」でも、世界ごとに呼び方・道具の形が違う）。
- **文化の「ゲノム」**：既存の文化8値（外婚性・母系性・年長者の尊重・世襲性・合議性・男系性・成人年齢・言葉のずれ）を、**政策・軍事・都市計画・美意識**の各ゲノムへ広げる。次元の数と組み合わせの数を増やし、衝突しないようにする。
- **「違う」の検証指標**【提案】：別Seedを20個作り、(a)到達する技術の集合、(b)政策の選択肢、(c)軍の編成、(d)都市の形、の各々を数値のベクトルにして、**2つの世界の距離**を測る。距離が一定以上であることを、自動テストにする。

**試作の結果（`docs/foundation-v1-report.md`）：** 22節・4つの世界で、世界の資源が技術の差になること、世界内でも民族ごとに違うこと、世界間の違いは進むほど広がるが頭打ち（節が少ないため）であることを確認。**節を100以上＋やり方の選択肢＋連続の作風の値**に広げる必要がある。

**拡散の試作（`docs/nation-v1-report.md`）：** 発明＋接触で伝わる仕組みを、民族の集計として毎年進めた（3000年・4世界）。農耕が1か所から波になって広がる、青銅の到達が世界で24〜71%と違う、など世界ごとの違いが自然に出る。

**既存との接続：** 文化8値、建築ゲノム（arch-gen）、言語・名前、継承・指導者の決め方。→ これらを**ゲノムの一部**として束ねる。

**未決：** 技術の軸の数（いまは7を例示）、1つの民族が同時に持てる技術の数、技術が「失われる」ことを入れるか。

### 4.2 P2：指導者の成長と、視点の梯子【提案】

| 段階 | 遊ぶ視点 | 操作 | 計算の粒度 |
|---|---|---|---|
| 個人（縄文〜） | 3人称/1人称 | 歩く・採る・作る・話す・狩る | 日・個人 |
| 指導者 | 集落の中＋地図 | 提案・命令（方針・移住・分配・建設） | 月・集団 |
| 国 | 地図中心 | 政策・外交・貿易・軍の動員 | 年〜10年・国 |
| 帝都 | 都市の編集 | 区画・道・施設の配置 | 年・都市 |

- 既存の「提案」（方針・移住）と首長・評判・配給を、**指導者の命令の入口**にする。
- 世代の継承は、すでにある。**国の段階でも「あなたの人物」を保つか**は未決。
- 上がるきっかけ：評判・人口・定住の段階など。

### 4.3 P3：民族の離合集散【提案】

- 既存の年ごとの分裂・融合・吸収に、**プレイヤーが関われる場面**を足す（分裂を防ぐ・促す、婚姻での融合を結ぶ、征服した民族をどう扱うか）。
- 融合した文化は、両方のゲノムを混ぜる（優勢な側に寄る）。分裂した文化は、離れた時間で少しずつずれる（既存の「言葉のずれ」と同じ考え方）。

### 4.4 P8：政策と都市の作り【提案】

- **政策**：文化のゲノムから「選べる政策の集合」を生成する。同じ「税」でも、文化によって「労役」「貢納」「共同の蓄え」の形が違う。選択は、効果と副作用のつりあいにする。
- **都市**：既存の集落の自動配置を、文化の都市計画ゲノム（道の形・中心の置き方・防御・区画）で拡張する。
- **帝都の改造**：区画・道・施設の配置を、プレイヤーが編集できるようにする。制約（地形・水・人口・文化）で、むちゃな配置はできない形にする。

**未決：** 編集の自由度（区画単位か、建物1つずつか）、編集中の性能（モバイル）。

### 4.5 P7：軍事【提案・最重要の未決あり】

**目標：** 文化ごとに違い、洗練され、自由度が高い。

**構成案：**

1. **兵力**＝人口の一部。職業「警備者」の延長で、徴兵・民兵・常備・戦士階級・傭兵などの**組織の形を文化から生成**する。
2. **装備**＝技術から決まる（素材の軸 × 軍事の軸）。
3. **戦術の考え方（ドクトリン）**＝文化から生成（密集・散開・騎馬・奇襲・籠城・海上など）。
4. **兵站**＝既存の食料の計算に乗せる（軍は食べる）。補給線＝交易路と同じ地図。
5. **地形**＝既存の地形・斜面・気候を使う。
6. **戦闘の解決**＝層別：小競り合い → 会戦 → 包囲 → 海戦。
7. **死と継承**と連動：戦死は、既存の継承の仕組みに入る。

**決定（Q1）：指揮。** 地図上で部隊を動かして戦う。設計の中身（部隊の単位・隊形・命令・士気・兵站・指揮官の能力・海戦の扱い）は、**ユーザーが持っている設計を受け取って**から確定する。Claude は、それを技術的な制約（下の「性能の論点」）と突き合わせる。

**性能の論点（先に分かっていること）：**
- 画面に出せる兵の数（描画はインスタンス化で数千規模は可能。個人の計算ではなく、部隊の集計で動かす必要がある）。
- 地形は、遊ぶ画面（約33m/マス＋1m細部）が既にあり、戦場に使える。
- 戦闘中は、時間を「日ごと」より細かく（時・分）進める層が要る。
- AI同士・画面外の戦闘は、自動計算で解く（これは選択ではなく性能上の必要）。

- **案A（自動計算＋方針）**：編成・目標・方針を決め、結果と戦況報告が返る。軽く、速く、深い編成の自由度に集中できる。
- **案B（地図上の指揮）**：部隊を動かす。見せ場は大きいが、操作・AI・描画・性能の負荷が大きい。
- **案C（折衷）**：普段は自動、重要な会戦だけ指揮に切り替える。

### 4.6 P5：貿易と海【提案】

- **資源と需要**：既存の資源の地図から、民族・都市ごとの余りと不足を出す。
- **陸路**：道は自動に生成され、プレイヤーも敷設できる。商隊の輸送量・速度・襲撃の危険を持つ。
- **海路**：港・造船所・船（船の種類は、技術と素材から生成）・航路。天候（既存）で嵐。海戦は軍事の一部。
- **別プロジェクトの船舶**：統合の方法を決める必要がある（第7章 Q6）。
- **効果**：技術の伝わり・文化の混ざり・富。→ P1・P3 とつなぐ。

### 4.7 P6：外交【提案】

- 個人の関係（信頼・好意・尊敬）を、集団間・国家間に**集約**する。
- 条約の型：停戦・通商・同盟・従属・婚姻同盟など。**選べる型は文化で変わる**。
- 相手国の指導者の判断＝性格 × 状況 × 文化（住民の性格の値が既にある）。
- 評判と裏切り（条約を破ると、全体の信頼が下がる）。

## 5. 技術的な制約と対応【提案】

| 課題 | 対応案 |
|---|---|
| 1万年の早送りが重い | 国の層を粗く（10年単位・集団単位）。個人は、プレイヤーの近くだけ細かく（LOD） |
| 単一HTMLが大きい | モジュール分割と遅延読み込み（時代や機能ごと）。アーティファクトの上限（16MB）に注意 |
| 世界生成が25秒 | 現状維持（ロード画面あり）。文化・技術の生成は、これに足して数秒以内に |
| iPhoneの性能 | 描画はインスタンス化を維持。軍や船の数は、粗い層の「集計」で扱う |
| 記録の大きさ | 国・条約・軍・航路を、集計値で保存（個人の保存は現状どおり） |
| テスト | 単体（Node）＋Playwright。**最後にまとめて1回**の方針を継続（クレジット効率） |
| 実機確認 | 各段階の完成時に、必ず実機で確認する場を作る |

## 6. 段階（マイルストーン）【提案】

各段階は「遊べる状態」で区切る。概算の「まとめ」は、直近の「生存の完成」程度の作業量を1と数えた**見立て**（確実な数字ではない）。

| 段階 | 遊べる状態 | 含む柱 | 概算 |
|---|---|---|---|
| **M0**（済） | 縄文の暮らしを個人として生きる | 個人・集団とのつながり | — |
| **M1 指導者と村の成長** | 農耕・牧畜で村が育ち、指導者として提案・分配・建設ができる | P2・P3 | 3〜4 |
| **M2 文化・技術の生成（核）** | 世界ごとに技術と文化が違うことが、数値で確かめられる。技術の表とゲノムの基盤 | P1・P4 | 4〜6 |
| **M3 国** | 領土・政策・内政・陸の交易・外交ができる | P2・P5・P6・P8 | 4〜6 |
| **M4 軍事** | 編成・兵站・戦闘・戦争ができる | P7 | 4〜6（Q1 で変動） |
| **M5 海** | 港・造船所・船・海路・海戦 | P5・P7 | 3〜5 |
| **M6 帝都と帝国** | 帝都の改造・帝国の運営 | P8・P2 | 3〜4 |
| 仕上げ | 性能・実機確認・バランス・保存の大きさ | 全体 | 2〜3 |

**合計：およそ 23〜34**。M2 は他の段階のすべての土台なので、**M1 の途中から並行して設計**する。

**最初にやる作業（骨組み）**：①縄文の暮らしの「物・作り方・目標・係数」を、コードから表（データ）へ切り出す。②技術・能力の基本の型を決める。③粗い時間の進め方（10年単位・集団単位）の試作と、性能の測定。

## 8. ChatGPT の設計資料との突き合わせ

次の手順で、食い違いを見つける。

1. ChatGPT の資料（民族・思想：412思想、30〜50の初期の思想 など）の**見出し**を、この文書の柱（P1〜P9）に振り分ける。
2. 各項目に、**状態**（実装済み／この設計に含まれる／含まれない／矛盾する）を付ける。
3. 「含まれない」ものは、段階（M1〜M6）のどこに入れるかを決める。
4. 「矛盾する」ものは、第7章の項目として追加する。

> 注：以前に確認した資料の要点＝「プレイヤーは1人」「後継は文化による」「動物は3種に絞る」（のち4種）。元のZIP（v20・v10）は、まだ手元に無い。

## 9. 用語

- **ゲノム**：世界のSeedと民族から決まる、文化・建築・政策などの「性質の組み合わせ」。
- **能力（ケイパビリティ）**：技術を「何ができるか」で表した軸。
- **視点の梯子**：個人 → 集団 → 国 → 都市と、同じ状態を粒度を変えて見る仕組み。
- **LOD**：近くだけ細かく、遠くを粗く計算・描画すること。
- **まとめ**：機能を1つずつ出さず、まとまった単位で実装し、全テストを最後に1回流す作業単位。
