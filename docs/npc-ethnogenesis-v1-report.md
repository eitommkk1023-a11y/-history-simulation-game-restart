# 民族の形成・分裂・融合・吸収（報告）

ブランチ：`claude/npc-ethnogenesis-v1`（`claude/npc-names-v1` から）。ユーザーの確認：「文化の特徴を集団に持たせる」「集団をまたぐ結婚を入れる」。以後は私の判断で進める方針。

## 設計の考え方
- 民族の成立は**単独の条件（時間・人口・距離）では起こさない**。文化の離れ具合・離れている年数・人口の条件がそろい、確率で起こる（仕様書の原則）。
- 民族IDは消さず、親・祖先・状態（生きている／融合した／吸収された／絶えた）を記録する。
- 民族の成立と、個人の帰属の変更は別の出来事。新しい民族ができても、大人は毎年一部（20%）が新しい民族を自分の帰属にし、元の民族は副次的な帰属として残る。12歳未満は、育った集団の民族になる。

## 入れたもの
1. **集団をまたぐ結婚**：近くの集団（35ブロック＝約115km以内、他の民族も含む）の男性を選ぶ。外婚性の高い文化ほど多い（結婚の3〜48%）。夫が妻の集団へ移るのは、母系性の高い集団。
2. **文化の特徴（集団ごと、0〜1の8つ）**：外婚性・母系性・年長者の尊重・世襲性・合議性・男系性・成人年齢・言葉のずれ。毎年、本体（または自分の塊）の平均へ寄り、近くの他の民族の文化へ少し寄り、揺れる。
   - **民族の決まり（継承の7種・首長の4種・成人年齢）は、この特徴から決まる**。新しい民族は、親と違う決まりを持つことがある。割り当ては、継承が約25/17/10/16/7/15/10%、首長が約32/30/21/17%になるように調整した［仮］。
3. **民族の分裂**：本体とつながっていない塊が、本体との文化の距離0.2以上・離れて60年以上・人口80人以上のとき、確率（年6%、距離が大きいほど高い）で新しい民族になる。新しい言語（親の言語から分かれる）・名前・色が付く。
4. **融合・吸収**：接触が40年以上・小さい民族の成人の12%以上に相当する集団をまたぐ結婚（直近）・文化が近い、のとき、年5%の確率で起こる。人口比が0.3以上なら**融合**（新しい民族ID、祖先は2つ、言語は混ざる）、0.3未満なら**吸収**（小さい方は記録に残り、大きい方に加わる）。
5. **変化の速さの設定**（情報パネル「民族の変化」：標準／速い×3／とても速い×8）。時間の条件を短くし、確率・揺れを大きくする。保存に含まれる。
6. 画面：出来事（分裂・融合・吸収）、「自分の民族」に由来（「○○族から分かれた」「○○族と△△族の融合」）。

## 測定（Seed 42）
- 標準の速さで150年：融合7回・吸収2回・分裂0回・絶えた18。民族 100→73（記録は107件）。集団をまたぐ結婚 1,924回。
- 速さ×8で100年：融合10回・分裂3回・吸収2回。民族 100→78（記録は113件）。
- 民族の年次処理を含む月の計算：平均 約17ms（最大 約38ms）。人数ではなく集団単位なので、人口が増えても増えない。
- 整合性：消えた民族に属する生きた集団 0件。保存→読み込みで、民族の記録・集団の文化が一致。人口は50年で約7,500人で落ち着く（以前と同じ）。
- ブラウザ（速さ×8、60年）：融合・吸収・絶滅の出来事、新しい民族の言語（200番台）と名前、保存→読み込みの一致を確認。岩石・開発者モード・提案・名前・キャラクターの移動も、エラーなし。

## 注意・未解決
- **標準の速さでは、分裂がほとんど起こらない**。集団は分裂しても近くにとどまるため、「本体とつながっていない塊」が生まれにくい。長い遊びで見える現象なので、速さの設定を用意した。移住の仕組み（遠くへ出る）を強めるか、つながる距離を短くするか、遊んでから決めたい。
- 初期の100民族は「1民族＝1集団」なので、最初の数十年は融合・吸収・絶滅が中心になる。
- 融合で、新しい民族の言語は、二つの言語を混ぜたものになる。集団名は元の言語のまま。
- 外婚の結果、子は両親の民族を副次的な帰属として持つが、その使われ方（帰属意識の強さ）はまだ無い。
- 文化の特徴の8つのうち、「言葉のずれ」は分裂の判定にだけ使っている。実際の言語の変化（時間による言葉の分化）はまだ。
- 全ての数値は仮。
