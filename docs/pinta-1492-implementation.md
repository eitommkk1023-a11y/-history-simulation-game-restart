## 2. このゲームでの仮説・推定（D または derived。`src/ship/pinta-1492-params.mjs`、全項目に証拠レベルと注記）
- 船体：断面は仕様の試験値の半幅表（D）を滑らかにつなぎ、上記のB値（全長・幅・水線長・水線幅・軽荷喫水・竜骨長）を満たすように形を合わせた。**曲線の制御点は実測点ではない。**
- 甲板の高さ2.60m（Puntal 2.28m＋0.32mの余裕、D）、舷墻0.7m（D）、船尾甲板（長さ船長の26%、高さ+0.95m、D）、昇降口（D）。
- **船倉の仕切り（D）**：研究は船倉全体の内部寸法しか示さず、原船の仕切り方は不明。資料の「船倉の中身（水樽・食料・船具・補修材・バラスト・貨物）」に沿って、後部倉庫（水樽・食料）／中央の貨物倉（昇降口あり）／前部倉庫（帆・索具・補修材）の3つに仮に分け、扉口2か所でつないだ。船室は作っていない（原船の居室は不明、豪華な船長室は禁止）。
- **質量は入力ではなく結果**：軽荷時の排水量 = 船体形状が喫水1.58mで押しのける水の重さ（約63.8t、D の船体形状による）。構成（船体55%・バラスト28%・索具7%・艤装10%）と重心高は D。
- 積荷（シナリオ用、D）：乗員26人×75kg、飲料水樽10個（1個260kg）、食料1,200kg → 排水量約69.5t、喫水約1.68m。
- 帆装：前檣・主檣は横帆、後檣はラテン帆（研究者の三檣候補、B〜C）。檣の位置・高さ・帆桁長・帆面積は**すべてD**。別案 `departure_lateen_hypothesis`（出航時にラテン帆とする仮説、C〜D）は、3本ともラテン帆として保持。**どちらの帆装を改装したのか（ピンタ号かニーニャ号か）は史料に異説があり、確定しない。**
- 帆の布は無漂白の亜麻色。**十字・紋章・旗は付けていない**（意匠は未解決）。
- 舵：船尾材に吊る方式（舵板・舵柄は D の寸法）。
- 武装：`status: unresolved`。砲は付けていない。
- 船体の摩擦・造波・横流れなどの係数：一般的な値（D）。この船に合わせて校正していない。**速度は出力であり、史料の最高速を採用していない。**

## 3. 実装済み
**データ・検証（M0）**：資料の取り込み（資料のJSONと一致をテスト）、証拠レベル・単位・「重量でない」「未確定はD」などの規則の自動検査、仮説はすべてD／derivedと注記つき。
**外形・スケール（M1）**：研究値から生成した船体（17断面、全長16.90m・最大幅5.00m・水線長15.75m・水線幅4.70m・軽荷喫水1.58mを再現、前後の傾きなし、GM 0.83m）、閉じた描画メッシュ、浮力用の形状（同じ断面）、主甲板・船尾甲板・船倉と、はしご・昇降口、甲板歩行（壁・船体の幅の内側）、舵（舵角で回転）、舷墻、キール・船首材・船尾材、外板の継ぎ目、昇降口の縁、樽、1:1の人物、描画の詳細度（近・中・遠）。
**帆装・帆走（M2）**：前檣・主檣の横帆と後檣のラテン帆（大西洋横断案）、全ラテン帆（出航時の仮説案）の切替、マスト・帆桁・帆布・静的索具・動索（帆桁の動きに連動）、無漂白の帆、見かけの風・横流れ・舵力・復原力、帆の操作の時間（手の数で速さが決まる）、風と海流に応じた航行、船長への委任（目的地を指定すると自動で航海）。
**積荷・船員・シナリオ（M3・M4）**：樽・食料・バラストの積み降ろしで質量・重心・喫水が更新される、船員26人（史料の3人＋汎用の乗組員）、当直（4時間交代）、持ち場への移動（階段を含む）、舵に人がいなければ舵は動かない、見張り、舵の状態（外れる／応急／再修理）、漏水と排水（船倉の水を質量として扱う）、1492年8月の3つの出来事（8/6 舵が外れる、8/7 修理、8/8 漏水）を、史料の区分Aと「どう起きたか」（D）を分けて再現。
**本体での船上歩行（2026-11-05）**：乗ると、本体のスティック・WASD・矢印キー・走る・しゃがむで甲板を歩ける。本体の移動処理が持つ差し込み口（`__wohDev.step`）を、乗船中だけ使う。深い水の上では本体の標準処理が止めてしまうため。歩く速さは本体の値（歩き1.5m/s、走り4m/s、しゃがみ0.65m/s）。壁・船体の幅・はしごは、テスト世界と同じ船内の部品が決める。船の揺れ（傾斜）でも足元の甲板に合う。船倉に下りると断面表示：船体は**不透明のまま**、すぐ上の甲板から上を切り取って（切断面は船の傾きに合わせる）、帆・マスト・上の構造を隠し、船内の床・壁・乗組員が見える。本体では、船倉の床が海面より下にあるため、断面表示の間だけ海面を隠す。カメラの軌道（距離4m）は本体と同じ式で、描画の直前に置き直す。乗っていないときの歩行は変更しない。
**表示・確認**：「史料と推定」パネル（研究値・仮説・異説・未確定の一覧）、テスト世界（軽く、約1秒で開く）、本体の写し（乗船・乗組員・舵・帆の3D）。
**検査**：`tests/pinta-data|hull|crew|scenario|audit.test.mjs` ほか全116件、`tools/check-pinta-3d.cjs`（3Dの寸法と有限性の確認）。監査テストは、後世の特徴（砲、帆の紋章、旗、バウスプリット、船室、高い船楼、4枚以上の帆）がないことと、40.10を重さに使っていないことを確認する。

- 本体の保存データ（`serializeState`）には船が入っていない（船はブラウザの別の保存先）。本体の保存処理の書き換えが必要。
- 実機（iPhone／iPad）での性能測定と描画負荷の評価（乗組員の図形は1人あたり2つの描画物で、まとめていない）。
- 浸水の完全な物理（今は漏水をバラストの水として質量に加える簡易版。区画間の流れ・自由表面効果は未接続）。舵の損傷は、舵力の割合で表している（舵の取り付けの物理ではない）。
- 帆の揚げ下ろし・裂け、前帆と主帆の風の干渉、索具の負荷と破断。
- 船員の技能・疲労・個人IDの人口システムへの接続（人口システムの実コードがこのリポジトリにない。IDは仮）。当直は固定の2交代（D）。
- 遠方の船の集約計算（休止中の航海）、船体の遠景専用メッシュ（今は同じメッシュを使い、索具と継ぎ目だけ省く）。
