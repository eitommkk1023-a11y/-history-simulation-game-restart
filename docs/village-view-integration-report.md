# 村の造形（Codex 試作：畑・家畜・施設）を本編へ取り込み

ブランチ：`claude/village-view-v1`。取り込み元：`codex/prototype-village-v1`（`prototypes/village/*.mjs`）。

## 取り込んだもの
- `tools/build-village-view.py`：Codex の ES モジュール5つ（geometry／fields／livestock-model／livestock／facilities）を、1ファイル `npc/village-view.js`（約31KB、グローバル `WohVillageView`）に変換。再生成：`python3 tools/build-village-view.py <Codexの抽出ディレクトリ>`。外部の画像・モデルはない（形・色・骨格は手続き生成）。
- 本編（`dwScan`、1秒に1回）に、近く（300m以内）の集団の畑・施設・家畜を集めて、変わったときだけ Codex の描画に渡す処理を追加。毎フレームは、カメラに合わせた LOD 更新と家畜の動きだけ。上限は畑200・家畜300・施設128。
- 畑：集落の配置（`layout.fields`）の区画を、Codex の畑にした（以前の平らな緑の板は、造形が使えないときだけ）。四隅の高さは地形から。作物は集団ごとに決まり（穀物70％・根菜30％など）、**生育は季節**（耕土→芽→伸長→実り→刈り跡）。季節の進みは人口の層（`g.cropStage`）が月ごとに計算。
- 施設：あなたが建てた**倉庫（高床倉庫）・井戸・家畜の囲い**が、村の広場のまわりの空いた場所に出る（建物・畑・ほかの施設と重ならない所を決定的に探す）。
- 家畜：集団の家畜の数（上限50頭を描画）が、囲いがあれば囲いの中、なければ村はずれに。体型は集団ごとに決まる（大型・山羊羊系・猪豚系）。状態（食べる・立つ・寝そべる・歩く）はばらつかせる。

## 確認したこと
- ブラウザ：技術を与え、倉庫・井戸・囲いを建てると、3つの施設と家畜9頭、畑が出る。柵と小屋の囲いの中に家畜がいる。畑には芽が並ぶ。ページエラーなし。
- 描画：畑2・家畜1・施設1の描画命令（Codex の計測どおり少ない）。家畜の骨格テクスチャは 192KiB。

## 未確認・課題
- **iPhone/iPad の実機の速さ**：Codex の報告どおり未計測。最大数（畑200・家畜500・施設80）の場面は、ソフト描画では重かった。実機で見て、距離や上限を調整する。
- 家畜は止まった位置で動く（位置を動かす歩行はなし）。群れの移動・放牧の動きは未実装。
- 施設の材料（壁・屋根）は今は木と草で固定。集団の建築の伝統（`arch-gen`）に合わせるのは次。
- 貯蔵穴・干し棚・共同の炉・物見櫓・窯は、造形はあるが、本編の仕組み（建設）とまだつながっていない。
- 村の「村ページ」は、本編側ですでに作った実データ版を使い、Codex の試作07（確認・取消の画面）は取り込んでいない。

# 続き：家畜が動く（claude/livestock-move-v1）

- 家畜の位置と行動を、ゲーム側で毎フレーム進める（約0.1秒ごと）。1頭ごとに「食べる／立つ／寝そべる（牛・山羊系だけ）／歩く」を入れ替え、歩くときは進行方向を向く（Codex の歩くクリップを使う）。
- **囲いがあれば、囲いの中だけを歩く**（柵から出ない）。囲いがなければ、村はずれの決まった範囲（半径20m）を歩く。水辺・急斜面には入らない。
- 家畜の数が増減しても、いる家畜の位置は動かさない（端から増減）。
- 動く家畜がいるとき、画面は再描画され続ける（約15フレーム/秒の更新）。
- 確認：50頭の群れで、8秒間に17頭が歩き、26頭が食べ、7頭が寝そべる。囲いの中の家畜は柵の外に出ない。エラーなし。
- 未実装：群れでの移動（先導する個体について行く）、人が近づいたときの反応、家畜どうしの衝突。実機の速さは未計測。
