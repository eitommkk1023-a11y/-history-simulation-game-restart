# ui-layout-v31 報告（HUDをモックの配置に作り直し）

ユーザーが示した画面モック（左上に日付と目標、上に方位、右上にボタンと丸いミニマップ、左下にステータス、下にホットバー、右下に操作ボタン）に合わせて、HUDを全面的に作り直した。絵（アイコン・パネル）はCSS/SVGで同じ雰囲気に作った。仕組みの無い物は「準備中」表示。

## 配置（iPhone横画面 874×380 を基準に、画面に合わせて 0.8〜1.6 倍で拡大縮小）
- **左上**：季節（春夏秋冬）・日付（「1月1日（1年目）」）・天気と気温（いまいる場所）・時間の操作（▶／日ごと／速さ／+1）。日付をタップすると歴史。
- **左**：「暮らしの目標」（11段階の入門：食べ物→薪→火→焼いた物を食べる→縄→粘土→土器→水さらしの木の実→煮物→家→家で眠る。進み具合「（0/5）」と「1/11」）。
- **上**：方位の帯（N・NE・E…が向きに合わせて流れる）。
- **右上**：マップ・情報・UI非表示・メニュー。その右に**丸いミニマップ**（視界の扇形・拠点・北）。FPSと速さはミニマップの下端に入れた（要望）。左隣に拡大／縮小／1人称視点のボタン。
- **左下**：ステータス4本（体力・スタミナ・満腹・水分）。**満腹だけが実際の値**（満腹度）。他の3本は準備中で、押すと「〜は準備中です」。
- **下中央**：持ち物・製作・装備・仲間・依頼・記録。持ち物と製作は持ち物パネル（製作は「作る」欄へ）、記録はメニュー（保存・読み込み・歴史）。装備・仲間・依頼は準備中。
- **右下**：「調べる」（大きな手のボタン。上の「食料／素材」で何を探すか選ぶ）、ジャンプ、ダッシュ、しゃがむ。
- **UI非表示**：HUDを隠す（ボタン・操作ボタン・ミニマップは残る）。**マップ**：世界を俯瞰（このときは従来の上のボタン列）。
- 開発ツール（再生成・Seed・実験など）は通常は隠し、メニューの「開発ツール」（開発者モードのみ）で出す。
- 持ち物パネル・メッセージはホットバーの上に出るようにした。1人称視点の切り替えボタンはミニマップの横。

## 検証（合格）
- 画面サイズ3種（iPhone 874×380、小さめ 740×340、iPad 1180×820）で、各部品の重なりを座標で確認。意図した重なり（操作ボタンの丸同士の外接の枠、ミニマップの縁の拡大ボタン）以外は無し。スクリーンショットも確認。
- Node 単体 158件（目標の判定・カウンター・保存を追加）。
- Playwright：日付・天気・FPS表示、情報/メニュー/マップ/UI非表示、準備中の表示（装備・仲間・依頼・体力）、調べる（素材モード）、持ち物・製作、ミニマップのズーム（拡大・縮小）、1人称ボタン、目標が進む、満腹バー（600kcal→20%）、開発ツールの出し入れ。エラー0。
- 回帰：titletest / devtest / rocksmoke / gotest / foragetest / cooktest / crafttest / hometest / fptest / avatartest / proptest / peopletest 通過（配置の変更に合わせてテストの操作を更新）。

## 未実装・未確認
- 体力・スタミナ・水分、装備、仲間、依頼、「話す」は準備中（見た目だけ）。方位の帯の下の目盛り・時間帯の太陽（朝昼夕の表示）は作っていない（ゲームに時間帯が無いため）。
- 天気はいまいる場所の気候から。ゲームの天気（実験パネルの変化）が動いているときはそれを使う。
- アイコンは線画の簡易版で、モックの細部とは異なる。実機（iPhone/iPad）のタップのしやすさ、文字の大きさは未確認。
- 「UI非表示」中もミニマップは残している（モックでは不明）。消したい場合は変更できる。
