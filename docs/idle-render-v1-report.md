# 視点停止時にアニメーションが止まる問題（原因・修正・検証）

## 症状
視点操作を止めると、FPS表示が0になる。NPCは動き続けるが、船舶の試作では波と船が止まる。

## 原因
1. このゲームは、**描画を「変化があったときだけ」行う**（省電力）。毎フレームの更新（`requestAnimationFrame` のループ）は、止まらずに回っている。ゲーム内の時間・NPC・物理・天候は、毎フレーム進む。
2. 描画をするかどうかは、「歩いた／地面が変わった／草が変わった／NPCが動いた／火や家畜が動いた／戦闘画面が動いた」のいずれかがあったときだけ。**波や船のように、カメラが止まっていても動き続けるものが、「描き続けて」と頼む窓口がなかった**。
3. FPS表示は、「1秒間に実際に描いた回数」（描画回数）を数えている。何も変化がなければ描かないので 0 になる。これは数え方として正しいが、「止まった」ように見えて紛らわしい。
4. 船舶版（ゲームに船舶のプラグインを足したもの）は、窓口がないので、ゲーム内部の変数（`state.drawDirty`）を直接書き換えて描画を促していた。しかも、条件が「船に乗っているか、800m以内に船が見えるとき」の**地上の視点だけ**で、**世界を俯瞰する画面や、遠い船は止まる**。

## 修正（このリポジトリの `World-of-History-v30-development.html`）
- **アニメーションの要求の窓口**を作った：`__wohNative.animate(名前, 指定)`。
  - `true`：止めるまで、毎フレーム描く。`false`：止める。数（ms）：その時間だけ描く（毎フレーム呼べば続き、呼ぶのをやめれば自然に止まる。置き忘れで描き続けることがない）。
  - 要求がないとき（何も動いていないとき）は、これまでどおり**描かない**（省電力は維持）。
  - 地上の視点も、俯瞰の画面も、同じ窓口で描く。`__wohNative.animating` で、いま要求している名前の一覧を見られる。
- 時間・NPC・物理の更新と、描画の判断は、もともと分かれている。変更は「描画の判断」に、要求を足しただけ（**描画を無意味に増やしていない**）。タブが見えないとき（`document.hidden`）は、これまでどおり更新も描画もしない。復帰時の時間差は、各更新で `min(dt, 0.05〜0.1)` に抑えている（船や波が急に大きく動かない）。
- **FPS表示**：数え方は「実際に描いた回数」のまま変えない（数値の見せかけの操作はしていない）。描いていないときは、「FPS 0（静止・省電力／ループ60）」と出す。ループ60は、更新のループが生きている回数。

## 検証（ヘッドレス・ソフト描画。実機の速さではない）
原野（NPC・火・家畜が見えない所）で、カメラを30秒止めた。
| 状態 | 描画（回/秒） | 更新のループ（回/秒） |
|---|---|---|
| カメラを動かしている | 11.6 | 16.2 |
| カメラ静止（何も動かない） | **0** | **60** |
| 静止＋ `animate('wave', true)` | **11.9**（描ける限り毎フレーム） | 11.9 |
| 要求を止めた直後 | 0 | 59.9 |
| 期限つき要求（毎フレーム更新→やめる） | 11.8 → 0 | 12.2 → 60.2 |
- 静止30秒の間、**ゲーム内時間は進んだ**（0.00766→0.02851日。24分で1日の速さで30秒ぶんに一致）。表示は「FPS 0（静止・省電力／ループ61）」。
- 村の中（NPC60人が見える所）で、カメラを15秒止めた：**描画 10.7回/秒（NPCが動くので描き続けている）**、同じNPC56人のうち20人が移動した。
- ソフト描画は描画が重く、描画回数が上限（約11回/秒）に張り付く。実機は60に近づく見込みだが、**未計測**。

## 試作ごとの調査結果
| 試作 | 同じ不具合 | 内容 |
|---|---|---|
| このゲーム（World of History） | 窓口がなかった → 修正 | 上記 |
| 自然地理生成器（`自然地理生成器.html`） | 同じ「変化があったときだけ描く」設計。波・船はない | 降水・噴煙・日付は変化として描画を要求している。止まる対象はなし。0 FPSは省電力の待機 |
| 船舶版（ゲーム＋船舶プラグイン、公開ページ） | **あった**（部分的な回避のみ） | 船に乗る／800m以内のときだけ描画を促す。俯瞰・遠い船は止まる。**プラグイン側を `animate('ships', 250)` を毎フレーム呼ぶ形に直すのが正しい**（下記） |
| 船舶テスト海（単体） | なし | 毎フレーム物理と描画を行う。カメラ操作と無関係 |
| 船舶シミュレーター（単体、2D） | なし | 毎フレーム描画。カメラ操作と無関係 |

### 船舶版のプラグインの直し方（このリポジトリには、船舶プラグインのソースがないため、未適用）
`frame()` の中の
`if (cp.state && !cp.view.overview && (boarded || …)) cp.state.drawDirty = true;`
を、次のように置き換える（俯瞰でも、遠い船でも、船が1隻でもあれば描く）。
`if (fleet.list().length) nat.animate('ships', 250);`
船が0隻になれば、呼ばなくなり、自然に省電力へ戻る。
