# 小規模統合ワールド 再構築（報告）

ブランチ：`claude/small-world-v1`（`main` 未変更・マージなし・公開ページ未更新）。独立HTML：`World-of-History-small-world-trial.html`（`main` の HTML と同じ単一ファイル。タイトル画面の「小規模ワールド（試験）」、または URL に `?small`／`?small=Seed` を付けると、小規模ワールドを神モードで始める）。

## 1. 第1工程：既存コードの統合準備
- Codex の2ブランチ（`politics-military-p0` は `politics-main-integration` に含まれる）：政治・軍事の土台（任務台帳・伝令・食料の運搬・保存の整合）を、**衝突なし**で作業ブランチに取り込んだ。取り込み後、Codex の node テスト120本は全て合格。HTML の既存の確認（HUD・開発者モード・人口・神モード）もエラーなし。
- 自律的な戦争・襲撃は既定で無効のまま（変更していない）。思想412種のカタログの正本は無く、代替は作っていない。
- Ver.4 の正本は入手できなかったため、`main` と上記を土台にした（指示に従い、Ver.4の復元はしていない）。

## 2. 第2工程：小規模ワールド（`npc/small-world.js`、`people-core.js` の `small` 設定）
- **世界**：既存の世界の生成をそのまま使い、陸地の20km四方（601×601セル）の窓を選ぶ。川・起伏・森が多い窓を好む（森が薄い窓は減点）。窓の外には人を置かず、動物の個体群は窓の外を計算から外す（窓の中・近くはそのまま）。大規模世界の既存設定は変えない（`small` を渡したときだけ働く）。
- **初期集落**：4村（定住）・約200人。食料の点数が高い場所から順に選び、村どうしの距離は最も近い村まで3〜10km。4つの民族。窓の縁から40セル内側。窓の外へは移住しない。
- **自然な成長・衰退**：戦争・移住を強制していない（9つの世界×Seedの60年で、戦争・襲撃は起きず、移住は自然に0〜4件）。
- 初期の置き方の改善：最初は点数に比例した乱数で選んでいたため、食料の乏しい場所に置かれた村が10年で人口の約3割を飢えで失い、滅びる組み合わせがあった。食料の高い場所から選ぶ方式にして、9組すべてで4村が60年続いた（人口 約170〜400）。

## 3. 第3工程：観察・統計・操作（既存の神モードを改修。新しいモードは作っていない）
- 村へのジャンプ（村の一覧・ラベル・ランキングから）、自由なカメラ（移動・回転・拡大縮小）、窓（20km）の外へ出られない（歩行・神モードとも）、窓の縁に線。
- 統計：世界・地域・集落の**人口・食料の充足・食料の蓄え**の時系列グラフ、ランキング、村の情報。統計の記録に食料の欄を追加（保存・復元・旧い記録の読み込みに対応）。
- 早送り：標準／日×10／月/秒／最大速度、**年・月を指定して進める**（1か月・3か月・半年・1年・5年・10年・30年・100年、任意の数）。進行画面・中止あり。毎月の計算を省かない。
- **性能モニター**：描画FPS・更新ループ・1か月の計算時間（動物／人の内訳）・1年あたりの時間・メモリ。**保存容量を測る**（内訳つき）。
- セーブ・ロード：窓の設定も保存。読み込み後も窓の制限と早送りが働く。
- 簡易樹木（新規）：森の濃さ（世界の植生）に応じて、近くにだけ幹と樹冠を並べる（インスタンス、最大8000本、村・水・急斜面を避ける）。

## 追記：最適化・圧縮
- 保存データの圧縮（deflate-raw）：3.66MB → 約0.7〜0.9MB。保存→読み込みの往復で状態一致、読み込み後の早送りも可（ブラウザ検証）。圧縮に使えない端末では従来の無圧縮で保存。

- S1：20km・4村・約200人／S2：40km・10村・約600人／S3：80km・24村・約2,000人（陸地率の条件はS3のみ緩和）。
