# 第2工程 2A：集落の立地条件の改善（報告）

## 1. 実装・修正内容
- 集落の候補地を「川沿いだけ」から4種類に拡張：川沿い／海岸／湖畔／湧水・オアシス（地下水が浅く、近くに地表水がない肥沃地）。
- 立地の評価を複数条件の積にした：食料 × 水 × 地形 ×（1＋0.35×（資源＋交通））× 洪水 × 暮らし方。各項目を `parts` として保存し、村ページに「立地：○○」と表示（長押しで内訳）。
- 移住・野営・提案・移動も「最寄りの川」ではなく「最寄りの候補地（同じ種類）」で動く。
- 定住の判断に、農耕・牧畜の見込み（`peSettleValue`）を加算。
- 初期配置は種類ごとの割り当て（川 .4／海岸 .3／湖畔 .2／湧水 .1：**仮の値**）。
- `g.site` はセーブに含まれる。

## 2. 実際に変化した動作
- 開始時の集団が川以外にも分布（例：川49・湖17・湧水6・海岸28）。
- どの種類でも集落の配置（建物）が作られることをブラウザで確認。

## 3. 検証結果
- `npc/test-sites.js`：60件通過（3世界×2シード、20年）。川だけの場合と比べ、人口・食料充足は同等以上（例：人口 8943→9432、充足 0.994→0.994）。
- ブラウザ確認（海岸・湖畔・湧水・川）全てOK、エラーなし。
- 全17本の回帰テスト：実行中（結果は別途追記）。

## 4. 既存仕様との整合性
- 技術の層・食料備蓄・施設・セーブ形式は変更なし。`g.site` が無い古いセーブでも読み込める（最寄りの候補地から再計算）。

## 5. 未解決の問題
- 種類ごとの割り当て比率は仮。実機で見て調整が必要。
- 川の判定は3か所に分かれたまま（統合は後続）。
- 湧水地は海岸・川に比べ配置が少ない。
