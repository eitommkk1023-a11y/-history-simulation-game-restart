# 本体統合版 v17

作業ブランチの自然地理生成器.htmlを本体統合版へ変更する。mainの元ファイルは変更せず、変更前の同一blobをbaseline/自然地理生成器.htmlにも保存する。

元HTMLの生成器・保存/ロード・時間・地質/火山操作・各表示モードを残したまま、共有するWebGLRendererへ三人称の描画を接続。俯瞰は元のscene/cameraと元の入力処理を実際に使用し、v16のコピーした広域描画は統合版では使わない。
三人称と本体のworldは同じ参照。初期画面はテスト地形ではなく本体の通常起動（既存オートセーブ確認または世界生成）。単一canvas。

通常はUIを隠し、スティック・ダッシュ・ジャンプ・しゃがみ・UI再表示のみ表示。UIを表示すると元のtoolbar等を利用できる。元の「表示：植生」等の表示切替は維持し、その隣に「世界を俯瞰／三人称に戻る」を追加。俯瞰中は人物を止め、アクションを隠す。
保存にはオプションのplayerフィールド（世界座標・カメラyaw）を追加。元のformat/genVersionは変更せず、既存セーブもplayerなしでロード可能。元の保存コードのほかの項目は維持。ユーザーの端末にある別オリジンのIndexedDBをこの環境から移動したり検証したりすることはできない。書き出しJSONは元のメニューから読み込む。
元の地形更新通知を受け、変更が落ち着いてから三人称チャンクを再構築する。実験操作は俯瞰へ切替えて行うのが見やすい。

## ビルド
node tools/build-integrated-world.mjs /tmp/geo-three-r128.min.js
baselineから本体ソースHTML（モジュール参照）とexports/World-of-History-integrated.html（Three.jsと三人称を内蔵する単一HTML）を生成する。
src/integration/third-person.mjsが統合用三人称の本体。previews/terrain-chunks.*は過去の検証用であり統合版の入口ではない。

## 検証
Node54件。integrated-world.browser.cjsで、本体からの実世界生成、1canvas、同一world、通常UI非表示、元のUI表示、俯瞰中の人物停止、三人称復帰、元のsaveTo/serializeState/loadState、人物位置の復元を確認。三人称と元の広域画面を目視確認。
ブラウザはChromium横844×390。Safari実機・ユーザーの既存保存データそのもの・全火山イベントの長期動作は未確認。

## v18 地図と三人称の見た目・位置対応
三人称地形の一律の緑色を廃止。本体の同じterrainTexを同じrendererで共有し、世界座標からUVを割り当て、植生/標高等の表示色を対応させる。元の表示モード変更でテクスチャが更新された際も追従する。
元の俯瞰に黄色の現在地マーカーを追加。座標は元のtoWorldX/toWorldZとmetersPerCellから算出。初回の人物配置は最初の北端平地ではなく、元の俯瞰中心に最も近い安全な内陸地点を選ぶ。保存済みのplayer位置を優先する。
俯瞰UIに「中央の陸地へ降りる」を追加。水域/急斜面なら拒否し、適切な陸地なら同じ座標を三人称に引き継ぐ。
重要な範囲: データが同じでも、俯瞰は元仕様の標高強調、三人称は実寸。元データ1セル約3.33kmのため人間の近くは滑らかな地面になりやすい。木・岩・建物の立体物、数m規模の詳細地形は未実装。この更新では追加していない。
検証: Node54件。本体統合ブラウザ試験でテクスチャの同一参照・UV、俯瞰マーカーの座標、同じ陸地点への降下、1canvas/同一world、人物停止、保存/ロード後の位置復元を確認。三人称/俯瞰画像を目視確認。Safari実機未確認。

## v19 開発用高速移動
`node tools/build-integrated-world.mjs /tmp/geo-three-r128.min.js --dev`で開発版exports/World-of-History-development.htmlを追加生成。通常の本体/単体HTMLには開発パネルを含めない。開発用ファイルの配布先による区別であり、ユーザー認証や秘密の権限判定ではない。
UIを表示→開発者から×1/×10/×100/×1000を選択。高速時は地形・水域の移動制限を無視して地盤に沿い、世界の外周で止まる。倍率選択後はパネルを閉じて操作の邪魔を避ける。
通常操作に戻す際、深い水/急斜面にいれば高速移動前の通常位置へ復帰。高速移動中の自動/手動保存は開始前の通常位置を保存する。世界の再生成・ロードで倍率はリセット。俯瞰から中央の陸地へ降りる操作も従来通り利用可能。
高速移動中は旧近景を遠景切替まで保持せず解放し、連続移動による一時メッシュの蓄積を抑える。移動が速過ぎる間は遠景の準備が追いつかないことがある。止まると通常のキューで補完する。
検証: Node55件。通常版に開発用コードが入らないこと、実際の移動量の増加、保存位置保護、海へ移動した後の通常復帰をChromium844×390で確認。世界境界のクランプも純粋関数で確認。Safari実機未確認。
