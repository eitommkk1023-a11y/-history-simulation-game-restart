# survival-v1 報告（生存の完成：狩り・怪我・衣服・保存食・水の持ち運び）

方針変更（クレジット効率のため）：機能ごとに公開・報告するのをやめ、まとまった単位で実装し、**全回帰テストは最後に1回**、レポート・公開・main への取り込みも1回にまとめた。

## 内容
1. **狩り**：弓（薪2・縄2）か槍（薪1・石1・縄1）を作り、「狩りに出る」（右下の「調べる」の上のモード「狩」、持ち物パネルの「狩りに出る」）。
   - 1回の旅＝1日（時計が1日進む）。朝・昼・夕を6回ずつ、計18回の追跡を、既存の動物の仕組み（`faunaHunt`）で行い、その場所にいる獲物のうち、数が多く狩りやすい種を狙う。実測で、1回の旅の成功は約3〜4割。
   - 腕前（狩猟の技能）、武器（弓は安全寄り、槍は獲りやすいが危険）、体調で成功率が変わる。得られる物：肉・毛皮・骨・角（持ちきれない分は残す）。狩りのたびに狩猟の技能が伸びる。武器は30回で壊れる。
2. **怪我と手当て**：獲物に反撃されることがある（鹿4%・野生ヒツジ5%・イノシシ22%・オーロックス30%、槍は×1.2、弓は×0.7）。怪我の間は体力が毎日−4。**薬草2つで手当て**するとすぐ止まる（薬草は森や草地で「素材を探す」）。怪我が原因で亡くなることもある（死因：怪我）。
3. **衣服**：毛皮の衣（毛皮4・縄2）は寒さを8割、草の外套（繊維16・縄2）は4割防ぐ。持っていれば自動で着る。毛皮の衣は約240日、外套は約80日で傷んで無くなる。
4. **保存食**：生ものは日がたつと傷む（肉30%・魚25%・貝20%・新芽20%・煮物20%・果実10%・焼いた物12%／日。貯蔵庫では半分。木の実・石などは傷まない）。**干す**（火のそばで肉・魚・果実を干し物にする）と、ほぼ傷まない（0.8%／日）。傷んだ分は捨てられ、画面に知らせる。焼き肉（1,100kcal）、干し肉（800kcal）なども追加。
5. **水の持ち運び**：水袋（毛皮1・縄1）は3回分、土器は4回分（両方で7回分）。川や湖で「水を汲む」と、水辺から離れても「水を飲む」で飲める。
6. 目標を5つ追加（全22）：弓か槍を作る／狩りで獲物を得る／肉や魚を干す／衣を作る／水を汲んで持ち歩く。
- 保存：怪我・持ち水・衣の傷み・傷みの端数も記録に入る（古い記録も読める）。死亡の画面の死因に「怪我」を追加。
