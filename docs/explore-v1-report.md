# 探索の改善（調査と移動手段）

ブランチ：`claude/explore-v1`（`claude/fauna-multi-v1` から）。きっかけ：「マップは広いのは良いが、探索に時間がかかる。走りでもなかなか山の頂上に辿り着けない」。

## 調査（Seed 42、ブラウザで測定）
- **水平**：1ブロック＝実際の3.33kmの1/100＝33m。世界の端から端まで約100km。走る（4m/s）と約7時間、ダッシュ（10m/s）でも約2.8時間。
- **標高**：`1000×tanh(実際の標高/3000)`で、約1,000mに圧縮。最高峰（実際7,400m）は986m。3,000m以上は、ほぼ全部が900〜990mの**台地**になり、山頂が目立たない。
- **傾斜**：マクロの地形で、標高1,500〜3,000mの地点の88%が45°以下（歩ける）。台地の上は歩ける。
- **本当の壁は台地の縁（崖）**：最高峰の東で、標高 913m（1,500m地点）→ 0m（2,000m地点）。水平500mで約900m落ちる（平均 約60°）。水平を1/100にして、標高は約1/7にしか縮めていないため、海岸から高地へ登るところが崖になる。
- 傾斜の上限を45°→58°（急な所は減速）に変えて、山頂へ走る歩行テストをしたが、台地の上では差が出なかった（どちらも止められない）。**効果を確認できなかったので、この変更は元に戻した**。

## 入れたもの
- 情報パネルの「移動」：**あなたの集団・近くの山頂（半径60ブロック）・近くの海辺（半径90ブロック）・近くの集落（距離順に14か所、民族名・段階・距離つき）**へ、移動できる。山頂のときは、実際の標高も表示。
- 確認：山頂・海辺・別の集落への移動が動作。既存の確認（住民・継承・提案・タイトル・岩石・開発者モード）にエラーなし。
