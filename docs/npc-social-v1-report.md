# 人間関係と首長（報告）

ブランチ：`claude/npc-social-v1`（`claude/npc-view-v1` から）。方針（会話・提案の準備）の1番目。「提案」は同じブランチで続けて追加する。

## 入れたもの
### 人間関係（家族以外）
- 信頼・好意・尊敬の3つ（0〜255、128が普通）。1人あたり最大6人（約42バイト。10万人で約4MB）。家族は保存せず、既存のデータから決まった値で扱う。
- 毎月、10歳以上の人が2回交流する。顔なじみ（すでに関係のある人）を55%の確率で選び、残りは同じ仕事の人・同じ集団の誰か。結果は、お互いの性格（社交性・共感性・誠実性・信頼傾向）・技能・年齢で決まる。いっぱいになったら、一番ふつうの関係を置き換える。
- 開始時に、それまでの暮らしでできた関係を作る（36回分）。

### 首長（集団の長）
- 決め方は民族ごと（仮の割合）：長老制30%／能力制30%／世襲25%／合議15%。
  - 長老制：35歳以上で、年齢と尊敬の合計が最高の人。
  - 能力制：尊敬・技能・判断力・計画力・洞察力の総合が最高の人。
  - 世襲：前の首長の跡継ぎ（継承の決まりに従う）。
  - 合議：総合上位3人の合議。その中で、一番尊敬されている人が代表。
- 首長がいなくなった集団は、すぐ決め直す。年に1回の見直しで、今の首長より15%以上高い人がいれば交代（世襲は首長が亡くなったときだけ）。
- 出来事：首長が代わったとき（自分の集団は重要度2）。

### 画面
- 情報パネルに「首長」の行（職業・性別・年齢・決め方）。
- 近くの人の情報カードに、「首長」の印と、「あなたから見て：信頼・好意・尊敬」。家族は決まった値、他は交流の記録。まだ付き合いがなければ「（まだ付き合いがない）」。

## 測定（Seed 42）
- 20年後：普通からの平均のずれ（信頼 64・好意 54・尊敬 91）。好意が高い関係は開始時 18% → 20年後 32%。相手への好意の平均は、社交性が高い人で164、低い人で92。
- 首長の決め方ごとの首長の平均年齢：長老制 66歳、能力制 61歳、世襲 61歳、合議 59歳（集団の成人の中央値は40〜42歳）。
- 首長の交代：集団あたり年 0.12回。
- 1か月の計算：平均 約15ms（人間関係を足す前は約12ms）。保存→読み込みで、関係・首長が一致。
- ブラウザ：首長の行、首長のカード、岩石・開発者モード・継承時のキャラクター移動、全てエラーなし。

## 注意
- 関係は最大6人で、昔の友人や敵は入れ替わっていく。恐怖・恩義・遺恨・利害は未実装。
- 首長に権限はまだ無い（次の「提案」で、首長の提案が通りやすくなる）。
- 係数（交流の効き・首長の決め方の割合）は仮の値。

## 追記：提案（方針・移住）
同じブランチ。ゲームの情報パネルに「提案」の行（選択肢と「提案する」）。

- **提案の種類（最初は2系統）**：方針（狩猟／採集／漁を優先、自動に戻す）と、移住（3Dのキャラクターがいる場所へ。近くの川沿いに直す。海を越える所・近すぎる所・川が無い所は提案できない）。
- **投票**：集団の成人から最大30人を抽出し、それぞれが賛成か反対かを判断する。材料：提案者への信頼（家族は高い）、年長者・首長の重み、仕事（自分の仕事の方針には賛成）、性格（慎重な人は変化に反対、好奇心の強い人は賛成）、食料（飢えていれば移住に賛成）、距離。
- **通る条件**：首長の提案は賛成40%以上、一般の人は50%以上。首長が反対しているときは必要な賛成が+10ポイント（通りにくくなるだけで、拒否はできない）。
- 結果（賛成率・必要な率・首長が反対か）を表示し、出来事に記録。通れば、集団の方針・移住に反映される。提案のあとは待ち時間（通ったら2か月、通らなかったら4か月）。成人していないと提案できない。

### 測定（Seed 42、集団ごとに首長1人・一般3人が提案、2,055回）
- 一般の人の方針：61%が通る（賛成率の平均58%、首長が反対 44%）。首長の方針：100%（賛成率の平均93%）。
- 移住：一般の人は食料があると12%・飢えていると100%。首長は食料があると49%・飢えていると100%。
- ブラウザ：提案が通る／通らない、待ち時間、出来事の記録、方針の反映を確認。エラーなし。

### 注意
- 首長の方針の提案は、ほぼ全て通る（首長の重みが大きい）。体感を見て調整する。
- 提案は自分の集団に対してだけ。他の集団・民族への働きかけは未実装。
- 移住の提案は、世界の位置を指定する操作（地図上のタップ）ではなく、キャラクターのいる場所。
