# 騎兵と荷馬車（戦闘計算 試作）

`npc/battle.js` に追加（係数は［仮］）。
- 騎兵：`addUnit(..., {mounted:true, weapons:[['lance',false,n]]})`。歩兵の約2.2倍の速さ、馬の体力30・乗り手12。森で半分の速さ。隊形の間隔が広い。
- 突撃：槍（lance）は、走りながら当てると傷が最大1.9倍。背面・側面は既存どおり大きい。
- 槍衾：槍の歩兵に正面から突っ込むと、25%で馬が突かれる。当たりの3割は馬へ。馬が倒れると乗り手は落馬して歩兵になる。生き残った馬は30%で後ろ脚立ち。
- 荷馬車：`addTrain`。進む、敵が近づくと引く、歩兵に壊される（体力40）。矢：射手は `arrows` が尽きると撃てず、25m以内の味方の荷馬車から12本ずつ補給される（`arrows` 未指定は無限＝従来どおり）。
- 画面へ：`viewHorses(B)` が馬・荷馬車ごとに speed／歩様（idle〜gallop）／state（0通常 1後ろ脚立ち 2倒れる 3倒れたまま）／stateT／rider を返す（Codex の馬の仕様どおり）。

## 検証
`node npc/test-battle.js` 35件通過（既存20＋追加15）。5000体（騎兵1000）：1ステップ約39ms（PC）。画面の戦場表示（battleview/battleview2）はエラーなし。
実測：助走つき突撃の撃破 3.6／止まって 3.4（差は小さい）、背後から 5.1、正面で馬を失う 平均1.0頭。
