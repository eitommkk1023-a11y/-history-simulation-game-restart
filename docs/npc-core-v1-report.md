# NPC 段階1：個人ID・ID から決まる能力値（測定報告）

`npc/npc-core.js`（ゲーム本体にはまだ組み込んでいない独立モジュール）、`npc/bench.js`（測定）。

## 方式
- 全員に個人ID（配列の添字）。1人あたり約 25 バイトの型付き配列（誕生日・死亡日・性別・民族・両親・配偶者・職業・フラグ）。
- 性格 10軸・認知 8・身体 5 の生まれつきの値は、Seed＋ID（＋両親、3世代まで）から計算。保存しない。
- 保存するのは人生で変わった分（delta）だけ。
- 判定は人ごとに月1回（id % 30 が日付と合う日）、記録は日付つき。乱数は固定の順序で使うので、同じ Seed なら同じ結果。

## 測定（Node、このコンテナ）
| 人数 | 配列メモリ | 1年進める | 備考 |
|---|---|---|---|
| 10万 | 約 5MB（30年後 13MB） | 約 170ms | 30年で 10万→14.4万（年約1.2%増） |
| 30万 | 約 14MB | 約 400ms | |
| 100万 | 約 48MB | 約 1.4秒 | |

- 全員×23項目を ID から計算：10万人で 80ms（1値 0.03μs）。
- 能力値の分布：平均 127.5、標準偏差 約 43（0〜255）。親子の相関 約 0.5。
- 変化分：10万人の10%に3項目で 3万件、保存 0.2MB。
- 同じ Seed で2回走らせて結果が一致。

## まだ測っていないこと・注意
- iPhone 実機の速度（Node の2〜3倍遅い可能性）。
- 1日ずつ進める場合は、1日分が 10万人で約 0.5ms、100万人で約 4ms。
- 死者の記録は配列に残り続ける（長期では圧縮が必要）。
- 出生・死亡率や結婚の仕組みは「たたき台」。人口の増え方は未調整。
