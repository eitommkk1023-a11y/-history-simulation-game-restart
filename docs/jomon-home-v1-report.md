# jomon-home-v1 報告（縄文の暮らし：住まい・貯蔵・睡眠）

前段 jomon-slots-v1 の上に、竪穴住居と貯蔵庫と睡眠を足した。ロジックは `npc/forage.js`、画面は持ち物パネルの「住まい」欄、3D表示はネイティブ側の新しい「置き物」API（`__wohProps`）。

## 仕様
- **家を建てる**：薪10・繊維12・縄2・粘土4。水辺・海辺には建てられない。完成まで3日（ゲームの時計）。1人1軒。位置は今いる場所のすぐ東（約4.5m）。
- **貯蔵庫**：家が完成していて、家のそば（3ブロック以内）にいるときだけ使える。30枠（積める数は持ち物と同じ規則）。「預ける」「取り出す」。持ち物が満杯だと取り出せない。
- **眠る**：家のそばで眠ると体調不良が治り、1日が過ぎる（時計が1日進む）。家が無くても、焚き火のそばなら野宿できる（1日が過ぎるが体調は戻らない）。
- **家を壊す**：貯蔵庫が空のときだけ（中身を失わないため）。材料は戻らない。
- **家へ戻る**：家のある場所へ移動。
- **野営地まで**：自分の集団の野営地までの距離を表示（家を村の近くに建てる目安）。
- **3D表示**：家（盛り土＋茅葺きの円錐屋根）と焚き火（石の輪＋揺れる炎）を地面の上に描く。炎が見えている間だけ毎フレーム再描画する。焚き火は燃えている間だけ表示。
- 保存：家・貯蔵庫・焚き火の座標も記録に入る。古い記録（家なし）も読める。

## 検証（合格）
- Node 単体 142件（建築・材料不足・水辺不可・二軒目不可・貯蔵の上限と距離・取り出し・壊す条件・眠る3通り・保存と壊れた保存）。
- Playwright（iPhone横画面）：内陸の草原で、預ける（家なし→拒否）→ 家を建てる（建築中は預けられない）→ 家も火も無い所で眠る→拒否 → 火を起こして野宿 → 3日後に預ける・取り出す・家で眠る → 3D表示（家・焚き火が `visible: true`、4方向のスクリーンショットで家を確認）→ 保存。エラー0。
- 回帰：cooktest / crafttest / foragetest / gotest / avatartest / peopletest / titletest / devtest / rocksmoke 通過。
