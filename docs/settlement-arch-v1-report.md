# 紀元0年の集落・建築システム改良（報告）

ブランチ：`claude/settlement-arch-v1`（`claude/settlement-v1` から。`main` やCodexのブランチには触れていない）。単一エージェントで、小単位で実装・検証・コミットした。
画像：`docs/images/settlement-coast-thatch.png`（海辺の草葺きの村）、`settlement-dry-mud.png`（乾燥地の土の平屋根の村）、`settlement-timber-village.png`（木と草葺きの大きな村）、`settlement-camp.png`（野営地）。

## 調査（既存コードの把握）
- 以前の家は、`dwScan`/`dwApply`（ゲーム本体）が円筒＋円錐を世帯数ぶん並べるだけで、位置は `npc-view` の `homeBase`（個人ID・世帯のハッシュで円状に散らす）。地形・水・道・資源を見ておらず、民族・環境による違いがなかった。
- 使える環境データ：気候（気温・降水）、資源の格子（木材・石・粘土・肥沃度）、植生・地形の分類（森・草・砂漠・ツンドラ・湿地・険しさ）、標高、3D側の細かい地形（傾斜・水深）。人口側：世帯ID（夫のID）、民族の文化の特徴、定住の段階、職業の人数。
- `src/transport`（交通の試作）は別目的のため触れていない。人物モデル・政治・軍事には着手していない。

## 実装したもの
1. **建築のプロシージャル生成**（`npc/arch-gen.js`、描画に依存しない）
   - 建築伝統の遺伝子（民族の系統ごと：平面形・屋根・材料・入口の向き・装飾の好み）。分裂・融合した民族は親の伝統を受け継ぎ、少しだけ変わる。
   - 地域の建て方（遺伝子＋気候＋資源＋植生＋建築技術）：壁（木・石・日干しレンガ・土・芝土・葦）、屋根（草葺き・板・芝・土・石板）、平面（円・長方形・多角形）、屋根の形（切妻・寄棟・円錐・平）、傾斜、高床／床下げの傾向。
   - 建物の設計データ：平面・壁の高さ・屋根・基礎・入口・窓・装飾・寸法（メートル。プレイヤー 1.7m と同じ縮尺）。用途：住居・倉庫・作業場・集会所・干し場。完成モデルは持たない。
2. **集落の自動生成**（`npc/settle-layout.js`）
   - 水場（住居は水から平均 約50m、干し場は水辺）、傾斜（26°超を避ける）、既存の建物との重なり防止、世帯の親族の近く、平らで乾いた広場。
   - 世帯と住居の対応（`byHouse`）。倉庫・干し場・作業場・集会所は、暮らし（採集・漁・道具づくり）と段階で数が決まる。固定の「集落タイプ」はない。
   - 道（各家の入口と広場、水場、障害物の迂回）、柵（防衛の歴史があるとき。出入口を開ける）、畑（農耕のある集団のときだけ。接続口）。
   - 基礎：傾斜・湿り・寒さで、土台・高床・テラス・床下げ。野営地は軽いテント。
3. **紀元0年の集落の歴史**（`settleHistory`）：成立年代（0〜480年前）、状態（成立したて・確立・衰退中・季節の野営）、出来事（洪水・火事・飢饉・疫病・拡大・襲撃）、建築技術、防衛（なし・柵・頑丈な囲い）。開始前の歴史を一日ずつ計算せず、成立年代から、建物の古さ・数・廃屋・防衛を決める。保存に含まれる。
4. **既存システムとの連携**
   - 民族・人口・世帯と同じID：建物は `gid（集団）`・`house（世帯ID）`・建物ID を持つ。親族は夫の母の世帯。
   - Seed・集団・世帯が同じなら同じ集落（再現性）。保存・読み込みで配置が一致。
   - 建物のデータに、寸法・入口の位置と向き・基礎・状態・築年を保持。
   - **NPC による建設・改築・解体の接続口**：`requestBuild`/`applyRequests`、世帯の増減を反映する `syncLayout`（新しい世帯は空き家に入り、足りなければ建てる。いなくなった世帯の家は空き家→廃屋（5年）→撤去（12年））。NPC の意思決定側からの呼び出しは未実装（接続口のみ）。
   - 住民は、世帯の住居の入口の近くで夜を過ごす（これまでは円状の乱数配置）。
5. **描画と性能**：9種類の共有の形（箱・円柱3種・切妻・寄棟・円錐3種）を色と大きさで変えたインスタンス描画。集落全体で描画 約11回。遠くは細部（窓・装飾）を省略。地面は近づいたとき細かい地形で測り、基礎の高さを決める。毎フレームの再生成なし（1秒に1回、近くの建物の行列を更新）。

## 実際の動作結果（合格・失敗・未検証）
### Node のテスト（合格）
- `npc/test-arch.js`（Seed 42・7・1）：寸法の妥当性（不正 0）、再現性、同じ系統は似ている。環境ごとの傾向：乾燥地は土・日干しレンガ・石の壁と平屋根、多雨地は急な屋根・高床、木材が豊富なら木の壁。**極端な合成環境**：寒冷なツンドラは芝土の壁と床下げ（100/100）、砂漠は日干しレンガ・土・石と平屋根（100/100）、密林は木の壁・高床・急な屋根（100/100）、岩山は石の壁（88〜95%）。同じ環境・技術でも民族が違えば 20〜25 種類の設計に分かれる。
- `npc/test-layout.js`（合成地形）：建物の重なり 0、水の中 0、急斜面 0、全世帯に住居、全入口が道で広場につながる、親族が近い（14m ＜ 34m）、干し場は水辺（平均5m）、再現性、世帯の増減（空き家への入居・新築・廃屋・撤去）、NPC の改築・解体の要求、畑の重なり 0、柵が建物と重ならない、成立したて・古い・衰退中・季節が共存、地形キャッシュの誤差が小さい。
- `npc/test-settle-people.js`：人口の仕組み（世帯・経済・歴史）との接続で、40集団すべてで全世帯に住居。
### ブラウザ（合格）
- 村・半定住・野営地で、民族と環境によって違う見た目の集落が描かれる（画像参照）。保存→読み込みで配置が一致。3年進めても最初の建物が動かず（136/136）、世帯の増減を反映。エラーなし。
- 既存の確認：住民・提案・名前・民族の変化・3D表示・継承・タイトル・岩石・開発者モードは、エラーなし。

## 既存機能への影響
- 以前の「円筒＋円錐」の家の描画は置き換えた（焚き火は残した）。住民の夜の位置が、家の入口の近くになった。
- 保存に、集落の歴史（全集団）と、近づいた集落の配置が加わる（90世帯の村で約 140KB／村）。古い保存は読み込める（歴史がなければ、そのまま始まる）。
- 遠くからの表示・仮想スティック・カメラ・ジャンプには変更なし。

## 性能
- Node：90世帯の集落の配置 約37ms。地形キャッシュの作成 約3ms。
- ブラウザ（ソフトウェア描画の環境、JS の時間は実測）：定常 1回の更新 約1ms（1秒に1回）。配置の作成は集落に近づいたとき一度だけ 約60〜100ms（1回の更新で作るのは1集落まで）。部品数 約1,000〜1,300／村、描画 約11回。
- **iPhone/iPad 実機は未検証**（ここに実機がない）。

## 未完成・注意
- **農耕・牧畜・交易はまだ人口側に無い**ので、畑・家畜小屋は接続口（農耕がある集団のときだけ作る関数）のみ。市場や倉庫の細かい役割分担も未実装。
- 材料の質感（テクスチャ）は無く、色で区別している。窓や入口の細部は近距離のみ。
- 配置は地形の粗い高さ（集落の周り200m、5m間隔）で決め、基礎の高さは近づいたとき細かい地形で測る。急な崖・川の岸などで、まれに家が水際に近すぎる／浮いて見えることがありうる（未検証）。
- 配置の保存が1村あたり約140KB。多くの村を見て回ると保存が増える（圧縮は未実装）。
- 防衛設備は柵のみ。軍事・政治の仕組みとはつながっていない。
- 実機の速度、長時間の遊びでの安定性は未検証。
