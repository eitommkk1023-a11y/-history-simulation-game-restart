# 第3工程：建築と民族・地域文化の多様化（報告）

## 仕組み（ランダムな形違い・色違いではなく、知識・環境・材料・交流から決まる）
1. **建築技法（知識）**：集団ごとに「知っている建築技法」を持つ（`g.arch.have`：技法→身につけた日）。基本の技法（編み壁・草葺き・芝土・練り土・皮張り・竪穴・高床・乾式石積み・深い庇）は誰もが持つ。進んだ技法は、**民族の技術の層**から身につく：丸太組み←舟、板張り←銅・青銅・鉄、日干しレンガ←土器、焼成レンガ←高温焼成、切石積み・漆喰←青銅・鉄、長い家←首長制。
2. **材料の選択は知識で制限**：知らない技法の材料・工法は選べない（板葺き屋根は板張り／丸太を知らないと不可、石板屋根は切石積み、など）。材料の適性は気候・資源・技術から（従来どおり）。新たに焼成レンガ・皮張りの壁と、工法（編み壁・丸太組み・板張り／乾式・切石）を追加。
3. **建物の形式**：竪穴の家・高床の家・長い家・円形の家・多角形の家・箱形の家（平屋根）・切妻寄棟の家・皮張りの天幕。形式は環境・知識・世帯の大きさから決まる（例：寒冷地は竪穴、水辺・多雨は高床、大きな世帯は長い家（長い家の技法を持つ場合））。深い庇（柱つき）も、暑い・多雨の地で。
4. **同じ民族内の地域差**：近い地域（25グリッド四方）ごとに、民族の好みに少しずつ癖が付く（`regional`）。同じ地域なら同じ癖、別の地域なら違う。さらに気候・資源が違えば材料も変わる。
5. **他民族との交流**：近くの集団（交流の届く距離 200グリッド）から、技法が伝わる（年ごとの確率。同じ民族間は伝わりやすい／他民族間は様式がしみこむ）。他民族の隣人の好み（平面・屋根・材料・入口・装飾）が、影響の度合い（最大40%）で混ざる。伝わった技法は「どの民族のどの集団から、いつ」を記録。
6. **建築年代**：建てた日に知らなかった技法は使えず、技術も今より低い（`tradAt`）。古い建物ほど素朴な作り（編み壁・乾式石積み・低い壁）。
7. **集落詳細マップに反映**：建物に 形式・工法・材料・築年・建設者を表示。建物の色分け（用途／壁の材料／家の形式／築年）と凡例。集落の「建築の知識」欄に、持つ技法と由来（自分たちの技術／○○民族から／開始前から）と他民族の様式の影響を表示。3D表示には、工法の見た目（丸太・板の角柱と継ぎ目、切石の基部、煉瓦の帯、庇の柱）を追加。

## 既存仕様との整合
- 建物の重なり禁止・配置・保存・集落詳細マップは維持。2Cの履歴（`rec`）に、工法・形式・庇が加わる。建築伝統の遺伝子（民族の系統ごとの好み）は従来のまま、その上に地域差・他民族の影響・知識の制限を重ねた。
- 旧版の保存（形式・工法のない建物）はそのまま読める（表示は「—」）。新しく作る集落から新しい建築になる。
