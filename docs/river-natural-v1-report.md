# 自然な川 v1：川と土の境目をなくす

ブランチ：`claude/river-natural-v1`。きっかけ：「川と土の境目がなくて、自然な川になっていない」（参考写真：石の河原と浅瀬、草の岸のある川）。

## 原因（調べた結果）
- 世界は 3000×3000 マスで、1マスが 33m。川は「川のマスが青く塗られる」だけだった。
- そのため、川は **1マス（33m）幅の青い帯で、岸がマスの形にカクカクしていた**。水の面も、深さも、岸の変化もなかった（水の面があるのは、海と湖だけ）。
- 川の中は、ただの青い地面として歩けた。

## 直したこと（見た目）
- 世界の川の線（流れの経路）から、近く（約2km四方）の**距離の場**を、2m刻みで作る（1回20ms ほど。500m移動するたびに作り直す）。川の幅は流量で決まる（幅およそ5〜32m）。
- 地面の色の計算に、次を足した。
  - **水**：中心は深い青、岸に近いほど浅い緑がかった色。縁は、ゆるいノイズでゆらぐ（真っ直ぐな線にならない）。
  - **岸**：濡れた暗い土の帯、その外側に**河原（砂利）と小石**、さらに外側に**草の縁**（少し濃い緑）。
  - 元の「青いセル」は、まわりの陸の色に置き換える。
  - 遠くでは、小石や細かい模様を弱める（ちらつき防止）。
- 川の中は、**浅くて歩いて渡れる深さ（最大0.55m）**として扱う。草は川の中に生えない。新しく作る集落の建物は、川の中に建たない。

## 確認したこと
- ブラウザで、川の近くを地上から、低い視点・高い視点から見て、川がなめらかに曲がり、深さの変化、河原、草の縁が出ることを確認。エラーなし。
- 川の中心は深さがあり、離れた所は0。

## 未対応・課題
- **湖と海の岸**は、まだ元のまま（水の面の縁がくっきり）。同じ方法で直せる。
- 川の床の彫り込み（地形の高さ）は変えていない。地面は平らなまま、色で川を描いている。
- 約2km の外の遠景は、元の青いマスのまま（遠くの川の見えやすさのため）。境目は、遠いので目立たないが、見える場合は広げる。
- 実機の速さは未確認（地面の色の計算が少し増えた。川の近くだけ重い）。
