# 馬（と荷馬車）の見た目の受け渡し仕様 v1［たたき台］

戦場に最大5,000体（人と馬の合計）を同時に出す前提。Codex が作る馬の造形・モーションを、戦闘計算（`npc/battle.js`）と画面（`BV`）につなぐための取り決め。

## 1. 描画方式（必須）
- Three.js r128。`InstancedMesh`（骨のスキニングは使えない）。
- 動きは **頂点アニメーション・テクスチャ（VAT）** か **頂点シェーダーでの手続き的な脚振り** のどちらか（近距離はVAT、遠距離は手続き、の併用も可）。
- 馬1体 = 1インスタンス。描画命令は、LODごと・種類ごとに数回まで。
- 三角形の目安：近 500〜800／中 150〜200／遠 50以下（板）。5,000体でも1フレーム 100万三角形以内。
- 見た目の違いはモデルを増やさず、インスタンスごとの値で出す（毛色・たてがみ色・大きさ）。

## 2. 動きの種類（名前は固定）
| 名前 | 内容 | 速さの目安（m/s） |
|---|---|---|
| `idle` | 立ち止まる（耳・尾が少し動く） | 0 |
| `walk` | 並足 | 〜2 |
| `trot` | 速歩 | 2〜5 |
| `canter` | 駆け足 | 5〜8 |
| `gallop` | 全力疾走 | 8〜 |
| `turn` | その場で向きを変える（左右） | - |
| `rear` | 後ろ脚立ち（後ろ脚だけで立ち上がり前脚を上げる。Tポーズではない）。突撃前・怯えたとき | - |
| `fall` | 倒れる（1回きり） | - |
| `dead` | 倒れたまま（静止ポーズ） | - |
- 歩様の切り替えは速さから自動で決める（シェーダー内でブレンド）。位相は個体ごとにずらす。
- 荷馬車を引く馬は `walk` / `idle` のみでよい。

## 3. 1体ごとに渡す値（インスタンス属性）
| 名前 | 型 | 意味 |
|---|---|---|
| 位置・向き・大きさ | 行列 | 位置(x,y,z)、向き(ヨー)、大きさ |
| `speed` | float | 現在の速さ（m/s）。歩様の選択と脚振りの速さに使う |
| `phase` | float | 個体ごとの位相（0〜1）。同じ動きがそろわないように |
| `state` | float | 0=通常 1=rear 2=fall 3=dead |
| `stateT` | float | 状態に入ってからの秒数 |
| `coat` | float | 毛色の番号（パレット参照） |
| `rider` | float | 0=騎手なし 1=騎手あり（鞍や荷の表示切替） |

## 4. 騎手・荷の取り付け位置
- 馬のモデルに「鞍」の点を持たせる（馬の座標系で位置と向き）。騎手モデルはこの点に置く。
- 動きで鞍の点がどう上下するかも同じ方法（VAT／式）で分かるようにする。人は歩様の上下動に合わせて動かす。
- 荷馬車：車体（荷台＋車輪）は別モデル。車輪は速さに比例して回す。引く馬とは連結点（くびき）を共有する。

## 5. 大きさ（ゲーム内の単位は m）
- 馬：体長約 2.4、肩の高さ約 1.5。荷馬車：長さ約 4、幅約 1.8。

## 6. 戦闘計算（こちら）との取り合い
- 計算側は 0.5 秒ごとに位置・向き・速さ・状態を更新する。画面側はその間を補間して描く（動きの再生は画面側）。
- 計算側の現在の兵の最小単位は「歩兵」。騎兵・荷馬車は今後 `battle.js` に追加する（馬の種類：軍馬／乗用馬／駄馬／輓馬）。

## 7. 計算側の実測（2026-11、Node、仮の係数）
1ステップ（0.5秒の戦場）の中央値：2,000体 7.5ms／5,000体 28ms（最大 65ms）。おおむね人数に比例。
画面の負荷とは別。iPhone 実機は未測定（PCより数倍遅い想定）。5,000体で等倍は足りる見込み、早送りは要対策（計算を複数フレームに分ける、小隊単位に粗くする）。
